## 本轮生成命令（逐字，cwd = `data_model`）

```bash
cd data_model
python -u -m pipelines.e2e.train --epochs 1     # 12:05:01 → 12:57:21，rc=0，3140.4 s
python -u -m pipelines.e2e.predict              # 12:57:22 → 13:37:20，rc=0，2398.8 s
```

- `--epochs 1` 是**冒烟轮次**，报告自证 `最大长度 / 轮数 / 学习率 = 512 token / 1 / 2e-05`，不冒充满轮。
- 设备 **CUDA（fp16）**；有效 batch 32（16 × 累积）；1653 batch。
- 训练产物：`models/codebert_e2e_v1/model.safetensors`（498,612,824 B，md5 `e49212368a0e9fd16512035c07aa4d06`，201 个张量，末维含 768，分类头 `classifier.out_proj.weight` = (2, 768)）。
- 预测产物：`data/prediction_result.csv` = **83,943 数据行**、5 列契约序（`commit_hash,model_name,risk_score,predicted_at,feature_version`）、`model_name` 全为 `codebert_e2e_v1`、`feature_version=codebert`、`risk_score` 0.002740~0.964200。
- **expert 线那份同名 `prediction_result.csv` 未被覆盖**（e2e 只写自己的 `pipelines/e2e/data/`）。
- 门槛日志：`evidence/gates_train_predict.log`（含 rc、耗时、行数、列名、取值范围）。

## 需要你知道的事（逐条都有证据文件）

1. **本线没有 `manifest.txt`**：e2e 不产在线加载清单，权重是 `codebert_e2e_v1/` 目录（safetensors + tokenizer），所以 #159 的改名与 `verify_all_weights --check` 两件事都与本线无关。
2. **排除了** `models/codebert_e2e_v1/checkpoints/checkpoint-1653/`（**1.4 GB** 训练中间态，含优化器状态）；导出后的 `model.safetensors` 已是同一轮的最终权重，需要中间态我再单独打一个包。
3. **多加了** 6 个 tokenizer/config 小文件（`config.json` / `merges.txt` / `special_tokens_map.json` / `tokenizer.json` / `tokenizer_config.json` / `vocab.json`，合计约 4.8 MB）—— 你的清单只点了 `model.safetensors`，但缺这 6 个 `from_pretrained` 起不来；不想要直接删这个目录里的非 safetensors 文件即可。
4. `reports/prediction_stats.md:13` 有一行本机绝对路径（`输出文件 | <本机路径>/…/prediction_result.csv`），**我没改**（它是评估报告正文、也就是你要的交付物）。这份报告在仓库里是 untracked-not-ignored，入库前需按 §0 第 3 条处理，建议改成仓内相对路径 `data_model/pipelines/e2e/data/prediction_result.csv`。
