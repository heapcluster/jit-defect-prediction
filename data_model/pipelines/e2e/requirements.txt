# e2e 线（CodeBERT 端到端微调）训练环境依赖
#
# 环境：Python 3.12.x
# 安装：pip install -r data_model/pipelines/e2e/requirements.txt
#
# ⚠️ 关于 CUDA（RTX 4060 必看）
# PyPI 上的 `torch==2.5.1` 是 **CPU 版**。在 4060 上要 GPU 加速，必须装 CUDA wheel：
#     pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu124
# 装完验证：python -c "import torch; print(torch.cuda.is_available())"  → True
# 若只装了 CPU 版，`train.py` 会自动退回 CPU（能跑，但微调极慢）。
#
# ⚠️ 首次运行会联网下载 `microsoft/codebert-base`（约 500MB）。离线机先缓存模型，
#    再设环境变量 HF_HUB_OFFLINE=1 运行。
#
# numpy / pandas / scikit-learn 与 expert 线（data_model/requirements.txt）**同源**，
# 跨线指标才可比 —— 不要单独升这几样的版本。
