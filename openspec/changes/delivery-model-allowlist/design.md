# 设计决策

1. 复用模型线已入库的交付副本 `feature_order.txt`，不在后端硬编码三模型列表。此清单不是特征权威；列序仍以 `docs/model/feature-columns.md` 冻结契约为准，后端用 `config.FEATURE_COLUMNS` 校验。
2. 采用拒绝加载而非猜测策略：缺清单、重复/非法模型名、列序不符时清空注册表，查询接口仍可启动；预测按现有契约返回 50000，内部错误仅进日志。
3. 逐个加载已声明模型；单个声明权重缺失或反序列化失败只跳过该项，沿用既有降级。目录中的未声明权重不碰、不解析，从而避免可选训练模型的额外运行依赖。真实三模型加载成功与 p95 仍需交付环境验证。
