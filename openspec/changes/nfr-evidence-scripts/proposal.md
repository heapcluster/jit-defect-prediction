# 性能与安全证据脚本（周报任务 10）

> Sprint 0 ｜ 对应飞书周报任务 10（两项质量要求的证据，负责人吕建江）｜ 做法与验收见 `docs/dev-handbook.md` §9，验证口径见 `docs/contracts/api-format.md` 1.3 §4
> 起草 2026-09-19 ｜ 起草人 吕建江 ｜ 前置：实现 PR #30（提供被压测与被测安全行为的服务）

## Why

- 课程两项非功能要求（性能 95% < 500ms、安全鉴权与不泄露）**必须有可出示的证据**，「只写已实现不算」（契约三 §4、handbook §9）。看板任务 10 已置「进行中」，Sprint 0 于 9/25 结束。
- 证据的载体是**脚本 + 输出**：压测要 100 次请求并输出分位数（不是平均值），安全要两组用例跑出留证。没有脚本，答辩当场拿不出东西。
- 压测靶子必须是 `POST /api/predict`（契约三 §4 明示「不要拿查询接口代替」），该接口随 #30 交付；安全行为（40100/40001/50000 掩码）亦由 #30 实现。

## What Changes

- **新增 `nfr-evidence` 能力**：`backend/scripts/perf_loop.py`（循环 100 次请求 `POST /api/predict`，输出 p50/p95/p99 与最大值，标注目标 p95<500ms）与 `backend/scripts/security_cases.py`（两组安全用例：缺失/错误令牌 → 401+40100；畸形参数 → 40001 且响应不含堆栈/SQL/路径；附 50000 掩码断言）。
- **证据进仓库**：每次运行产出 `backend/scripts/evidence/<日期>-<主题>.md`（含日期、模型来源标注、命令、关键输出），提交版本控制（handbook §9 允许放 `backend/`）。
- **占位模型政策**：真 `.pkl` 未交付前，压测用本地训练的小决策树占位（14 维特征、pickle 进临时 MODEL_DIR），证据**显式标注「占位模型」**；真 `.pkl` 交付后重跑并追加新证据、旧证据保留不删（change 更新提交）。
- 脚本为**独立 HTTP 客户端**（仅依赖 httpx 与环境变量 BASE_URL/API_TOKEN），不 import 应用代码 —— 提案与脚本的评审/合入不与 #30 串联；运行证据在本地对 feat 服务生成并标注构建来源。

**不做什么（显式列出）**

- **不改**接口实现与契约（本 change 只验证、不改动被验对象）
- **不做**限流证据（MVP 不实现限流，已知边界登记在设计文档第五章）
- **不用**查询接口代替压测靶子（契约三 §4 明示）
- **不删**旧占位证据（保留标注、追加真跑证据，留演进痕迹）

**是否触及 `docs/sprint0-scope.md` 的边界**：**不触及**。证据属课程非功能要求的验证层，不改变系统定位与四条线边界。
