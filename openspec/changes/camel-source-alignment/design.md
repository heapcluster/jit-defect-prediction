1. 保持上游选定的 tag/commit，避免再换版本使已产出的 8 模型证据失效。使用官方 `git ls-remote` 的 peeled tag 核验完整提交。
2. 登记基准来自 `866b7dc` 中的 `commit_extract_stats.md` 与 `szz_labeling_stats.md`；既有报告中错误的 AMQ/None 文案只做透明勘误，保留原始统计与耗时，不伪造重跑。
