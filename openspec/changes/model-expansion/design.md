# 设计：模型覆盖补齐

## 上下文

- 首 change 已交付 3 个经典模型（`lr_v1` / `rf_v1` / `xgb_v1`）与两类指标，链路可复现（固定种子 42、时间序切分、`.pkl` 导出）。
- 课程要求「至少 2 类（经典机器学习、深度学习）不少于 8 种」，现状 1 类 3 种。
- 评估侧已发现「排序口径」问题（`risk_score` 降序 vs 风险密度降序），需要校准与阈值证据支撑契约提案（Issue #37 / #38）。

## 决策

### 决策一：两个类别的划分口径

| 类别 | 本 change 的判定 | 本 change 的模型 |
|---|---|---|
| 经典机器学习 | 线性 / 树 / 概率 / 实例四族 | `lr`（线性，已有）、`nb`（概率生成式）、`dt`（单树）、`rf`（Bagging 树）、`xgb`（Boosting 树，已有）、`knn`（实例式） |
| 神经网络（深度学习） | 多层非线性网络，误差反向传播训练 | `mlp`（1 隐藏层，32 单元）、`mlp_deep`（3 隐藏层 64/32/16 + 早停） |

**为什么 MLP 算深度学习类**：多层感知机是最小的「深层」网络 —— 含隐层、非线性激活、由反向传播与梯度下降联合训练全部参数。课程把两类并列时，区分点在「是否用神经网络」，不在「是否用了某个框架」。**因此本 change 的两个神经网络模型各取一种深度**（浅层 1 隐层 / 深层 3 隐层 + 早停），而不是「同一模型换超参凑两个」。

### 决策二：为什么不做 LSTM / RNN（重开条件）

要跑序列模型，需要**先有序列**：

| 缺什么 | 具体是什么 | 工作量级 |
|---|---|---|
| 序列化数据集 | 按时间窗把提交切成片段，每片段成为样本（当前样本粒度是单提交） | 新增一个数据工程步骤（`04` 之后） |
| 未冻结的输入口径 | 窗口长度、片段内特征聚合方式（均值 / 末值 / 拼接）、片段间重叠策略 | 需要新契约或契约补充，且要重算全量 |
| 运行依赖 | PyTorch 或 TensorFlow（当前环境未装） | 按 `AGENTS.md` 第五节属「新增依赖」，必须先问 |

三条都不在「补齐覆盖」的射程内，故 **不在本 change 做**。**重开条件**：若课程/老师明确要求「用深度学习框架实现的序列模型」，则另开 change `model-sequence`，其前置是「序列化数据集」的规格与口径冻结。本 change 在报告里显式登记这一边界，避免答辩时被当成遗漏。

### 决策三：校准必须走时间序交叉验证

概率校准（isotonic / Platt）内部要做交叉验证，**默认的随机 `KFold` 会破坏时间序**：训练折里混进了未来提交，校准曲线会被乐观偏差污染。故统一用 `TimeSeriesSplit`，折间保持时间先后 —— 这是红线第 1 条（禁止随机切分）在校准环节的延伸。

### 决策四：交付模型不变，新模型只进评估矩阵

后端线的加载路径与 `models/feature_order.txt` 属于跨线接口，本 change **不动**：

- 交付模型仍是 `xgb_v1`（首 change 已交付、已签收口径），`07_predict_all.py` 不改；
- 新模型只产出评估指标，**不进** `[models]` 段；
- 若评估矩阵显示某新模型显著更优，登记为**「模型切换」提案**（另开 change，需同时评估后端加载与契约影响），**不在本 change 静默切换** —— 静默换模型会让「已交付的 `prediction_result.csv` 是哪来的」说不清。

### 决策五：8 种模型沿用同一份切分与同一套口径

模型数量增加，最容易出的偏差是「为了某个模型好看而顺手改口径」（改特征、改切分、调 `feature_version`）。本 change 锁死三条：

1. 训练/检验集只取 `data/` 既有时间序切分产物（`split_szz_train.csv` / `split_szz_test.csv`），不重新切分；
2. 14 项特征列序照契约二第三节，不改计算与取值口径；
3. 随机种子统一固定（`--seed 42`），且写进报告。

**可核对性**：既有 3 个模型在本 change 下重跑，指标必须与 `reports/model_metrics.md` 逐项一致 —— 这是「口径没被动手脚」的自证。

## Risks

| 风险 | 影响 | 处置 |
|---|---|---|
| 神经网络在表格特征上收益有限，反而拖低「补齐」的说服力 | 答辩被问「加神经网络有意义吗」 | 报告按类给出对照并如实说明优劣；**覆盖达标**是课程要求，**指标更好**不是本 change 的目标 |
| 模型数变多，矩阵报告可读性下降 | 评审成本上升 | 矩阵报告只放「每模型一行 + 每类最优一行」，明细计算口径沿用 `06` 文件头（不重复抄一遍） |
| 校准结论被当成契约结论 | 越权改契约 | 规格 R5 明确：证据交提案决策，`MUST NOT` 在本 change 内改契约三语义 |
| 训练耗时上升（MLP 迭代 + 8 模型） | 复现成本 | 单次全量 8 模型在本机分钟级；复现命令登记在 `docs/data-pipeline.md` |
