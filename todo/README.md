## 分配原则

- 按能力分配：代码与单元测试归蛋神的蛋；集成/系统/验收/调度与项目管理（周报/看板/讨论）归 neon；仓库 docs/ 治理（断链/规范/OpenSpec 归档）归 sober；飞书《产品需求文档》《产品设计文档》维护与统稿归 lsh；公开数据集/Demo/原型归 lsh。
- 一份任务只有一个负责人，不重叠；跨人依赖写在"依赖与前置"里。
- 未完成项才进本目录，已完成项不重复。

## 完成定义（DoD）

- 每项任务有交付物与可核对的验收标准。
- `openspec/changes/*/tasks.md` 勾选必须有证据支撑，不"勾了就算完成"。
- 归档 change 后 `openspec/specs/` 与当前产品一致。
