# 蛋神的蛋-2 单元测试

> 负责人：蛋神的蛋｜优先级：P0｜关联：测试实践 25 分

## 一句话任务

对你写的核心代码做「正常 / 边界 / 异常」三例单元测试，保证能独立跑通；覆盖率报告由 CI 产出、sober 归档，你**不需要留存截图**。

## 为什么做

课程测试考核里单元测试占 25 分。单测由写代码的人做最合适——你最清楚边界和异常在哪。

## 你要做什么

1. **圈核心函数**：后端——鉴权（40100）、参数校验（40001）、风险概率范围 `[0,1]`、14 维特征顺序；前端——纯函数与工具方法；模型线——SZZ 标签 0/1/null、时间序切分、Effort 边界。
2. **每题三例**：每个核心函数至少正常、边界、异常各一条。
3. **断言到位**：断言业务结果（错误码、概率范围、字段一致），禁止 `assert True` 或只判断"没抛错"。
4. **隔离外部依赖**：数据库、模型文件、第三方接口用 Mock/Stub。
5. **本地跑通**：`cd backend && python -m pytest -q`、`npm run test:unit`、`python -m pytest`（data_model）一键能过。
6. **AI 合规**：AI 生成的用例标 `[AI生成]` / `[AI生成-人工修改]` / `[手写]`，保留 Prompt，核心断言人工复核。

## 交付物

- 测试代码（`backend/tests/`、`frontend/tests/`、`data_model/tests/`）。
- 本地跑通结果（自测通过即可，不需截图归档）。

> 说明：覆盖率 HTML/PDF 报告由 CI 的 `pytest-cov` 产出、**sober** 归档；你只需保证测试代码本身达标、能跑通。

## 什么算合格（验收清单）

- [ ] 每个核心函数有正常/边界/异常三例，断言精准。
- [ ] 本地一键可跑、无 flaky、单例 <1 分钟。
- [ ] 外部依赖已隔离，不直连真实库/网络。
- [ ] AI 来源逐条标注、Prompt 已留、核心断言经人工复核。
- [ ] 覆盖率达标（行 ≥80%、分支 ≥70%）以 CI 报告为准。

## 不要做什么

- 不改产品逻辑（发现问题自己修）。
- 不整理测试文档、不归档截图（归 sober / neon）。

## 依赖与协作

- 覆盖率与测试文档归档找 **sober**；接口/系统测试找 **neon**。
