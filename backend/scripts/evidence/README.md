# 证据目录约定

- **顶层只放「每类最新一份」证据** —— 要引现行口径，只看本目录顶层。
- **`archive/` 放被取代的历史证据** —— 仅作历史基线保留，**不得再引**（除非明确要追溯某个历史数字）。
- 判定「被取代」的依据是证据文件自己的声明（如「已作废 …，不得再被引用」「旧文件保留为历史基线，不覆盖、不倒填」），或同类已有更新的一份。
- **不删文件**：历史证据一律 `git mv` 进 `archive/`，不删除、不原地改写数字（遵守「另出文件、不倒填」）。新一次实测**另出新文件**，不倒填旧文件。
