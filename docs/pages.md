# 页面 ↔ 接口 ↔ 字段 映射

> 状态：草案，待确认 ｜ 版本 1.0 ｜ 创建 2026-09-16 ｜ 维护 刘帅华 ｜ 审核 吕建江、蒋励

## 0. 这份文档管什么、不管什么

**管**：三个页面分别用哪个接口、每个页面元素取自响应里的哪个字段、三态与错误码怎么处理。这是**前后端联调的唯一依据**。

**不管**：线框、配色、间距、组件细节、页面交互流程 —— 那些是设计内容，在**飞书《产品需求文档》六、交互原型图**。仓库不重复一份。

低保真是有意为之：先把「数据从哪来」对齐，再做视觉。信息结构没定就去做视觉，改一次等于重做一次。

| 页面 | 接口 | 本文档章节 |
|---|---|---|
| 风险列表 | `GET /api/commits` | 第 2 节 |
| 提交详情 | `GET /api/commits/{commit_hash}` | 第 3 节 |
| 缺陷引入趋势看板 | `GET /api/trends` | 第 4 节 |

**只有三个页面。** 第四个页面（模型管理、用户设置之类）不做 —— 见 `docs/sprint0-scope.md` 第 3 节。

接口细节（参数、响应结构、错误码表）一律以 `docs/contracts/api-format.md` 为准。

## 1. 三页共用的约定

1. **字段名与契约完全一致**，前端不做改名或驼峰转换：后端给 `risk_score`，前端变量就叫 `risk_score`。改名是联调事故最常见的来源。
2. **概率一律由前端转百分比显示**。后端返回 `0.0` ~ `1.0` 的小数，不返回 `"85%"` 这种字符串。
3. **时间**：接口返回 ISO 8601 带时区，前端转成本地时区展示。
4. **响应包络统一** `{ "code": 0, "message": "ok", "data": {...} }`，前端只判 `code === 0`。
5. **技术栈**：Vue 3 + Element Plus + ECharts（图表统一 ECharts，不混用其他图表库）。

## 2. 页面一：风险列表

**接口** `GET /api/commits` ｜ **回答的问题**：哪些提交最该先看？

| 页面元素 | 来源 | 说明 |
|---|---|---|
| 模型下拉 | 请求参数 `model_name` | 选项来源见第 6 节待确认第 1 条 |
| 最低风险输入 | 请求参数 `min_risk` | `0.0` ~ `1.0` |
| 时间范围 | 请求参数 `start_time` / `end_time` | 提交前转成 ISO 8601 |
| **风险** | `items[].risk_score` | **前端 × 100 转百分比**，保留一位小数 |
| 提交哈希 | `items[].commit_hash` | 列表只显示前 8 位，悬停显示全量；点击可复制 |
| 作者 | `items[].author_name` | — |
| 提交时间 | `items[].committed_at` | 转本地时区 |
| 提交信息 | `items[].message` | 单行截断，悬停显示全文 |
| 总数 | `total` | — |
| 分页控件 | `page` / `size` | 默认 20，上限 100 |

**接口没有的字段不要画在页面上。** 需要新字段就先改契约，不要前端自己造（例如「本次预测是否命中真实标签」目前接口不返回 —— 见第 6 节待确认第 3 条）。

**排序**：MVP 固定按 `risk_score` 降序（契约已规定「从高到低」），不开放自定义排序。

**跳转**：点击整行跳转提交详情，路由带 `commit_hash`。

## 3. 页面二：提交详情

**接口** `GET /api/commits/{commit_hash}` ｜ **回答的问题**：这一次提交为什么被判为高风险？

| 页面元素 | 来源 | 说明 |
|---|---|---|
| 风险值 | `risk_score` | 前端 × 100 转百分比 |
| 风险等级标签 | 前端按阈值判定 | 阈值见第 5 节，**只定义一处** |
| 模型版本 | `model_name` | 显示原值，如 `xgb_v1` |
| 提交哈希 | `commit_hash` | 全量显示，点击复制 |
| 作者 | `author_name` | — |
| 提交时间 | `committed_at` | 转本地时区 |
| 提交信息 | `message` | 全量显示，不截断 |
| 风险解释条 | `explanation[].feature` / `.contribution` / `.direction` | 见下方约定 |
| 特征值 | `features.*` | 按五个维度分组，11 + 3 项全显示 |

### 风险解释的显示约定

- 每条读作「**这个特征把风险推高了 / 降低了多少**」：`direction = "increase"` 向右，`"decrease"` 向左
- 排序按 `|contribution|` 降序，页面只显示前 8 项（接口返回全部，多出的折叠）
- **不显示 `contribution` 的绝对值含义解释**（SHAP 值还是特征重要性，由模型线定），页面只说「推高 / 降低」

### 特征值分组（按契约的五个维度，不自造维度名）

| 分组标题 | 字段 |
|---|---|
| 代码分布 | `ns` `nd` `nf` `entropy` |
| 规模 | `la` `ld` `lt` |
| 目的 | `fix` |
| 历史 | `ndev` `age` `nuc` |
| 开发者经验 | `exp` `rexp` `sexp` |

| 情形 | 处理 |
|---|---|
| 特征值为 0 | 照常显示 `0`，**不隐藏** |
| 特征字段缺失 | 显示 `—`。**这是链路出问题的信号，要让它可见**，不要静默当成 0 |

> `features` 的键名必须与 `docs/contracts/feature-columns.md` 完全一致 —— 页面上要把 `explanation[].feature` 的值拿去 `features` 里取值，键名不一致会取不到，表现为解释条显示空白。**这是本页最容易静默出错的地方。**

## 4. 页面三：缺陷引入趋势看板

**接口** `GET /api/trends` ｜ **回答的问题**：风险随时间怎么变？

| 页面元素 | 来源 | 说明 |
|---|---|---|
| 粒度选择 | 请求参数 `granularity` | `week`（默认）/ `month` |
| 模型选择 | 请求参数 `model_name` | 选项来源同列表页待确认项 |
| 时间范围 | 请求参数 `start_time` / `end_time` | ISO 8601 |
| 折线（y） | `series[].avg_risk` | 平均风险，0.0 ~ 1.0；**前端可直接按 0~1 画轴，不必转百分比** |
| 折线（x） | `series[].period` | 形如 `2026-W30`，按原样显示 |
| 汇总：提交总数 | `series[].commit_count` 求和 | 区间内合计 |
| 汇总：高风险提交 | `series[].high_risk_count` 求和 | 前端求和 |
| 汇总：平均风险 | `series[].avg_risk` 加权平均 | 权重用 `commit_count`，**不要简单取算术平均**（各周期提交数不同，算术平均会失真） |
| 明细表 | `series[]` 全字段 | 与图上数据点一一对应 |

> **「高风险」的口径只有一处定义：** 后端返回 `high_risk_count`（阈值 `risk_score ≥ 0.5`）。**前端不再自己按 `avg_risk` 或阈值重算** —— 两处各算一次，数字对不上时无法解释。

| 情形 | 处理 |
|---|---|
| 悬停数据点 | tooltip 显示该周期的 `period` / `commit_count` / `avg_risk` / `high_risk_count` |
| 点击数据点 | 跳转风险列表页，时间范围自动收窄到该周期（用 query 参数带回） |
| **数据点少于 2 个** | **不画折线**，只显示明细表 + 提示「数据点不足，无法绘制趋势」 |

## 5. 三态与错误码（三页共用）

| 情形 | 页面表现 |
|---|---|
| 加载中 | 表格骨架屏 / 图表区 loading 占位，**容器高度保持不变**（否则加载完页面会跳） |
| 空数据 | 列表：「当前筛选条件下没有提交」+「清空筛选」；趋势：「所选时间范围内没有数据」+「重置时间范围」。**空数据不是错误** |
| `40001` 参数非法 | 指出是哪个参数（例：`size` 超过 100、`granularity` 取值非法） |
| `40100` 未通过鉴权 | 提示令牌失效 / 需重新登录，**不给「重试」按钮**（重试无用） |
| `40400` 目标不存在 | 「该提交不存在」+「返回列表」按钮。**不显示服务端 message 原文** |
| `50000` 服务内部错误 | 「服务异常，请稍后重试」+ 重试按钮。**不显示堆栈、SQL、路径，也不显示 message 原文** |
| `explanation` 为空数组 | 显示「该模型未提供特征解释」并保留特征值区域 |

**风险着色阈值只在下面这一处定义**，三个页面统一使用：

| 区间 | 表现 |
|---|---|
| `≥ 0.5` | 高风险，深色警示 |
| `≥ 0.3` | 中等风险 |
| 其余 | 常规 |

- [ ] **本页要不要显示「模型这次判对了没有」？** 若要，`prediction` 表需要增加真实标签回填字段（见 `docs/contracts/data-fields.md` 待确认） —— 待刘帅华定
- [ ] `explanation` 的具体算法（SHAP / 特征重要性）由模型线确定后回填，展示形式可能随之调整
