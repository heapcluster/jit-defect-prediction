# 模型训练页（Train）

功能④　顶级 tab「模型训练」　路由 `/train`　步骤 01–05

一句话：选数据源、选算法与超参、切分训练 / 验证 / 测试、异步训练并对比效果，最后下载或保存模型与测试集。

## 1 页面定位

- 入口：顶级「模型训练」，登录后可用。
- 出口：模型文件（`.pkl` / `.pt`）下载与保存、测试集导出与保存。
- 上游：本人已保存的收集 / 清洗 / 导入清洗结果（不含测试集），或符合字段契约的 CSV / Excel。
- 不负责：数据收集、清洗、预测、解释；不修改数据集与模型文件。

## 3 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 页头 · 重置 | 清空本页进度与未保存产物 | 二次确认；已保存资产不受影响 |
| 01 数据源 | 导入文件 / 已保存的收集或清洗结果二选一 | 切换来源清空已选；导入后立即校验表头并识别模型线；失败给出第一处不符列 |
| 01 识别结果 | 模型线、行数、正负样本、时间范围 | 缺列、多列、列序不符时指出第一处不符列；识别失败不显示默认值，直接禁用下一步 |
| 02 算法表 | 名称、类别、超参 | 只列当前模型线的可训练算法；默认全部不勾选；超参来自 `数据库/algorithm.md` 固定清单，可改；至少选 1 个 |
| 03 切分 | 方式单选 + 三段比例 | 时间序与比例互斥；三个比例均 > 0 且合计 100；比例变化即时刷新预览 |
| 04 训练 | 开始 / 取消、进度、当前模型、任务表 | 运行中禁止改 01–03；`total` 为算法数；失败算法单独标红 |
| 05 指标表 | 训练与验证指标 | 缺类导致无法计算的指标显示 `—`，不填 0 |
| 05 图表 | 柱状图 / 雷达图 | 柱状图按选中指标对比训练与验证；雷达图固定 P / R / F1 / AUC / MCC |
| 05 模型卡 | 模型名、验证指标、下载、保存勾选 | 未保存也可下载；保存勾选只对成功的模型生效 |
| 05 测试集 | 文件名、导出、保存勾选 | 导出 CSV / Excel；保存后成为 `split` 数据集 |
| 保存资产 | 保存选中模型与测试集 | 未勾选任何项时禁用；保存失败保留当前结果可重试，已成功的模型 / 测试集不重复保存 |

## 4 主流程

1. 选择导入文件或已保存的收集 / 清洗结果，确认识别出的模型线与样本统计。
2. 勾选算法并调整基础超参；默认全部不勾选，由用户自行选择。
3. 选择切分方式，填写三段比例，确认预览行数。
4. 点击「开始训练」，页面锁定 01–03，进度按算法推进并显示当前模型。
5. 训练结束后查看指标表与图表，切换指标对比不同算法。
6. 下载需要的模型文件与测试集，或勾选后保存为个人资产。
7. 点击「重置」开始新一轮，未保存的模型与测试集被丢弃。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 数据源为空 | 03–05 禁用，提示先选择数据 |
| 表头不符 | 01 显示第一处不符列与期望值，禁用后续步骤 |
| 模型线无法识别 | 提示只支持 14 维专家特征或 768 维语义特征 |
| 比例非法 | 就地标红并禁用开始按钮，不发请求 |
| 某段缺类 | 指出缺少正样本或负样本的段，禁用开始按钮 |
| 训练中 | 显示进度、当前模型与已用时间；可取消 |
| 部分失败 | 成功模型正常展示，失败模型标红并给出原因，可保存成功部分 |
| 全部失败 | 任务失败，05 不展示模型卡，保留失败原因 |
| 取消 | 二次确认；取消后结果区清空，不可保存 |
| 保存被拒 | 显示原因（结果已丢弃），保留当前结果供重试 |
| 鉴权失效 | 禁用训练、下载与保存，提示重新登录 |
| 接口失败 | 显示可读原因与重试，不用空数据冒充成功 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 导入并校验文件 | `POST /api/train/import` |
| 已保存数据集校验与预览 | `POST /api/train/precheck` |
| 启动训练 | `POST /api/train/run` |
| 任务进度 | `GET /api/jobs/{job_id}` |
| 取消训练 | `POST /api/jobs/{job_id}/cancel` |
| 训练结果与指标 | `GET /api/train/results/{job_id}` |
| 下载模型 | `GET /api/train/outputs/{job_id}/{name}` |
| 导出测试集 | `GET /api/train/results/{job_id}/test-set/export` |
| 保存模型与测试集 | `POST /api/train/save` |
| 页面进度 | `GET/PUT /api/page-state/train` |

字段、错误码与请求体以 [`../接口/train.md`](../接口/train.md) 为准。

## 7 响应式与可访问性

- ≥900px：01–03 单列卡片，算法表全宽，05 指标表与图表左右并列。
- 768–899px：图表位于指标表下方，模型卡两列。
- <768px：模型卡单列，比例输入三列压缩为两行，按钮整行；表格横向滚动不压缩列。
- 图表提供文字摘要（最佳算法与指标值），不只依赖颜色区分模型。
- 运行中通过 `aria-live` 播报当前模型与进度变化。

## 8 验收

- [ ] 顶级出现「模型训练」，路由 `/train`，未登录跳登录页。
- [ ] 导入文件或选择数据集后显示模型线、行数与正负样本；表头不符时指出第一处不符列。
- [ ] 算法列表只出现当前模型线的可训练算法，默认全部不勾选；勾选后可修改超参。
- [ ] 时间序与比例互斥；比例合计不为 100 时禁止开始。
- [ ] 任一段缺少正样本或负样本时开始按钮禁用，并指出缺失的段。
- [ ] 训练进度按算法数推进并显示当前模型名；取消后结果清空且不可保存。
- [ ] 单个算法失败不阻断其余算法；全部失败时任务失败。
- [ ] 训练完成后指标表同时展示训练与验证指标，柱状图与雷达图可切换。
- [ ] 模型文件可直接下载，扩展名与算法一致（`.pkl` / `.pt`）；测试集可导出 CSV / Excel。
- [ ] 勾选保存后，模型与测试集出现在数据存储页，测试集带父数据集关系。
- [ ] 刷新页面或重新登录后，本页进度与结果可恢复；点「重置」后清空。
- [ ] 375px 下无横向溢出，训练、取消与保存操作可完成。
