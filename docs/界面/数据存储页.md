# 数据存储页

路由 `/storage`　需登录　管理页，不使用步骤编号

## 1 定位

- 目标：当前用户唯一的数据与配置中心。
- 入口：登录后默认进入；页头提供登出。
- 出口：下载数据集与模型、查看数据集成员、删除数据集或模型、保存个人配置。
- 不负责：收集、清洗、训练、预测；不提供导入与上传入口。

## 2 页面结构

```text
数据存储　当前用户 [用户名] ｜ 数据集 N ｜ 模型 N ｜ 最近登录 [时间]　[登出]
[ 我的文件 ] [ 算法库 ] [ 我的配置 ]
──────────────────────────────（页头分隔线）

── 我的文件 ──────────────────────────────
统计：数据集 N ｜ 模型 N
筛选：类型 [ 全部 ▾ ]  标签 [ 全部 ▾ ]  状态 [ 全部 ▾ ]  搜索 [        ]   [ 刷新 ]
表：名称 | 类型 | 标签 | 来源任务 | 生成时间 | 状态 | 操作（查看 / 下载 / 删除）

── 算法库 ────────────────────────────────
筛选：模型线 [ 全部 ▾ ]  搜索 [ 算法名 ]

── 我的配置 ──────────────────────────────
预估黄色提醒 [ 10 ] 分钟   预估红色提醒 [ 30 ] 分钟

```

## 3 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 页头 | 当前用户名、数据集与模型数量、最近登录 | 用户名与统计来自会话；不可编辑 |
| 区域切换 | 三个区域，对应 `section` 参数 | 默认「我的文件」；`/settings` 进入「我的配置」 |
| 统计行 | 数据集与模型数量 | 数据来自真实接口；读取失败显示 `—` |
| 筛选栏 | 类型、标签、状态、关键字 | 类型固定为数据集 / 模型；标签对数据集为 `source_type`（原始 / 导入清洗 / 清洗 / 测试集 / 预测结果），对模型为模型线（`expert` / `semantic`）；筛选变化回到第一页 |
| 资产表 | 名称、类型、标签、来源任务、生成时间、状态、操作 | 按生成时间倒序；数据集下载可选文件名与 CSV / Excel 格式，模型按产物格式下载 `.pkl` / `.pt`；数据集与模型都可独立删除 |
| 查看抽屉 | 普通数据集看元数据与成员；prediction 数据集看预测结果七列；模型看算法、指标与文件 | 只读；结果表分页；prediction 数据集额外提供「查看结果」跳转预测详情 |
| 算法表 | 算法、模型线、类别、可训练、说明 | 只读，无编辑入口 |
| 配置表单 | 两项耗时阈值 | 数值输入，黄色必须小于红色；保存后立即生效 |

## 4 主流程

### 4.1 浏览与下载

1. 进入「我的文件」，默认看到全部资产。
2. 按类型、状态或关键字筛选。
3. 点击「查看」打开抽屉；数据集看元数据与成员，模型看算法、指标与文件。prediction 数据集显示 `commit_hash`、`commit_message`、`author_name`、`commit_time`、`bug`、`risk_score`、`predicted_label` 七列，并可「查看结果」进入 `/predict/{job_id}/commit/{commit_hash}`。
4. 点击「下载」：数据集弹出文件名与格式（CSV / Excel）；模型直接下载对应格式（`.pkl` / `.pt`）。prediction 数据集导出时提交列名为外部契约 `commit_id`。

### 4.2 删除数据集或模型

1. 点击「删除」，二次确认展示名称；数据集展示样本数，模型展示算法。
2. 删除只影响当前资产：数据集删除记录、成员与本数据集 `temp/datasets/<id>/` 目录，prediction 数据集同时删除预测明细；派生数据集的来源显示「来源已删除」，模型的数据集引用置空，不级联删除其他资产。
3. 成功删除后刷新列表与统计。

### 4.3 修改配置

1. 切到「我的配置」，读取已保存值。
2. 修改阈值后保存；黄色不小于红色时就地报错，不提交。
3. 保存成功后重开页面仍为保存值。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 空库 | 表格空态，说明保存的数据集与模型会显示在这里，并给出“去收集”入口 |
| 加载中 | 统计与表格骨架 |
| 筛选无结果 | 空态说明当前筛选条件 |
| 删除失败 | 显示可读原因（不存在、网络失败），资产保留 |
| 配置读取失败 | 显示错误与重试，不用默认值冒充 |
| 鉴权失效 | 跳登录页 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 资产列表 | `GET /api/storage/files` |
| 数据集详情与成员 | `GET /api/datasets/{id}?page=&page_size=`（prediction 数据集返回预测结果七列） |
| 删除数据集 | `DELETE /api/datasets/{id}` |
| 删除模型 | `DELETE /api/models/{model_name}` |
| 资产下载 | `GET /api/storage/files/{id}/download` |
| 算法清单 | `GET /api/algorithms` |
| 配置读写 | `GET /api/config`、`PUT /api/config` |
| 当前用户 | `GET /api/auth/me` |

## 7 响应式与可访问性

- ≥900px：三个区域横排；统计一行多格。
- 768–899px：统计折行，筛选压缩，表格内部滚动。
- <768px：单列；表格横向滚动不压缩列；配置表单整行。
- 抽屉打开后焦点进入，关闭回到触发行。

## 8 验收

- 页头显示当前用户名、数据集与模型数量、最近登录。
- 页面不出现任务链路区域。
- 只显示当前用户的数据集、模型与配置。
- 数据集或模型可独立删除；删除后不级联删除其他资产。
- 算法库只读，无编辑入口。
- 配置只出现两项阈值；保存后刷新仍为保存值；阈值倒置时不能保存。
- 页面不存在导入或上传入口。
- 375px 无横向溢出。
