# 预测详情页（Predict Detail）

功能⑤ 子页　路由 `/predict/{job_id}/commit/{commit_hash}`　归属模型预测

一句话：查看单条提交的预测信息、可切换的 XAI 解释，以及有源码时的缺陷定位与修复建议。

## 1 页面定位

- 入口：预测结果表点击任意行；保存后的预测数据集在数据存储页抽屉点击「查看结果」进入。
- 出口：无；解释与定位只读。
- 依赖：预测任务结果；解释需要模型文件，定位需要仓库来源。
- 不负责：重新预测、修改阈值、保存资产。

## 3 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 01 预测信息 | 提交、模型、阈值、概率、标签 | 只读；真实标签仅在有 `bug` 列时显示 |
| 02 解释切换 | SHAP / LIME / 置换重要性 | 专家线三种；语义线无 SHAP；切换后按需计算 |
| 02 贡献表 | 特征、贡献值、方向 | 按绝对值降序，专家线显示全部 14 项，语义线显示前 10 维 |
| 02 贡献图 | 横向条形图 | 专家线显示；语义线只显示表 |
| 03 文件列表 | 变更文件与可疑度 | 按可疑度降序；点击展开 diff |
| 03 diff | 上下文行、新增/删除行 | 可疑行高亮；行号与实际文件一致 |
| 03 修复建议 | 规则模板建议 | 按关键字类别生成；不调用外部模型 |
| 无源码 | 提示文案 | 外部导入数据集显示，不展示伪造定位 |

## 4 主流程

1. 从预测结果表进入，先看到预测信息。
2. 在解释区选择技术，等待计算后查看贡献表与图。
3. 下滑到定位区，查看变更文件与可疑行；展开 diff 核对上下文。
4. 阅读修复建议；无源码时只看到提示。
5. 点击「返回预测结果」，回到原列表与原有筛选。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 加载中 | 预测信息骨架；解释区显示计算中 |
| 解释失败 | 显示原因与重试；模型未保存或文件缺失时提示「模型不可用」，不显示空图 |
| 技术不可用 | 语义线隐藏 SHAP 并说明原因 |
| 无源码 | 定位区显示"外部导入数据集不支持定位" |
| 提交不在缓存 | 显示"仓库缓存缺少该提交"，不伪造 diff |
| 结果已丢弃 | 提示结果已失效，返回列表并刷新 |
| 鉴权失效 | 整页只读提示重新登录 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 预测详情 | `GET /api/predict/results/{job_id}/commits/{commit_hash}` |
| 解释 | `POST /api/predict/explain` |
| 定位与修复建议 | `POST /api/predict/localize` |

请求体与错误码以 [`../接口/predict.md`](../接口/predict.md) 为准。

## 7 响应式与可访问性

- ≥900px：解释与定位上下排列，贡献图与表左右并列。
- <768px：贡献图收起为表格；diff 横向滚动并保留行号列。
- 可疑行同时用图标与文字标注"可疑"，不只依赖背景色。
- 解释切换使用 tab 键盘导航；返回按钮固定在页头。

## 8 验收

- [ ] 从结果表点击任意行可进入详情页，显示提交、模型、阈值、概率与预测结果。
- [ ] 有标签时显示真实标签，无标签时不显示该行。
- [ ] 专家线可切换 SHAP / LIME / 置换重要性；语义线不出现 SHAP。
- [ ] 切换技术会重新计算，刷新页面后不保留上次解释。
- [ ] 有仓库来源时可展开 diff，可疑行有文字标注与行号。
- [ ] 修复建议按可疑行给出，不出现与代码无关的通用文案。
- [ ] 外部导入数据集显示"不支持定位"，不展示伪造的源码或建议。
- [ ] 仓库缓存缺少提交时给出明确提示。
- [ ] 返回后预测结果页保持原有筛选与分页。
