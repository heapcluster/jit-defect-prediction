# 数据清洗页

路由 `/clean`　需登录　流程页，按步骤推进

## 1 定位

- 目标：对本人数据集或上传文件做清洗与预处理，观察每步变化，产出可导出的结果。
- 入口：顶级导航「数据清洗」。
- 出口：导出 CSV / Excel；保存为个人数据集。
- 不负责：收集、训练、预测；不改变列结构。

## 2 页面结构

```text
数据清洗　[ 重置 ]
──────────────────────────────────────────
01 数据来源
  (·) 选择我的数据集 [ 选择数据集 ▾ ]（收集 / 导入清洗 / 清洗结果，不含测试集与预测结果）
  ( ) 上传文件       [ 选择文件 ]  支持 CSV / Excel
  校验结果：识别为 专家线 / 语义线 ｜ 行数 N ｜ 列数 N
02 清洗与预处理
  [x] 去重        方式 [ 完全重复行 / 按提交 hash ▾ ]      [↑] [↓]
  [x] 缺失值      方式 [ 删除含缺失行 ▾ ]  目标列 [ 多选 ▾ ]
  [ ] 异常值      方式 [ IQR 截断 ▾ ]
  [x] 标签规范化
  [ ] 样本平衡    方式 [ 欠采样 ▾ ]
  [ 开始清洗 ]（未选任何操作时禁用）
03 执行与变化
  进度条 + 当前步骤 + [ 取消 ]
  步骤列表：去重 (行数 a → b) ｜ 缺失值 ｜ …
  图表：前后对比图 + 数值统计对比表
04 结果
  行数 N ｜ 正样本 N ｜ 负样本 N
  表：核心字段，分页
  文件名 [          ]  格式 (·) CSV ( ) Excel   [ 导出 ]
  名称 [          ]   [ 保存到数据库 ]
```

## 3 区域与组件

| 步骤 | 内容 | 交互与约束 |
|---|---|---|
| 01 数据来源 | 单选：我的数据集 / 上传文件 | 二选一；数据集仅含收集、导入清洗与清洗结果；切换来源清空后续配置与结果 |
| 01 校验 | 字段校验结果 | 缺列、多列、列序不符均指出第一处不符列；不通过不能进入下一步；Excel 只读第一个 sheet |
| 02 操作 | 五项操作，各带开关、参数、上移下移 | 默认顺序固定；样本平衡只提供欠采样；未选任何操作时开始按钮禁用 |
| 03 执行 | 进度、步骤列表、图表 | 每步一张前后对比图；可取消 |
| 04 结果 | 摘要、分页表、导出、保存 | 只显示核心字段；列结构与输入一致 |

## 4 主流程

1. 选择数据源：下拉选本人数据集，或上传 CSV / Excel。
2. 等待校验结果；不通过时按提示更换文件或数据集。
3. 勾选操作、填写参数、调整顺序。
4. 点击「开始清洗」，观察进度与每步变化。
5. 完成后查看结果分布与分页表。
6. 导出文件，或填写名称后点击「保存到数据库」。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 未选数据源 | 02 步不可展开 |
| 校验失败 | 指出第一处不符列（列序号、期望、实际），不允许继续 |
| 文件超限 | 选择时即拒绝，提示大小上限 |
| 未选操作 | 开始按钮禁用，并提示至少选择一项 |
| 执行中 | 进度与当前步骤；可取消 |
| 执行失败 | 指明失败步骤与原因，提供重试 |
| 单步无变化 | 该步标注“无变化”，不画空图 |
| 保存被拒 | 名称非法或结果正样本为 0，提示原因，保留结果 |
| 保存成功 | 提示已保存，数据存储页可查 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 我的数据集 | `GET /api/datasets?scope=mine` |
| 上传与校验 | `POST /api/clean/import` |
| 启动清洗 | `POST /api/clean/run` |
| 任务状态 | `GET /api/jobs/{job_id}` |
| 步骤统计 | `GET /api/clean/results/{job_id}/steps` |
| 结果分页 | `GET /api/clean/results/{job_id}/rows` |
| 导出 | `GET /api/clean/results/{job_id}/export` |
| 保存数据集 | `POST /api/datasets` |
| 页面进度 | `GET/PUT /api/page-state/clean` |

## 7 响应式与可访问性

- ≥900px：操作列表单列，参数与排序按钮同行。
- 768–899px：操作参数折行。
- <768px：按钮整行；图表高度自适应；结果表横向滚动。
- 操作开关可键盘操作；错误提示与对应字段关联。

## 8 验收

- 未选数据源时无法进入操作配置。
- 表头不符的文件被拒绝，并指出第一处不符的列。
- 未选择任何操作时开始按钮不可用。
- 执行后每一步都有前后对比图与统计，图表数值与统计表一致。
- 结果表的列名、顺序、数量与输入完全一致。
- 导出文件名可自定义，CSV 与 Excel 均可下载。
- 保存后数据存储页出现该数据集；基于已保存数据集清洗时，详情显示来源数据集。
- 同一配置重复执行覆盖原结果；覆盖不改变已训练模型与已保存预测结果。
