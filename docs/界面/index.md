# 界面

描述每个页面「长什么样、怎么交互、失败怎么表现」。不重复接口字段、错误码与表结构。

## 文件

| 文件 | 职责 |
|---|---|
| `routes.md` | 页面清单、路由、子页、重定向的唯一真源 |
| `ui-rules.md` | 跨页通用规则：加载、空态、错误、鉴权失效、响应式、可访问性 |
| `<页面>.md` | 单页的结构、区域、交互、接口映射与验收 |

## 单篇模板

定位 / 页面结构 / 区域与组件 / 主流程 / 状态与反馈 / 接口映射 / 响应式与可访问性 / 验收

## 编写规则

1. `routes.md` 是路由唯一真源；新增、改名或下线页面先改它。
2. 页面文档只写「调用哪个接口、传什么参数、拿到什么结果」，字段与错误码引用 `接口/<模块>.md`。
3. 每个操作同时写触发条件、成功反馈、失败反馈；失败反馈必须可区分网络失败、业务拒绝与鉴权失效。
4. 状态值与枚举引用 `约束/enums.md`，不在页面内自定义取值。
5. 验收条目必须能通过页面操作复现，不写“体验良好”这类不可判定的描述。
