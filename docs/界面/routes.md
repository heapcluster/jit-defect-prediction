# 路由

本文件是页面路由的唯一真源。新增、改名或下线页面先改这里。

## 1 页面路由

| 路由 | 页面 | 访问 | 说明 |
|---|---|---|---|
| `/login` | 登录页 | 公开 | 未登录时唯一可访问页面 |
| `/storage` | 数据存储页 | 需登录 | 登录后默认页；三个区域：我的文件、算法库、我的配置 |
| `/collect` | 数据收集页 | 需登录 | 仓库 + 分支 + 解析方式 → 预览 → 导出 / 保存 |
| `/clean` | 数据清洗页 | 需登录 | 选数据源 → 配操作 → 执行 → 结果 |
| `/train` | 模型训练页 | 需登录 | 数据源 → 算法与超参 → 切分 → 训练 → 结果 |
| `/predict` | 模型预测页 | 需登录 | 数据源 → 模型与阈值 → 预测 → 结果 |
| `/predict/{job_id}/commit/{commit_hash}` | 预测详情页 | 需登录 | 单条预测的解释与缺陷定位 |
| `/evaluate` | 模型评估页 | 需登录 | 预测结果 → 指标与阈值 → 评估 → 历史 |

## 2 重定向

| 来源 | 目标 | 说明 |
|---|---|---|
| `/settings` | `/storage?section=config` | 配置区兼容地址 |
| `/` | `/storage` | 已登录；未登录先跳登录页 |

- 未登录访问需登录路由，跳转 `/login`，登录成功后回到原目标。
- 已登录访问 `/login`，直接跳 `/storage`。

## 3 页面状态参数

| 参数 | 页面 | 取值 |
|---|---|---|
| `section` | `/storage` | `files`（默认）、`algorithms`、`config` |

- 页面进度不放在 URL，按用户存在服务端，见 [接口/page-state.md](../接口/page-state.md)。
