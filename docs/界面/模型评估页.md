# 模型评估页（Evaluate）

功能⑥　顶级 tab「模型评估」　路由 `/evaluate`　页面主体为新建评估，底部为历史评估；历史详情以抽屉打开

一句话：对带标签的预测结果计算所选指标、生成图表，导出指标表与 PNG，并保存评估历史。

## 1 页面定位

- 入口：顶级「模型评估」，登录后可用。
- 出口：指标表 CSV / Excel、单图 PNG、评估历史。
- 上游：本人预测结果数据集，或有标签的预测结果文件。
- 不负责：预测、训练、解释、修改预测结果。

## 3 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 历史评估区块 | 搜索、刷新、历史表 | 位于页面底部；新建结果不受影响 |
| 01 数据集 | 本人 `prediction` 数据集 | 无标签结果禁用并说明原因 |
| 01 导入 | 预测结果 CSV / Excel + 显示名 | 缺列、多列、列序不符时指出第一处不符列，空标签拒绝，均不能进入下一步 |
| 01 识别 | 模型、样本、正负、阈值 | 只读；来源为文件时模型显示"外部预测结果" |
| 02 指标 | 七个复选项 | 至少选 1 项；单类别时 AUC / AP 禁用 |
| 02 阈值 | 0–1 数值 | 默认 0.5；非法值就地报错 |
| 03 评估 | 开始 / 取消、进度 | 运行中锁定输入 |
| 04 指标表 | 指标 / 值 | 中文表头；只显示勾选项 |
| 04 图表 | ROC、PR、混淆矩阵、柱状图 | 按勾选条件生成；每图单独下载 PNG |
| 04 导出 | CSV / Excel + 文件名 | 英文列名；文件名非法就地报错 |
| 04 保存 | 保存到评估历史 | 名称默认 `evaluate-{job_id 去掉 job_ 前缀后的前 8 位}`，可改 |
| 05 历史表 | 名称、来源、模型、阈值、摘要、时间 | 按时间倒序；查看打开右侧抽屉，删除二次确认 |
| 历史详情 | 指标表与图 | 只读；可重新导出，不可重新计算 |

## 4 主流程

1. 选择预测结果数据集，或导入预测结果文件并填写显示名。
2. 勾选指标并设置阈值；单类别时 AUC / AP 不可选。
3. 开始评估，等待指标与图生成；可取消。
4. 查看指标表与图，导出指标表或单张 PNG。
5. 需要留档时保存到评估历史；之后可在历史评估中重新打开。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 无预测结果 | 01 空态，提示先到预测页生成并保存结果 |
| 结果无标签 | 数据集禁用，提示"来自无标签输入，无法评估" |
| 表头不符 | 指出第一处不符列，禁用开始 |
| 空标签 / 非法标签 | 拒绝并说明行数，禁用开始 |
| 单类别 | AUC / AP 置灰并说明原因 |
| 未选指标 | 禁用开始 |
| 评估中 | 进度按图推进；可取消 |
| 取消 | 结果清空，不可导出与保存 |
| 图片缺失 | 单图显示"生成失败"与重试，不影响指标表 |
| 保存被拒 | 重名或结果已失效，保留结果供重试 |
| 历史为空 | 显示"保存的评估会出现在这里" |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 预测结果数据集校验 | `POST /api/evaluate/precheck` |
| 导入预测结果 | `POST /api/evaluate/import` |
| 启动评估 | `POST /api/evaluate/run` |
| 进度 / 取消 | `GET /api/jobs/{job_id}`、`POST /api/jobs/{job_id}/cancel` |
| 结果 | `GET /api/evaluate/results/{job_id}` |
| 指标表导出 | `GET /api/evaluate/results/{job_id}/export` |
| 单图 PNG | `GET /api/evaluate/results/{job_id}/figures/{figure_type}` |
| 保存历史 | `POST /api/evaluate/save` |
| 历史列表 | `GET /api/evaluate/history` |
| 历史详情 | `GET /api/evaluate/history/{evaluation_id}` |
| 历史指标表导出 | `GET /api/evaluate/history/{evaluation_id}/export` |
| 历史图 PNG | `GET /api/evaluate/history/{evaluation_id}/figures/{figure_type}` |
| 删除历史 | `DELETE /api/evaluate/history/{evaluation_id}` |
| 页面进度 | `GET/PUT /api/page-state/evaluate` |

## 7 响应式与可访问性

- ≥900px：指标复选四列，图表两列。
- 768–899px：指标两列，图表单列，表格内部滚动。
- <768px：全部单列，按钮整行；图表宽度自适应。
- 图表提供文字标题与数值摘要，不只依赖图片。
- 单图下载与删除操作可用键盘完成。

## 8 验收

- [ ] 只有带标签的预测结果可选；无标签结果禁用并说明原因。
- [ ] 导入文件缺列、多列或列序不符时指出第一处不符列，不能进入下一步。
- [ ] 指标至少选 1 项；单类别时 AUC / AP 不可选。
- [ ] 阈值默认 0.5，修改后依赖阈值的指标与混淆矩阵变化。
- [ ] 只勾选部分指标时，指标表与柱状图只出现勾选项。
- [ ] ROC / PR / 混淆矩阵按触发条件生成，不生成空图。
- [ ] 指标表可导出 CSV / Excel，列名为所选指标英文名加 `threshold`。
- [ ] 每张图可单独下载 PNG。
- [ ] 保存后历史评估出现记录，可查看、重新下载与删除。
- [ ] 删除历史不影响预测结果数据集与模型。
- [ ] 375px 下无横向溢出，评估、导出与保存可完成。
