# 登录页

路由 `/login`　公开页面

## 1 定位

- 目标：用账号密码进入系统；登录后进入数据存储页或回到原目标页。
- 入口：未登录访问任意页面时自动跳转，也可直接访问。
- 出口：登录成功进入 `/storage`；已登录访问本页直接跳 `/storage`。
- 不负责：注册、找回密码、修改密码。

## 2 页面结构

```text
┌──────────────────────────────────────────────┐
│  系统名称                                     │
│  一句话说明                                   │
│                                              │
│  用户名  [                                  ] │
│  密码    [                                  ] │
│                                              │
│  [ 登录 ]                                     │
│  错误提示区                                   │
└──────────────────────────────────────────────┘
```

- 单列居中卡片，≥900px 时最大宽度固定，不铺满全屏。
- 不提供注册、第三方登录与“记住我”。

## 3 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 用户名 | 文本输入 | 必填；回车可提交 |
| 密码 | 密码输入 | 必填；不可见字符；回车可提交 |
| 登录按钮 | 提交 | 两项为空时禁用；提交中显示 loading 并禁止重复点击 |
| 错误提示 | 登录失败原因 | 凭证错误统一提示“用户名或密码错误”，不区分哪一项错 |

## 4 主流程

1. 输入用户名与密码，点击登录。
2. 成功后写入会话，跳转原目标页；无原目标则进入 `/storage`。
3. 失败时停留本页，保留用户名，清空密码，展示错误。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 字段为空 | 登录按钮禁用 |
| 提交中 | 按钮 loading，输入框只读 |
| 凭证错误 | 提示“用户名或密码错误”，清空密码 |
| 网络失败 | 提示“无法连接服务器，请重试” |
| 会话已存在 | 直接跳 `/storage`，不闪现登录表单 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 登录 | `POST /api/auth/login` |
| 当前用户 | `GET /api/auth/me` |

字段与错误码见 [../接口/auth.md](../接口/auth.md) 与 [../接口/conventions.md](../接口/conventions.md)。

## 7 响应式与可访问性

- <768px：卡片左右留 16px，按钮整行。
- 标签与输入框关联；错误提示可被读屏读取；焦点默认在用户名。

## 8 验收

- 未登录访问 `/collect` 被带到本页，登录后回到 `/collect`。
- 用户名或密码错误时提示统一文案，不透露是哪一项错误。
- 登录成功后刷新页面仍保持登录态。
- 已登录状态访问 `/login` 直接进入 `/storage`。
