# 模型预测页（Predict）

功能⑤　顶级 tab「模型预测」　路由 `/predict`　步骤 01–05

一句话：选待预测数据集与模型、设置概率阈值，批量预测缺陷概率，结果可查看详情、导出与保存。

## 1 页面定位

- 入口：顶级「模型预测」，登录后可用。
- 出口：结果表预览、单条详情、CSV / Excel 导出、保存为预测数据集。
- 上游：本人已保存数据集，或符合字段契约的 CSV / Excel；本人模型或导入的模型文件（`.pkl` / `.pt`）。
- 不负责：训练、评估指标、修改数据集或模型。

## 3 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 页头 · 重置 | 清空本页进度与未保存结果 | 二次确认；已保存资产不受影响 |
| 01 数据源 | 导入文件 / 已保存数据集（收集、清洗、导入清洗、测试集） | 切换来源清空已选；预测结果数据集不可选；校验后显示模型线、有无标签、行数 |
| 01 识别结果 | 模型线、标签情况、样本统计 | 除 `bug` 外缺列、多列、列序不符时禁用后续步骤并指出第一处不符列 |
| 02 已保存模型 | 与数据线一致的模型下拉 | 不显示其他线的模型；未选择时禁用 03–05 |
| 02 导入模型 | `.pkl` / `.pt` + 模型线声明 + 保存模型 | 特征数与声明线不一致时拒绝；`.pt` 只接受本项目导出的自包含格式；提示加载外部模型的风险；保存后可用于后续解释 |
| 03 阈值 | 0–1 数值或滑杆 | 默认 0.5；非法值就地报错 |
| 04 预测 | 开始 / 取消、进度 | 运行中锁定 01–03；取消后结果清空不可保存 |
| 05 结果表 | 七列中文表头 | 分页来自真实接口；无标签时真实标签为空 |
| 05 筛选 | 全部 / 缺陷 / 正常 | 变化回到第一页 |
| 05 导出 | CSV / Excel + 文件名 | 文件名非法就地报错；导出英文表头 |
| 05 保存 | 保存为预测数据集 | 导入模型未保存也可保存结果；若希望后续解释，先保存模型 |

## 4 主流程

1. 选择导入文件或已保存数据集，确认识别出的模型线与标签情况。
2. 选择同模型线的已保存模型，或导入 `.pkl` / `.pt` 并声明模型线。
3. 设置概率阈值，默认 0.5。
4. 点击「开始预测」，进度按行推进；可取消。
5. 结果表按七列展示，点击任意行进入详情页。
6. 导出 CSV / Excel，或点击「保存到数据库」登记为预测数据集。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 数据源为空 | 02–05 禁用 |
| 表头不符 | 01 指出第一处不符列，禁用后续步骤 |
| 模型线不一致 | 02 提示并禁用开始 |
| 导入模型失败 | 显示"无法加载模型/特征数不符"，不进入预测 |
| 阈值非法 | 就地标红，禁用开始 |
| 预测中 | 显示进度与已用时间；可取消 |
| 取消 | 二次确认；结果区清空，不可保存 |
| 保存被拒 | 名称为空或非法，或结果已失效，给出原因并保留结果 |
| 鉴权失效 | 禁用预测、下载与保存，提示重新登录 |
| 接口失败 | 显示可读原因与重试，不用空数据冒充成功 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 导入并校验数据 | `POST /api/predict/import` |
| 已保存数据集校验 | `POST /api/predict/precheck` |
| 已保存模型列表 | `GET /api/storage/files?type=model` |
| 导入模型 | `POST /api/predict/import-model` |
| 保存导入模型 | `POST /api/predict/save-model` |
| 启动预测 | `POST /api/predict/run` |
| 进度 / 取消 | `GET /api/jobs/{job_id}`、`POST /api/jobs/{job_id}/cancel` |
| 结果分页 | `GET /api/predict/results/{job_id}/rows` |
| 导出 | `GET /api/predict/results/{job_id}/export` |
| 保存资产 | `POST /api/predict/save` |
| 页面进度 | `GET/PUT /api/page-state/predict` |

字段与错误码以 [`../接口/predict.md`](../接口/predict.md) 为准。

## 7 响应式与可访问性

- ≥900px：01–03 横排，结果表全宽。
- 768–899px：01–03 两列，结果表内部滚动。
- <768px：单列，阈值输入与按钮整行；表格横向滚动不压缩列。
- 结果表提供"缺陷 / 正常"文字，不只依赖颜色。
- 详情入口可用键盘进入，返回后焦点回到原行。

## 8 验收

- [ ] 带 `bug` 与不带 `bug` 的数据集都能导入并识别模型线。
- [ ] 模型下拉只显示与数据线一致的模型；线不一致时禁止开始。
- [ ] 阈值默认 0.5，修改后预测标签随之变化。
- [ ] 结果表显示七列中文表头，分页数据来自真实接口。
- [ ] 有标签数据展示真实标签，不出现指标计算。
- [ ] 导出 CSV / Excel 使用原始英文列名与顺序，末尾追加预测三列。
- [ ] 点击行进入详情页；返回后仍在原页与原有结果。
- [ ] 保存后数据存储页出现"预测结果"数据集，每次预测独立成条。
- [ ] 导入模型未保存时结果仍可保存，模型名为空；保存模型后可用于解释。
- [ ] 375px 下无横向溢出，预测、取消与保存可完成。
