# 数据收集页

路由 `/collect`　需登录　流程页，按步骤推进

## 1 定位

- 目标：从公开仓库采集提交，按 SZZ 打标，产出可预览、可导出的缺陷数据集。
- 入口：顶级导航「数据收集」。
- 出口：导出 CSV / Excel；保存为个人数据集。
- 不负责：清洗、训练、预测；不支持私有仓库与本地文件导入。

## 2 页面结构

```text
数据收集　[ 重置 ]
──────────────────────────────────────────
01 仓库与解析方式
  仓库地址 [ https://github.com/owner/repo        ]  [ 读取分支 ]
  分支     [ 选择分支 ▾ ]
  解析方式 [ 专家特征 ]  [ 语义向量 ]
  预检：提交数 N ｜ issue 数 N ｜ 预计 X 分钟   [ 预检并估算耗时 ]
  [ 开始收集 ]（预检通过后可用）
02 执行进度（启动后出现）
  进度条 + 当前阶段 + 已用时间 + [ 取消 ]
03 结果预览（成功后出现）
  正样本 N ｜ 负样本 N ｜ 总行数 N
  表：commit_id | commit_time | author_name | bug | 前 6 项特征
  分页器
  文件名 [                  ]  格式 (·) CSV  ( ) Excel   [ 导出 ]
  数据集名称 [                  ]   [ 保存到数据库 ]
```

## 3 区域与组件

| 步骤 | 内容 | 交互与约束 |
|---|---|---|
| 01 仓库与解析方式 | 地址输入、读取分支、分支下拉、解析方式卡片、预检与开始 | 地址必须为 `github.com` / `gitee.com` 的公开仓库；host 决定平台；读取分支后清空旧预检；切换解析方式自动重新预检 |
| 02 执行进度 | 进度、阶段、已用时间、取消 | 启动后出现；运行中锁定 01；取消后本轮结果丢弃 |
| 03 结果预览 | 摘要、分页表、导出、保存 | 只显示核心字段；全量行可翻页；`bug` 只有 0/1；导出只是下载，保存按钮才写库 |

核心字段固定为：`commit_id`、`commit_time`、`author_name`、`bug`，加前 6 项特征列；完整列只在导出文件中。

## 4 主流程

1. 输入仓库地址，点击「读取分支」；成功后选择分支。
2. 选择解析方式；已选仓库与分支时切换会自动重新预检。
3. 点击「预检并估算耗时」，确认预估后点击「开始收集」。
4. 观察进度；可随时取消，取消后不产生可保存结果。
5. 完成后查看摘要与分页表，确认正负样本数量。
6. 填写文件名导出；需要留存时填写数据集名称并点击「保存到数据库」。

## 5 状态与反馈

| 状态 | 表现 |
|---|---|
| 地址非法 | 输入框下方报错，不请求分支 |
| 平台接口限流 | 提示“平台接口限流，请稍后重试（仅支持公开仓库）”，不启动任务 |
| 分支加载失败 | 下拉区显示原因与重试 |
| 预检中 | 预检卡骨架 |
| 预估超黄色阈值 | 黄色提示，说明可取消 |
| 预估超红色阈值 | 红色提示，建议缩小分支或改用其他仓库 |
| 执行中 | 进度、阶段、已用时间；禁用开始按钮；可取消 |
| 执行失败 | 展示失败阶段与原因，提供重试 |
| issue 不可用 | 明确提示“该仓库无可用的缺陷 issue 数据”，任务失败 |
| 正样本为 0 | 结果区警示，禁止直接保存为可训练数据集 |
| 取消 | 保留已产生的中间信息，不产出可保存结果 |

## 6 接口映射

| 能力 | 接口 |
|---|---|
| 分支列表 | `GET /api/collect/branches?repo_url=` |
| 预检与预估 | `POST /api/collect/precheck` |
| 启动收集 | `POST /api/collect/run` |
| 任务状态 | `GET /api/jobs/{job_id}` |
| 结果分页 | `GET /api/collect/results/{job_id}/rows` |
| 导出 | `GET /api/collect/results/{job_id}/export` |
| 保存数据集 | `POST /api/datasets` |
| 页面进度 | `GET/PUT /api/page-state/collect` |

## 7 响应式与可访问性

- ≥900px：单列流程，每步一块，块间有分隔线。
- 768–899px：预检卡字段折行。
- <768px：按钮整行；结果表横向滚动。
- 单选卡片用真实单选语义，键盘可切换。

## 8 验收

- 非 GitHub / Gitee 地址无法读取分支，并给出可读原因。
- 未完成预检时开始按钮不可用；切换解析方式后重新预检。
- 预检展示提交数、issue 数与预估耗时；超过阈值有黄 / 红提示。
- 执行中可取消，取消后没有可保存结果。
- 结果表分页展示核心字段，正负样本数与摘要一致。
- 导出文件列名与顺序符合字段契约。
- 未点击保存时刷新仍能看到结果；点击重置后结果清空。
- 点击保存后数据存储页出现该数据集，其他用户不可见。
