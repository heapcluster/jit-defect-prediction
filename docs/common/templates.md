## 1. 工作周报模板（结构不得改）

三张表，顺序固定；上方说明文字不得改；比对基线见本文件 §1（原 `docs/templates/` 已并入本文件）。

```
# 工作周报-日期

> 模板基线：weekly-report-template.md v1.0 ｜ 本周比对：六项打勾全过 ✅

## 一、本周计划
| 重要工作事项 | 状态 | 备注 |
|---|---|---|
| … | 未开始/进行中/待审阅/已完成/已延期 | … |

## 二、本周总结
| 重要工作事项 | 状态 | 证明材料 | 待改进 |
|---|---|---|---|
| … | … | 路径/链接 | … |

## 三、下周计划
| 重要工作事项 | 状态 | 备注 |
|---|---|---|
| … | … | … |
```

填法：计划细到「谁做哪件事」；总结用实测值；没做完写进「待改进」；证明材料指路径/链接（不粘全文）。

## 2. PR 模板（四件事，见 `repo/git-pr.md`）

```
## 改了什么
## 为什么改（对应 change）
## 怎么验证
## 关联编号 Closes # / change-id:
```

## 3. Issue 模板

- Bug（`type:bug`，必填五项：现象/复现条件/优先级/处理状态/关联，见 `repo/defect-management.md`）
- 任务（`type:feat`；含负责人/线/Sprint）
- 文档/规范（`type:docs`）
