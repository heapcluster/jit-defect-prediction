## 系统测试

- 定义

系统测试(system testing)是将经过集成测试的软件,作为计算机系统的一个元素，与计算机硬件、外设、数据库等其他系统元素结合起来，在实际运行环境中对被测软件系统的功能、性能等进行的一系列的测试，以发现软件中潜在的问题。

系统测试的对象不仅仅包括开发出来的软件，还包括软件运行所依赖的硬件、接口、操作系统、其它支撑软件及相关数据等。

系统测试的依据是软件需求规格说明书。通过测试验证软件系统是否符合软件规格说明书，找出与软件规格说明书不一致的地方。

- 系统测试与集成测试的区别

| 比较项目 | 集成测试 | 系统测试 |
|---|---|---|
| 测试对象 | 软件本身 | 软件及其运行环境组成 的整个系统 |
| 测试依据 | 设计说明书 | 软件规格说明书 |
| 测试方法 | 白盒测试和黑盒测试 | 黑盒测试方法 |
| 测试内容 | 侧重各模块接口及模块集成后 的功能 | 整个系统的功能、性能 等 |
| 测试人员 | 开发人员或开发人员与测试共 同完成 | 测试人员 |

- 系统测试的分类
- 功能测试

系统测试中的功能测试是指验证被测试系统是否满足软件规格说明书中所描述的功能要求。功能测试是系统测试中最基本的测试，可以分为：

(1)功能点测试：测试软件规格定义的所有功能点是否都已实现。

(2)功能组合测试：相关联的功能项组合后的功能是否都能正确实现。

(3)业务流测试：完整的业务流是否都能正确实现。

(4)场景测试：特定场景下所要求的业务流程组合能否完成。

(5)异常处理及容错性测试：输入异常数据，或执行异常操作后，测试系统容错性及错误处理机制的健壮性。

系统测试阶段的功能测试,除测试基本的、正常的功能外，还需要重点测试复杂的功能组合、业务功能冲突、特殊业务功能、异常操作等情况。

注：1. 测试用例一般应包含正向用例和反向用例；
