## 1. 功能板块（按包）

### 后端（吕建江）
- B1 库表与建表（四表字段与 `design/database.md` 逐字一致）
- B2 四个接口（空数据返回 `null`/`[]` 非 404；`risk_score` 不以 0.0 冒充）
- B3 鉴权（四接口 `X-API-Key`；`50000` 不回显内部）
- B4 在线预测+模型加载（实时推理+SHAP；幂等 upsert）
- B5 性能（POST /api/predict 95%<500ms，分位数证据）
- B6 安全（缺令牌/畸形参数两组截图）

### 前端（刘帅华）
- F1 三页面可演示（风险列表/详情/趋势，构成闭环）
- F2 字段映射一致（每个字段能在 `backend/api-spec.md` 找到）
- F3 三态齐全（加载中/空数据非错误/失败）
- F4 阈值统一（≥0.5/≥0.3 只在 `frontend/pages.md` 一处）
- F5 联调通过

### 模型（蒋励）
- M1 数据可复现（固定 `activemq-5.18.7`，±0）
- M2 SZZ 两套（标准行级+文件级简化版，差异量化）
- M3 Kamei 14 项（键名同源）
- M4 8 种模型 / 2 类（经典 6+深度 2；两类指标齐全）
- M5 时间序切分（禁随机；selfcheck 拦住）
- M6 全量预测交付（`prediction_result.csv` 字段=契约一表三）
- M7 解释 SHAP（逐特征带 direction）
- M8 校准与阈值证据

### 工程与协作（苏哲勋）
- R1 仓库工程基线（main 保护+Squash+模板生效）
- R2 全部 PR 非作者审阅（记录留 Git）
- R3 缺陷管理（GitHub Issue 五项齐全）
- R4 周报常态化（每周五晚，模板不改）
- R5 OpenSpec 推进（change 立/审/归节奏）
- R6 用户故事追溯（核心 27 + 可选附加 4 = 31 条能点回 openspec）

### 设计（全员）
- D1 架构/DB/四图（含生成方式标注）
- D2 非功能验证（性能+安全两项出证据；可靠/易用佐证）

### 可选附加（Epic G · 不进 MVP · Sprint 3 排期）
- G1-1 缺陷可视化定位（行级；行级数据缺失时降级到提交级并提示，不报错）
- G1-2 高质量修复建议（可回溯风险解释键名；无依据返回空态）
- G1-3 公开缺陷数据集加载与质量治理（标签粒度 / 语种单一 / 数据质量三项）
- G1-4 预训练语义特征建模（专家 vs 语义 vs 融合对比）

> Epic G 已拆分：G1-4 **语义特征提升为模型线主线**（change `semantic-feature-mainline`，Kamei 14 降为基线对照）、G1-3 公开数据集治理提升为承诺范围（change `public-dataset-quality`）、G1-1/G1-2 仍为可选附加（change `feature-addons-sprint3`）；不替换 Kamei 14 基线与交付模型（切换须另开「模型切换」提案），详设见 `design/addons.md`。

## 3. 一票否决风险（课程判定缺陷）

| 风险 | 后果 |
|---|---|
| 前端/后端/模型三处字段名不一致 | 「规格与代码不一致」 |
| 性能只写「已实现」无分位数证据 | 非功能缺项 |
| 模型只报一类指标（Effort-unaware 或 Effort-aware） | 不满足「两类」 |
| 周报改了模板结构 | 过程证据失分 |
| 数据版本浮动 `main` | 不可复现 |
| 随机切分（非时间序） | 准确率假的 |
| PR 无至少 1 位非作者审阅 | 协作规则不符 |
| 改需求只改码不改规格 | SDD 缺陷 |
| 附加功能静默替换交付模型 | 违反 `specs/model-coverage` R6，规格与实现不一致 |
| 第四个页面（模型管理/用户设置） | 稀释完成度，反扣分 |

## 4. 演示（Demo Day）覆盖

用户问题/价值 → 架构决策 → 核心场景（三页面+联调） → 一个 change 从规格→实现→测试→归档 → 测试概述 → 总结（关键数据/已知问题/亮点/教训）。
