# 接口

描述每个模块的端点、请求、响应、错误码与状态语义。

## 文件

| 文件 | 职责 |
|---|---|
| `conventions.md` | 响应信封、通用错误码、鉴权、分页、请求约定的唯一真源 |
| `<模块>.md` | 端点清单、请求、响应、错误码、状态与幂等 |

## 单篇模板

- 端点：方法、路径、用途、同步或异步。
- 请求：路径参数、查询参数、请求体，含必填与取值范围。
- 响应：成功示例（完整 JSON）、关键字段含义。
- 错误码：业务错误码、HTTP 状态、触发条件、前端应如何提示。
- 状态与幂等：重复提交、重试、任务轮询的语义。

## 编写规则

1. 信封结构、鉴权方式、分页参数与通用错误码只写在 `conventions.md`，模块文档引用不复写。
2. 异步任务型端点写明返回的任务标识、轮询端点与终态判定；状态机引用 `约束/job-state.md`。
3. 每个端点给出可直接发起的请求示例与完整响应示例。
4. 错误码必须是全系统唯一值，新增错误码先登记到 `conventions.md`。
