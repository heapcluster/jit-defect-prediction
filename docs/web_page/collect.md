# 数据收集页（Collect）

功能②　顶级 tab「数据收集」　路由 `/collect`

## 1. 页面定位

- 目标：从 Git 仓库或公开数据集 URL 拉取数据，生成带缺陷标注的数据集，预览二维表并下载核心结果文件。
- 入口：顶级「数据收集」tab。
- 出口：数据集预览、核心数据集下载（CSV / Excel）；历史数据集到「数据存储 / 产物库」查看、导出或删除。
- 不负责：训练 / 测试划分、清洗、建模、解释、定位；历史产物管理与删除归 `/storage`。
- 页面组织：单页配置，历史产物不在本页展示；配置区四步，结果区只展示本次运行。旧 `/collect/datasets` 书签重定向到 `/storage?section=library`。
- 来源模式：Git 仓库与公开数据集（URL 拉取）两种模式并列；公开数据集模式输入数据集 URL、许可证、字段映射与标签映射，由 collect 任务下载并落库，不经 `/api/storage/import` 创建。
- 来源 query：旧 `?section=public` 会被路由改写为 `?source=public`，页面进入公开数据集模式；`?source=git` 进入 Git 模式。

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 来源切换 | Git 仓库 / 公开数据集两张卡片 | 两张卡片均有 radio、名称与用途说明；切换后清空另一模式的输入、结果区与结果文件 |
| 公开数据集 URL | URL 输入 + [读取字段] | 仅接受 `https`；按 `collect.protocol_whitelist` 校验，不允许账号密码、query、hash；读取成功后展示列名并填充字段映射；失败保留错误与 [重试读取]，运行按钮禁用 |
| 字段 / 标签映射 | 列下拉 + 正负样本值 | 提交哈希与标签列必填；标签映射把源值映射为 1 / 0 / 未标注；映射缺列或标签值无法识别时阻止提交 |
| 01 仓库 URL | URL 输入框 + [刷新分支] | Git 模式支持公开仓库或服务端已配置凭据的仓库；URL 按 `collect.protocol_whitelist` 与白名单校验；不允许账号密码、query、hash；URL 改变后清空旧分支列表、已选分支、结果区与结果文件 |
| 分支刷新 | `GET /api/collect/branches?repo_source=...` | 点击 [刷新分支] 后拉取远端分支；刷新中按钮 loading、分支下拉禁用；失败保留错误并允许 [重试刷新]，不允许手工输入，不允许继续运行 |
| 分支选择 | 分支下拉 | 选项只能来自刷新返回的分支列表；默认选中第一项；分支不可为空；后端运行前必须校验分支存在 |
| 仓库信息卡 | 仓库名称、已选分支、仓库 URL | 分支列表就绪且已选分支后显示；路径过长换行；不显示“默认分支（HEAD）”这种非列表值 |
| 02 配置时间范围 | `el-date-picker` 日期范围 | 过滤提交的 `committed_at`，不是作者时间或拉取时间；留空表示全量提交；结束日期包含当天；结束早于开始时显示错误并清空结束日期 |
| 03 确认导出配置 | 数据集 / 导出文件名称输入框 + 配置预览卡 | 一个字段同时作为数据集名称与下载文件基础名；默认名为 `仓库名-起止日期`，无日期时为 `仓库名-full`；用户输入不含扩展名，下载时生成 `<名称>_<job_id>.csv/.xlsx`；用户改名后不被默认值覆盖 |
| 04 导出数据集 | [开始收集并导出数据集] 按钮 | 独立步骤、占满整行；Git 模式要求仓库 URL 合法、分支列表已加载且已选分支；公开数据集模式要求 URL 合法、字段 / 标签映射完整；名称非空、日期有效、无运行任务时可点击；运行中显示 loading 并禁用 |
| 进度区 | `JobProgress` | 文案按用户语言分阶段：校验来源、拉取提交、缺陷标注、生成数据集、完成导出；支持重试与取消；1.5 秒轮询；页面卸载或切换任务时终止旧轮询 |
| 数据集预览 | 已打标数据集二维表 | 成功后默认展开；展示前 20 行；默认列包含提交哈希、提交信息、作者、提交时间、缺陷标签、标签来源、采集备注；“显示全部字段”可查看完整 `collected_commits` schema；标签中文显示“有缺陷 / 无缺陷 / 未标注” |
| 结果文件 | 一个逻辑文件「已标注数据集」 | 下载按钮展开 CSV / Excel 两个格式；CSV 直接读取规范主表，Excel 从同一主表即时生成；summary / audit / quality / manifest 不在此区展示，也不提供下载 |
| 自动保存 | 数据集库登记 | 成功后自动保存；保存失败保留文件并提供手动重存，不以数据库失败否定文件产物 |
| 历史产物 | 不在本页渲染 | 已收集数据集在 `/storage?section=library` 统一查看、导出、查看成员与删除，本页不提供历史记录区 |

## 4. 主流程

1. 在第 01 步选择来源：Git 仓库或公开数据集；公开数据集输入 URL、许可证，点击 [读取字段] 后完成字段与标签映射。
2. Git 模式填写仓库 URL 并点击 [刷新分支]；系统校验 URL 并拉取远端分支。
3. Git 模式从返回的分支列表中选择分支，默认选中第一项；分支不可手填、不可留空；刷新失败时只能重试刷新。
4. 在第 02 步设置提交时间范围；留空表示全量。
5. 在第 03 步填写或修改数据集 / 导出文件名称，并在配置预览中核对所有参数。
6. 在第 04 步点击 [开始收集并导出数据集]，任务进入进度区并按用户语言阶段推进。
7. 成功后自动拉取数据集预览，并把规范主表保存到数据集库。
8. 结果文件区只显示「已标注数据集」一个逻辑文件；下载时选择 CSV 或 Excel。
9. 历史数据集到「数据存储 / 产物库」查看、导出或删除；失败时可重试原任务，运行中可取消。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| URL 为空 / 非法 | URL 下方显示校验错误；Git 模式的 [刷新分支] 与分支下拉禁用，公开数据集模式的 [读取字段] 禁用，运行按钮禁用 |
| 公开数据集读取中 | [读取字段] loading，映射下拉禁用，显示“正在读取数据集列” |
| 公开数据集读取失败 | 显示可读错误与 [重试读取]；映射下拉保持禁用；运行按钮禁用 |
| 字段 / 标签映射缺失 | 映射区标出缺失项；运行按钮禁用并说明原因 |
| 分支刷新中 | [刷新分支] loading，分支下拉禁用，显示“正在读取远端分支” |
| 分支刷新失败 | 显示可读错误与 [重试刷新]；分支下拉保持禁用；不允许手工输入；运行按钮禁用 |
| 分支列表为空 | 显示“未找到可用分支，请检查仓库 URL 或权限”；分支下拉禁用 |
| 分支已加载 | 默认选中第一项；显示仓库信息卡；运行按钮仍受名称和时间范围校验约束 |
| URL 改变 | 清空分支列表、已选分支、结果区与结果文件，要求重新刷新分支 |
| 日期倒置 | 日期下方显示“结束日期必须晚于开始日期”，结束日期被清空 |
| 任务排队 | 进度文案“当前正在排队等待执行” |
| 任务运行 | 按阶段显示“校验来源 / 拉取提交 / 缺陷标注 / 生成数据集 / 完成导出”，按钮禁用并提供取消 |
| 任务成功 | 进度文案“当前收集与导出已完成”；自动拉取数据集预览并自动保存 |
| 任务失败 | 进度文案“当前收集失败，可重试原任务”；显示顶部错误摘要与重试按钮 |
| 自动保存失败 | 保留文件与预览，显示保存错误与 [重新保存] |
| 鉴权失效 | 禁用运行、下载与数据集操作，提示重新登录 |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 枚举仓库分支 | `GET /api/collect/branches?repo_source=` |
| 读取公开数据集列 | `POST /api/collect/source-columns` |
| 运行收集 | `POST /api/collect/run` |
| 任务恢复 / 轮询 / 重试 / 取消 | `GET /api/jobs?kind=collect`、`GET /api/jobs/{id}`、`POST /api/jobs/{id}/retry`、`POST /api/jobs/{id}/cancel` |
| 数据集预览 | `GET /api/collect/preview/{job_id}` |
| 核心数据集下载 | `GET /api/collect/outputs/{job_id}/{name}?format=csv|xlsx`（格式转换按需生成） |
| 自动 / 手动入库 | `POST /api/collect/resave/{job_id}` |

数据集列表、导出、删除与成员查看的入口在 [`storage.md`](storage.md)，本页不调用。

## 7. 响应式与可访问性

- ≥900px：来源卡片两列，字段两列；步骤与结果面板跨整行。
- <768px：来源卡片与字段单列；主按钮整行；数据集预览表内部横向滚动。
- 仓库 URL、数据集 URL、许可证、映射下拉、日期选择器与文件名输入框均有可见标签或 `aria-label`。
- 分支刷新失败、公开数据集读取失败、运行中、列表为空均有文字反馈，不依赖颜色或图标单独传达。
- 保存状态使用 `role="status"`；下载格式菜单可键盘操作。

- [ ] 仓库 URL 输入后出现 [刷新分支]，分支只能从刷新结果中选择。
- [ ] 分支默认选中第一项；没有手填入口；没有“留空使用 HEAD”文案。
- [ ] 分支刷新失败时只能重试刷新，运行按钮保持禁用。
- [ ] 仓库 URL 改变时清空分支列表、已选分支、结果区与结果文件。
- [ ] 第 02 步按提交时间配置范围，留空表示全量，结束日期包含当天。
- [ ] 第 03 步使用单一“数据集 / 导出文件名称”字段，并完整预览配置。

- [ ] 数据集预览位于原提交预览位置，默认展开并展示前 20 行。
