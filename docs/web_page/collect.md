# 缺陷收集工具台（Collect）

实现状态：目标契约　期次：一期

> 旧页面把收集写成“产出含 14 维特征和 70/30 切分的 commits.csv，并可橘导入库”；本文已废止该口径。新页面以“带标签二维表 + 默认保存 + CSV/XLSX 导出”为核心。本轮只修改设计文档。

## 一句话

独立收集工具台：用户选择 Git 仓库或公开标注数据集，配置来源和标签规则后运行任务，页面展示带缺陷标签的二维表，默认保存数据库，并支持导出 CSV/XLSX。

## 入口与导航

- 顶级 tab：②收集，路由 `/collect`。
- 页内子视图三个：

```text
[Git 仓库采集] [公开数据集导入] [已收集数据集]
```

- 本页是板块 2 的唯一 Web 入口；CLI 与页面调用同一实现，同参数产出等价文件。
- 文件契约见 [`../file-contracts.md`](../file-contracts.md) §3.1、§3.9。

## 控件与接口映射

| 控件 | 端点 | 说明 |
|---|---|---|
| Git 仓库路径/URL、分支、时间/提交范围、模式、SZZ 方法、数据集名、保存数据库 | `POST /api/collect/run` | `source_type=git_repo`，返回 `job_id` |
| 提交清单拖拽/库中文件选择 | `POST /api/collect/run` 的 `files[]` | 仅用于圈定采集范围，不是运行前提 |
| 公开数据集文件/URL、许可证、来源、字段映射、标签映射 | `POST /api/collect/run` | `source_type=public_dataset` |
| 运行/导入 | `POST /api/collect/run` | 异步创建 `job.kind=collect` |
| 进度、日志、重试、取消 | `GET /api/jobs/{id}`；`POST /api/jobs/{id}/retry\|cancel` | 五态、阶段进度、脱敏日志 |
| 二维表预览 | `GET /api/collect/preview/{job_id}` | 返回列名和前 20 行 |
| CSV/XLSX | `GET /api/collect/outputs/{job_id}/{name}` | 下载本次二维表 |
| manifest / summary / quality | 同上 | 下载机器可读产物 |
| 已收集数据集 | `GET /api/datasets` | 只读展示默认保存后的数据集 |
| 重新保存 | `POST /api/collect/resave/{job_id}` | 保存失败后按已保留产物重试入库 |

## 交互流程

### Git 仓库采集

1. 用户填写仓库路径/URL 和采集范围；前端做 obvious 非法校验，后端做最终安全校验。
2. 可选上传提交清单或从库中选择清单文件；未上传则按时间/提交范围全量或增量采集。
3. 配置分支、模式、SZZ 方法、数据集名；保存数据库默认勾选。
4. 点击运行，调用 `POST /api/collect/run`，返回 `job_id`。
5. 轮询 `/api/jobs/{id}`，展示阶段：拉取/读取仓库 → 采集提交 → SZZ 打标 → 生成二维表 → 保存数据库 → 生成导出文件。
6. 成功后渲染二维表前 20 行、统计和下载按钮。
7. 数据库保存成功时在输出区提示“已保存到数据集库，可在已收集数据集查看”。
8. 数据库保存失败时任务为 failed，但文件仍可下载，页面提供“重新保存”。

### 公开数据集导入

1. 用户选择公开数据集文件/URL，填写许可证和来源说明。
2. 用户指定字段映射；系统只接受显式映射，不自动猜字段。
3. 用户指定标签映射；输入中出现的每个原始标签值都必须有映射。
4. 点击导入，后端校验字段、标签、大小、格式与许可证信息。
5. 成功后产出统一二维表、统计、质量报告和 manifest。
6. 默认保存数据库，保存失败语义同 Git 模式。

### 已收集数据集

- 只读展示 `GET /api/datasets` 返回的数据集列表。
- 字段：数据集名称、来源类型、来源地址、标签来源、样本数、正/负/未打标、保存状态、创建时间。
- 库空时显示“暂无已收集数据集”，不触发采集或其他计算。

## 空态与错误

- 加载中：骨架屏。
- 空态：库空下拉显示“暂无可用数据集，可直接填写来源”；数据集列表空态给出明确说明。
- 失败：展示脱敏错误原因、失败阶段和可用操作（重试/取消/重新保存）。
- 错误码：
  - 40001：参数、路径、协议、字段映射、标签映射、文件格式错误。
  - 40100：鉴权失败，禁用运行。
  - 40400：job、数据集或产物不存在。
  - 50000：内部错误。
- 非法输入不产半成品；运行失败的 job 不显示伪成功预览。

## 验收

- Git 仓库模式和公开数据集模式都可独立完成运行、预览、下载，不依赖其他模块或库中已有数据。
- 页面不显示 14 维特征、测试集占比、70/30 切分等旧文案。
- 二维表预览列与 file-contracts §3.1 一致；未打标显示“未打标”，不显示 0。
- 保存数据库默认开启；保存成功与失败均有明确页面反馈。
- CSV/XLSX/manifest/summary 可下载；公开数据集额外可下载质量报告。
- 公开数据集模式不显示 SZZ 方法；标签来源显示“公开数据集”。
- job 五态、进度、日志、重试、取消和重启中断恢复均可见。
- 已收集数据集列表只读，不作为运行前置。
