# 数据存储页（Storage）

功能①　顶级 tab「数据存储」　路由 `/storage`　管理页，不使用步骤编号

一句话：一个页面同时承载「我的文件」与「我的配置」——查看、下载、删除自己完成的数据集、产物与模型，浏览算法库，并读写常用配置。

## 1. 页面定位

- 目标：作为系统唯一产物中心与配置入口，把收集 / 清洗 / 训练 / 预测 / 评估 / 解释各阶段自动保存的产物集中管理，并让用户在同一页调整自己的常用配置。
- 入口：顶级「数据存储」tab，默认进入「我的文件」；`/settings` 作为兼容地址重定向到本页配置区。
- 出口：产物文件下载、数据集成员查看与 CSV 导出、数据集删除、整条链路删除、五项配置保存。
- 页面归属：单一页面内的四个区域——我的文件、数据链路、算法库、我的配置；文中「产物库」与「我的文件」指同一区域。
- 不负责：采集、SZZ、清洗、训练、预测、解释、定位；不修改产物内容。
- 无文件导入：本页不提供上传入口，也不接受用户选择文件；`POST /api/storage/import` 仅为清洗成功后内部自动登记数据集使用，不对页面开放。
- 删除单位：链路以整体删除，提供 `DELETE /api/storage/chains/{chain_id}`；链路内的任务记录、产物文件、训练产出的模型（`.pkl`）与收集产出的数据集一并删除。不提供单条任务产物删除。
- 共享保护：若链内数据集或模型被链路外的任务引用，删除前置拒绝并列出引用方（40001），由用户先处理外部引用；不静默删除共享资产。

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 区域切换 | 我的文件 / 数据链路 / 算法库 / 我的配置 | 第一个区域为默认；`/settings` 重定向到我的配置 |
| 统计行 | 数据集与六类任务结果的数量 | 数据来自 `GET /api/jobs?kind=` 与 `GET /api/datasets` 的 `total`；读取失败显示 `—`，不用 0 冒充有数据 |
| 筛选栏 | 产物类型、状态、关键字 | 类型固定为数据集 / 收集结果 / 清洗结果 / 训练结果 / 预测结果 / 评估结果 / 解释结果；筛选变化回到第一页 |
| 产物表 | 名称、类型、来源任务、生成时间、产物文件数、状态、操作 | 按生成时间倒序；单页隐藏分页；横向滚动不压缩列 |
| 行操作 · 查看 | 打开查看抽屉 | 数据集展示元数据与成员；其他产物展示产物文件列表；抽屉内信息只读 |
| 行操作 · 下载 | 下载主产物或数据集 CSV | 非数据集下载登记的主产物文件（优先 `.csv/.xlsx/.zip`）；数据集导出成员 CSV；鉴权失效时禁用 |
| 行操作 · 删除 | 删除数据集 | 仅数据集行显示；确认后调用 `DELETE /api/datasets/{id}`，模块产物文件不受影响 |
| 链路表 | 链路、节点数、类型分布、创建时间、操作 | 展开行展示节点明细；节点按任务真实父子关系展示，训练多算法保持分叉 |
| 链路操作 · 整链删除 | 删除整条链路 | 二次确认展示链路标题与节点数；被链路外引用时拒绝并列出引用方 |
| 算法表 | 算法、模型线、类别、默认标记、说明 | 只读；支持按模型线筛选与关键字搜索；清单来自 `/api/algorithms` |
| 配置表单 | 五项配置 | 高风险 / 中风险阈值为数值，默认数据集与默认解释技术为下拉，页面大小为枚举；保存后立即生效 |

## 4. 主流程

### 4.1 查看、下载与删除

1. 进入「我的文件」，默认看到全部历史产物；按类型、状态或关键字筛选。
2. 点击「查看」打开抽屉：数据集核对元数据并翻页查看成员；其他产物查看产物文件并逐个下载。
3. 数据集行可点击「删除」，确认后删除数据集及其成员关联；模块产物文件不受影响。
4. 切到「数据链路」，展开链路查看节点明细；需要清理时点击「整链删除」，确认后一并删除链内任务、产物、模型与数据集。
5. 删除成功后刷新链路表、产物表与统计。

### 4.2 浏览算法库

1. 切到「算法库」，按模型线筛选或搜索算法名。
2. 查看算法所属模型线、类别、是否默认与说明；算法清单由 `data_model` 注册表同步，页面不提供编辑。

### 4.3 修改配置

1. 切到「我的配置」（或从 `/settings` 重定向进入），读取当前已保存值。
2. 修改五项中的任意项，点击 [ 保存 ]；高风险阈值必须大于中风险阈值。
3. 保存成功后立即生效；后端或页面重开后自动回填已保存值，未保存草稿不保留。

### 4.4 被工具页选择

1. 需要使用上游产物的工具页在 01「选择输入」点击「从产物库选择」，打开 `ArtifactPicker` 弹窗；数据清洗与模型预测按各自页面文档使用受控下拉框，不走该弹窗。
2. 弹窗锁定本次需要的产物类型（如训练页只列清洗结果），支持关键字筛选。
3. 单选或按要求双选后确认，回填为 01 步的信息卡；关闭弹窗不改动已选值。
4. 弹窗只列可用产物，不提供上传与删除；需要清理时到本页处理。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| 空库 | 表格显示空态并说明“收集、清洗、训练等任务的结果会显示在这里”；统计显示 `—` |
| 加载中 | 统计与表格显示骨架 |
| 筛选无结果 | 表格空态说明当前筛选条件 |
| 删除被拒 | 链内资产被链路外任务引用时，显示引用方清单与“先处理外部引用”的说明，不执行删除 |
| 删除中 | 删除按钮 loading，禁止重复提交；成功后刷新列表与统计，失败保留原数据并说明原因 |
| 链路无法贯通 | 缺少 `parent_job_ids` 的孤立任务单独成链，标题标注“未关联”，不伪造上下游 |
| 配置读取失败 | 显示错误与重试，不用默认值冒充已加载 |
| 阈值非法 | 高风险不高于中风险时就地报错，不发起保存 |
| 鉴权失效 | 禁用下载、删除与保存，提示重新登录 |
| 接口失败 | 显示可读原因与重试，不用空数组冒充“无数据” |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 产物列表 | `GET /api/jobs`（按 `kind`、`status`、`chain_id` 与分页过滤） |
| 数据集清单 | `GET /api/datasets` |
| 数据集成员 | `GET /api/datasets/{id}/commits` |
| 删除数据集 | `DELETE /api/datasets/{id}` |
| 链路列表 | `GET /api/storage/lineage` |
| 删除整条链路 | `DELETE /api/storage/chains/{chain_id}` |
| 产物下载 | 按类型走 `GET /api/{collect\|clean\|train\|predict\|evaluate\|explain}/outputs/{job_id}/{name}` |
| 数据集 CSV 导出 | `GET /api/storage/export` + `GET /api/storage/outputs/{job_id}/{name}` |
| 算法清单 | `GET /api/algorithms` |
| 配置读取 / 保存 | `GET /api/config`、`PUT /api/config`、`PUT /api/config/{key}`、`DELETE /api/config/{key}` |

内部自动登记（页面不调用）：`POST /api/storage/import` 由清洗成功后自动调用，登记数据集。

字段与错误码以 [`../api/storage.md`](../api/storage.md)、[`../api/datasets.md`](../api/datasets.md)、[`../api/jobs.md`](../api/jobs.md)、[`../api/config.md`](../api/config.md)、[`../database/job.md`](../database/job.md) 为准，本页不复制 schema。

## 7. 响应式与可访问性

- ≥900px：四个区域位于页头标题右侧；统计一行多格，筛选栏两行，表格全宽。
- 768–899px：统计折行，筛选栏压缩，表格内部滚动；查看抽屉接近全宽。
- <768px：统计两格一行，筛选与配置表单单列，按钮整行；表格横向滚动不压缩列。
- 表格与成员表有表头；抽屉打开后焦点进入，关闭回到触发行。
- 状态与错误使用文字表达，不依赖颜色单独传达；不可用操作同时给出原因。
