# 系统设置页（Settings）

独立顶级 tab「系统设置」　路由 `/settings`

## 1. 页面定位

- 目标：只管理风险分档阈值，保存后立即生效。
- 入口：顶级「系统设置」tab。
- 页面组织：单页表单，无子签；页面只保留两个字段。
- 展示范围：只展示高风险阈值、中风险阈值；其余配置键仍由配置 API 提供，但不在本页暴露。
- 不负责：内部配置机制、密钥与部署参数；页面不显示 `.env`、API Key、密码或令牌。
- 不负责：各工具页的运行参数与界面主题。主题由 `frontend/src/styles/ui.css` 设计令牌决定，配置中心不再覆盖背景色与主题色。
- 不提供的交互：无「界面 / 通用」子签、无颜色取色器、无 JSON 高级编辑、无单字段恢复推荐、无来源（factory/global/user）提示。

## 2. 页面结构

```text
系统设置　调整风险分档阈值，保存后立即在所有页面生效
────────────────────────────────（页头唯一分隔线）

  ┌ 风险分档阈值 ──────────────────────────────────────┐
  │ 预测分数达到高风险阈值即标为高风险，介于中、高阈值之间为中风险。 │
  │ 高风险阈值 [ 0.50 ]        中风险阈值 [ 0.20 ]        │
  │ 分数 ≥ 0.50 判定为高风险     分数 ≥ 0.20 且低于高风险阈值时判定为中风险 │
  │                                                     │
  │ 当前风险区间  低风险 0–0.20 │ 中风险 0.20–0.50 │ 高风险 0.50–1 │
  └─────────────────────────────────────────────────────┘
  [ 保存修改 ]  修改后点此保存，保存后立即生效
```

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 高风险阈值 | `risk_high_threshold`，数值输入 | (0,1)，须大于中风险阈值；非法值在字段下方提示 |
| 中风险阈值 | `risk_mid_threshold`，数值输入 | (0,1)，须小于高风险阈值 |
| 风险区间预览 | 低 / 中 / 高风险三段比例条 | 随输入实时更新，只读 |
| 保存条 | 保存修改、状态与提示 | 无修改时按钮禁用；保存中 loading，成功显示“设置已保存，已在所有页面生效” |

## 4. 主流程

1. 进入页面读取配置，只取两个阈值键填入表单；读取失败显示错误与重试，不用默认值冒充已加载。
2. 修改字段时就地校验；跨键约束（中风险阈值 < 高风险阈值）在保存前检查。
3. 点击 [保存修改] 提交变更项，成功后重新读取并回填。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| 加载中 | 表单骨架屏 |
| 读取失败 | 错误提示 + 重试；不显示空默认表单 |
| 无修改 | 保存按钮禁用，提示“当前为已生效设置” |
| 字段非法 | 字段下方红字，保存被阻止 |
| 保存中 | 保存按钮 loading，表单可读 |
| 保存成功 | 成功提示 + 已保存值更新 |
| 保存失败 | 错误摘要，保留草稿 |
| 鉴权失败 | 禁用保存，提示重新登录 |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 读取设置 | `GET /api/config`（只渲染两个阈值键） |
| 批量保存 | `PUT /api/config`（只提交两个阈值键） |
| 其他配置键 | 仍可经 `GET /api/config`、`PUT /api/config`、`PUT /api/config/{key}`、`DELETE /api/config/{key}` 读写，但不在本页暴露 |

## 7. 响应式与可访问性

- ≥760px：字段两列；<760px：单列，保存条整行。
- 所有字段有 label；错误在字段下方；数值输入可键盘操作。

## 8. 验收清单

- [ ] 页面为单页表单，无「界面 / 通用」子签。
- [ ] 只展示高风险阈值、中风险阈值两项，其他配置键不在页面出现。
- [ ] 不出现取色器、JSON 编辑、恢复推荐与来源提示。
- [ ] 修改保存后立即生效；保存只提交变更的阈值键。
