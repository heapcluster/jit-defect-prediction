# Web 页面契约索引（README）

实现状态：部分　期次：一期

## 一句话

Web 顶级导航由与原图功能①~⑧一一对应的 8 个功能 tab 组成，原独立展示页与设置页全部收进对应功能 tab 的页内子视图（子签）；页面只编排 API、展示结果与保存配置，不承载特征、训练、预测、评估、解释或定位算法。

## 入口与导航

各功能工具台接受本模块输入文件并交付输出文件；展示子视图只读已通过功能①导入的 12 表，不承载业务计算，也不是任何工具运行的前提。功能⑨（多种形态）是二期拓展，不占顶级 tab。

## 控件与接口映射

| 全局能力 | 端点 | 契约 |
|---|---|---|
| 七类文件计算入口 | `POST /api/{collect,clean,train,predict,evaluate,explain,localize}/run` | 文件进、文件出；前六类按模块契约创建对应 job，定位同步为主 |
| 工具产物下载 | `GET /api/{module}/outputs/{job_id}/{name}` | CSV 默认、XLSX 可选，manifest 必伴；定位以同步响应的产物引用代入路径占位 |
| 数据导入 / 按表导出 | `POST /api/storage/import`；`GET /api/storage/export` | 自动识别目标表，按自然键幂等 upsert；导出 CSV/XLSX/manifest |
| 任务生命周期 | `GET /api/jobs`；`GET /api/jobs/{id}`；`POST /api/jobs/{id}/retry\|cancel` | 六类 kind、五态 queued/running/success/failed/cancelled；状态读 `job` 表 |
| 用户配置 | `GET/PUT /api/config`；`PUT/DELETE /api/config/{key}` | 全局键与模块命名空间键统一落 `user_config`，保存生效、重启恢复 |
| 模型 / 数据集选项与已收集数据集 | `GET /api/models`；`GET /api/datasets` | 下拉便利输入来自已登记资产；②的已收集数据集只读展示同一数据集清单；不上传库中文件也可独立运行工具 |
| 展示子视图只读数据 | `GET /api/commits`；`GET /api/commits/{hash}`；`GET /api/trends` | 只读导入后的库，不触发收集、训练、预测或评估 |
| 运行状态 | `GET /api/health`；`GET /api/health/live`；`GET /api/health/ready` | 不就绪时显示原因，不伪造页面数据 |

## 交互流程

1. 所有 API 与文件下载统一携带 `X-API-Key`；40100 时显示鉴权原因并禁用写操作。
2. 工具台以上传文件为完整运行路径，库中文件下拉只是便利选项。上传后校验大小、扩展名与魔数、列 schema 和 CSV 公式注入；非法输入返回 40001，不产半成品。
3. 收集、清洗、训练、批量预测、评估、解释按各自契约返回 `job_id`，前端轮询 jobs 族展示五态，进度存入全局 store；失败可重试，运行中可取消。定位同步返回结果，不新增 job kind；数据导入导出使用自身请求状态。
4. 工具成功后预览输出并提供 CSV/XLSX/manifest 及模块特有产物下载。支持展示表映射的工具可选 [导入库] 调 `POST /api/storage/import`，逐表反馈 inserted/updated/skipped/conflicts；不导入不影响文件交付。定位输出不映射展示库，只交付文件，不提供导入按钮。
5. ⑤的风险列表、趋势看板与提交详情以及②的已收集数据集默认只读导入后的库，不承载业务计算、不作为模块运行前置。库空时显示对应空态和去①数据管理导入的引导；筛选无结果与库未导入是两种不同空态。
6. ①的用户配置区批量写配置，任一键非法则整批不写。全局键与模块命名空间键均重启恢复；`.env` 只提供出厂默认值，不在页面编辑。
7. 未打标 `is_bug_inducing=null` 显示「无 SZZ 标记」，不得当作 0；缺预测行或缺预测字段留空并显示「未预测」，不得渲染风险 0。

## 鉴权取图约定

- 图片与图文件一律用 `fetch` 携带 `X-API-Key` 获取二进制，转 `ObjectURL` 后交给 `<img>`；不得让 `<img>` 直连受鉴权接口。
- 组件卸载、抽屉关闭或图片替换时调用 `URL.revokeObjectURL`。缺图按接口 `missing[]` 或明确状态降级，不通过反复请求 404 探测。

## 空态与错误

- 全站三态：加载中（骨架屏）/ 空（说明原因与下一步）/ 失败（可读文案与可用的重试）。
- 错误码统一：40001 参数、校验或并发冲突；40100 鉴权；40400 对象或产物不存在；50000 内部错误。错误响应不得回显凭证、堆栈、SQL 或服务器敏感路径。
- 六类 job 的进程重启中断记录为 failed，可从持久化状态恢复并重试；定位与存储请求失败不伪造 job。
- 展示子视图接口失败时保留已选筛选条件，不用空数组冒充无数据；工具页失败时保留输入与配置快照。

## 验收

- 8 个功能 tab 逐一可达且与原图功能①~⑧一一对应；上表与本索引链接覆盖全部 13 篇页面文档，未知路由有 404 页。
- ⑤内含风险列表、趋势看板、提交详情三个页内子视图（子签），详情可由风险列表行进入；⑥内含模型性能子视图；①内含用户配置区；各重定向保留其他 query/hash，`/commit/:hash` 高亮预测。
- 八个工具台均可仅凭各自输入文件完成运行、预览和下载，库空不影响独立验收；输出 schema 与 file-contracts §3.1–3.9 一致。
- 六类 job 五态、日志、重试、取消与重启中断行为一致；定位不新增 job kind。
- 展示子视图只读导入后的库，库空均提供去①数据管理导入的引导，且不出现业务计算触发器；②可只读展示已收集数据集版本列表。
- 用户配置区中的全局键与模块命名空间键保存生效并重启恢复；敏感信息不在页面编辑或入库。
- 图片全部鉴权 fetch 转 ObjectURL 并正确释放；未打标与缺预测均不渲染 0。
