# 模型训练页（Train）

功能④　顶级 tab「模型训练」　路由 `/train`

## 1. 页面定位

- 目标：从清洗后数据出发，选择一条特征线、一个或多个算法并配置超参数，按比例或提交时间划分训练 / 测试集，确认后运行；模型自动保存与登记，训练集、测试集自动保存并可下载。
- 入口：顶级「模型训练」tab；01 步通过「从产物库选择」弹窗选择已清洗数据。
- 出口：每个算法一个 `.pkl` 模型文件（在结果文件区单独列出、单独下载）、训练集、测试集与 manifest；历史训练结果到「数据存储 / 产物库」查看或删除。
- 不负责：判定阈值（训练不设阈值，阈值只在⑤模型预测时设置）；**任何模型性能对比**（指标、排序、对比图、混淆矩阵、ROC / PR 与评估报告均不在本页展示）；超参数自动寻优；仓库来源填写。
- 页面组织：单页配置，不设历史子签；配置区五步，结果区只展示本次运行。
- 与设计图对齐：设计图④只有「划分训练测试集、选择一个或多个算法、设置超参数」三件事。本页把“选择特征线”并入 02（后端必填 `line` / `feature_set`），把“划分”拆成比例或时间两种滑块，并保留随机种子（可复现）；这些都是实现必要项。
- 性能对比边界：设计图④注“对比模型性能时可选多个算法”，只表示一次训练可以产出多个 `.pkl`；**训练页不展示任何性能指标、不做算法排序、不画对比图**，模型性能对比不在本页提供。
- 模型交付形态：训练不打包 ZIP。每个成功算法直接产出一个 `.pkl` 权重文件，结果文件区逐算法展示；模型元数据（特征顺序、特征 schema、超参与版本）由训练侧车 JSON 与 manifest 承载，不占用用户可见的结果文件位。

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 清洗数据选择（01） | 清洗任务产物 | 点击「从产物库选择」打开弹窗，只列成功清洗结果；选中后展示数据集名称、来源仓库、分支与 HEAD、清洗任务、任务状态、生成时间、输入与输出行数、删除与修改行数、正负与未标注、提交时间范围、数据文件与清单文件；不提供手动上传 |
| 特征线（02） | 专家特征（Kamei 14 维）/ 语义特征（CodeBERT 768 维） | 单选卡片；切换特征线会清空已选算法与超参数，并重新加载该线算法目录；卡片写明特征口径，悬停显示补充说明 |
| 算法卡片（02） | 当前特征线注册的算法 | 多选，勾选顺序生成序号并作为训练顺序；卡片展示名称、所属类别与一句话用途；默认口径带「默认」徽标；勾选后卡片内展开中文超参数，数值项用数字输入、枚举项用中文下拉，标签和选项不出现 `lr__C`、`svm__gamma`、`scale` 等原始 key / value |
| 算法介绍 | 抽屉 | 每张卡片提供「查看介绍」，展示名称、所属特征线、类别、简介、适用场景、超参数说明与默认值；内容来自 `GET /api/algorithms` 的 `description` 与 `hyperparams_schema`，不新增接口；更长的适用场景文本由算法注册表补充 |
| 切分方式（03） | 按比例 / 按提交时间 | 二选一单选；两种模式互斥，确认卡只回显当前模式；切换时保留比例值或边界值，便于切回 |
| 比例滑杆 | 单滑杆 | 50%–90%、步长 5%，测试比例取补集并实时显示；仅比例模式出现 |
| 时间滑杆 | 单滑杆 | 取值区间为所选清洗数据的提交时间范围（最早至最晚，UTC）；边界左侧训练、右侧测试（训练最晚 ≤ 边界 < 测试最早）；拖动时实时显示边界时间与两侧样本数、占比；样本数来自清洗产物的时间分布，不靠前端猜 |
| 随机种子 | 数字输入 + 随机按钮 | 非负整数，默认 42；「随机刷新」生成新的非负整数并回填；种子进入任务指纹，保证同输入同结果可复现 |
| 确认配置（04） | 训练数据、特征线、算法与超参摘要、切分方式与参数、种子、输出 | 两列信息网格；长内容跨列；只回显已确定的配置，不重复展示可编辑控件 |
| 运行（05） | 开始训练 | 独立步骤，按钮占满整行；未选数据、未选算法、切分非法或缺时间范围时禁用并说明原因；训练中禁用重复提交，可重试或取消 |
| 进度 | 总进度、当前算法、算法队列 | 总进度来自任务 `progress`；当前算法来自 `current_item`；队列按勾选顺序展示等待 / 训练中 / 已完成 / 失败；单个算法失败不阻塞后续算法 |
| 本次算法产出 | 序号、算法、状态、模型名 | 只展示训练是否成功与产物名称，不展示任何指标、耗时排名或对比图 |
| 登记/加载状态 | 模型登记 x/y、已加载 z、失败数 | 训练任务自动完成，页面不提供手动导入或开关；登记失败不影响产物下载 |
| 结果文件 | 每个算法的 `.pkl`、训练集、测试集、manifest | 只列本次运行产物；每个 `.pkl` 单独一行、单独下载，文件名为 `train_<algo>_model_<job_id>.pkl`；训练集与测试集支持 CSV / Excel；不经 ZIP 打包；历史产物到 `/storage` |

## 4. 主流程

1. 在 01 选择清洗数据，核对信息卡中的来源、样本规模、标签分布与提交时间范围。
2. 在 02 先选特征线，再按顺序勾选一个或多个算法；需要时展开超参数，或打开「查看介绍」了解算法。
3. 在 03 选择按比例或按提交时间切分；按比例拖动滑杆，或按时间拖动边界滑杆查看实时两侧比例；按需填写或随机生成种子。
4. 在 04 核对配置摘要，确认算法顺序、超参与切分参数。
5. 在 05 点击 [开始训练]，进度区按算法顺序展示当前算法与总进度。
6. 成功后查看各算法产出与登记状态，在结果文件区逐个下载 `.pkl`、训练集与测试集。
7. 历史训练结果到「数据存储 / 产物库」查看。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| 未选数据 | 主按钮禁用，提示先选训练数据 |
| 清洗结果缺少时间范围 | 时间切分不可用并说明“该清洗结果未登记提交时间范围”；比例切分仍可用 |
| 未选特征线 | 算法列表不展开，主按钮禁用 |
| 未选算法 | 主按钮禁用，提示至少选择一个算法 |
| 超参数非法 | 字段下方就地提示，主按钮禁用 |
| 时间边界任一侧为空 | 滑杆旁提示“训练集 / 测试集为空”，主按钮禁用 |
| 测试集标签为空 | 提交后由后端拒绝，显示可读原因，保留全部配置 |
| 运行中 | 总进度、当前算法与算法队列可见；可取消，切换路由不丢任务状态 |
| 单算法失败 | 队列标记失败，其余算法继续；结果区保留成功模型的产物 |
| 全部失败 | 显示失败摘要与重试，不显示伪成功 |
| 登记失败 | 显示登记失败数与原因，产物仍可下载 |
| 鉴权失败 | 禁用训练与下载，提示重新登录 |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 清洗产物选择 | `GET /api/jobs?kind=clean&status=success`（产物库选择弹窗共用） |
| 清洗数据时间范围与分布 | 清洗产物 `summary.time_range` 与 `summary.time_bins`（见下） |
| 算法与超参元数据 | `GET /api/algorithms?line=` |
| 启动训练 | `POST /api/train/run` |
| 任务状态 / 重试 / 取消 | `GET /api/jobs/{id}`、`POST /api/jobs/{id}/retry|cancel` |
| 结果下载 | `GET /api/train/outputs/{job_id}/{name}` |
| 模型登记 / 热加载 | 训练任务内部完成；结果区回显 `register_status` / `load_status` |

依赖与缺口：

- 时间滑杆需要清洗产物登记 `time_range`（最早、最晚提交时间）与 `time_bins`（分桶时间与累计样本数）；当前清洗 summary 只有行数与标签分布，属待补契约，补齐前时间切分只能退回手填时间边界。
- 训练集下载需要训练产物新增 `train_trainset_<job_id>.csv/.xlsx`；当前只产出测试集，属待补产物。
- 逐算法状态依赖任务轮询暴露 `current_item` 与已完成算法列表；若后端只提供整体进度，则队列只能显示“当前算法 / 已完成算法”。
- 训练响应中的 `models[].metrics` 只作为后端内部记录 / 排查能力，训练页不读取、不展示；`GET /api/train/compare` 与 `train_comparison_*.json` 已移除。
- `.pkl` 必须可被预测模块直接加载；特征顺序、特征 schema、超参与版本由侧车 `train_<algo>_meta_<job_id>.json` 承载，checksum 由 manifest 登记，不以 ZIP 打包。
- 后端已按逐算法 `.pkl` + 侧车 JSON 产出并登记，训练不产出 ZIP 模型包。

## 7. 响应式与可访问性

- ≥1200px：特征线卡片两列，算法卡片每行 4 个，信息卡两列铺满宽度。
- 768–1199px：算法卡片每行 2–3 个，超参数与信息卡换行。
- <768px：单列；特征线、算法卡片与两个滑杆单列，统计块两列，按钮整行。
- 滑杆支持键盘方向键微调，并暴露 `aria-valuemin` / `aria-valuemax` / `aria-valuenow` 与当前边界文本；时间滑杆的两侧比例用文字同步显示，不只依赖位置。
- 算法卡片用单选 / 复选语义与可见文字表达选中；超参数标签和枚举选项为可见中文；键盘可完成全部配置与介绍查看。
