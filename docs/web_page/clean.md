# 数据清洗页（Clean）

功能③　顶级 tab「数据清洗」　路由 `/clean`

## 1. 页面定位

- 目标：从数据收集已入库的数据集中选择一份，配置常用清洗操作与预处理操作，生成清洗后数据集，并查看处理前后变化。
- 入口：顶级「数据清洗」tab；01 步从数据收集保存的数据集中选择。
- 出口：下载清洗后数据集，查看处理记录、前后差异与分页预览；历史清洗结果到「数据存储 / 产物库」查看或删除。
- 不负责：步骤排序、模型特征工程、训练与测试切分、SZZ 重打标。清洗项顺序与参数由后端约束固定，用户只勾选启停和填写中文参数。
- 页面组织：单页同屏四步，不设子签，不做分页向导；结果区只展示本次运行。

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 输入选择 | 数据收集保存的数据集下拉框 | 只列 `status=ready`、schema 符合 `collected_commits`、来源为 Git 仓库收集结果的数据集；不提供手动上传；选择后 02 自动解锁 |
| 数据集信息 | 名称、来源类型、仓库、分支、HEAD、样本数、正负样本、未标注、时间范围、状态、创建时间 | 两列信息卡；未选中数据集时不显示；提供「查看前 20 行样本」折叠区，不直接展示全量数据 |
| 数据集切换 | 清空字段相关配置 | 保留用户填写的数据集 / 导出文件名称；清空依赖列参数、结果、图表、预览和结果文件，并提示“数据集已切换，字段相关配置需要重新确认” |
| 常用清洗操作（02） | 后端 `group=clean` 的操作列表 | 用户可见分组名为“常用清洗操作”；卡片显示序号、中文名称、结果说明；必选项写明原因并不可取消；参数控件来自 `params_schema.default`，标签和选项全部中文化 |
| 预处理操作（02） | 后端 `group=preprocess` 的操作列表 | 用户可见分组名为“预处理操作”；只做数据格式与展示字段处理，不生成模型特征；不提供 `log_transform`、`standardize`、`categorical_encode`、`feature_select` 等训练侧变换 |
| 差异展示策略 | 用处理记录展示前后变化 | 页面不提供“生成对比图”开关或列多选；结果区用表格展示每步行数、缺失、重复、标签分布变化及字段级前后差异 |
| 确认输出与配置（03） | 数据集 / 导出文件名称输入框 + 配置摘要 | 一个字段同时作为清洗后数据集入库名称和下载文件基础名；默认 `<原数据集名>清洗后`；用户不填扩展名；配置摘要不出现列选择 |
| 运行（04） | [开始清洗] 按钮 | 独立步骤、占满整行；无输入、名称为空、运行中或未加载处理项时禁用 |
| 清洗进度 | 进度条和一行状态文字 | 阶段文案为“校验数据集 / 执行清洗 / 发布结果 / 生成结果预览 / 完成入库”；支持重试和取消 |
| 结果摘要 | 输入行数、输出行数、删除行数、修改行数 | 四项统计成等宽卡片；未出结果显示 `—`；自动保存成功 / 失败只在这里以状态文字回显 |
| 处理记录 | 每步统计表 | 展示步骤、前后行数、删除行数、修改行数、标签分布；默认收起，有数据时自动展开 |
| 清洗前后对比 | 每步差异表 + 字段变化明细 | 基于处理记录展示行数、缺失、重复、标签分布变化，并列出每个被修改提交的字段前后值；不生成 PNG 变化图 |
| 清洗后数据预览 | 分页二维表 | 成功后支持分页浏览全量清洗后数据；展示全部字段，默认每页 12 行；横向滚动不压缩列；完整数据通过结果文件下载 |
| 结果文件 | 一个逻辑文件「清洗后数据集」 | 下载菜单只有 CSV / Excel；CSV 直接读取规范主表，Excel 下载时从同一主表即时生成；不展示 manifest / steps_stats 等内部记录 |
| 自动入库 | 任务成功后自动保存清洗后数据集 | 自动保存状态在结果摘要中显示；保存失败不影响结果文件下载，提供手动重存入口 |
| 历史产物 | 不在本页渲染 | 历史清洗结果在 `/storage?section=library` 统一查看、下载与删除，本页不提供历史记录区 |

## 4. 主流程

1. 进入页面后加载数据收集保存的数据集列表和清洗操作元数据。
2. 在 01 选择数据集，查看数据集信息；需要时展开前 20 行样本确认内容。
3. 切换数据集时保留输出名称，但清空字段相关配置、结果、图表、预览和结果文件。
4. 在 02 分别配置“常用清洗操作”和“预处理操作”；必选项不可取消，参数只显示中文标签与中文选项。
5. 在 03 填写或修改数据集 / 导出文件名称，核对配置摘要；页面不要求选择生成图列。
6. 在 04 点击 [开始清洗]，任务进入进度区并按用户语言阶段推进。
7. 成功后查看结果摘要、处理记录、变化图和清洗后数据分页预览。
8. 清洗后数据集自动保存到数据集库；保存失败可在结果区重试。
9. 在结果文件区只下载「清洗后数据集」一个逻辑文件，下载时选择 CSV 或 Excel。
10. 历史清洗结果到「数据存储 / 产物库」查看、导出或删除；失败时可重试原任务，运行中可取消。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| 未选择数据集 | 数据集信息不显示，02–04 不可用；结果区常驻，统计显示 `—` |
| 数据集列表为空 | 下拉框显示“暂无数据收集数据集，请先在数据收集页保存数据集” |
| 加载处理项失败 | 02 显示重试按钮，不禁用其他区域 |
| 数据集切换 | 字段相关配置、结果、图表、预览和文件清空；提示重新确认字段配置 |
| 未开始 | 进度条为 0；结果区统计 `—`，折叠区与结果文件为空 |
| 运行中 | 按阶段显示进度文案，可取消 |
| 成功 | 结果摘要、处理记录、变化图、分页预览、自动保存状态和结果文件可见 |
| 无变化图 | 图表区显示原因，例如“本次处理未产生可展示的字段变化”，不让用户配置列 |
| 失败 | 显示可读原因和重试，输入与配置保留 |
| 自动保存中 | 结果摘要显示“正在自动保存到数据集库” |
| 自动保存完成 | 结果摘要显示数据集名称 |
| 自动保存失败 | 结果摘要显示失败原因与 [重新保存]，不影响结果文件下载 |
| 鉴权失效 | 禁用运行、下载与保存操作，提示重新登录 |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 数据集候选 | `GET /api/datasets`，只筛数据收集保存的可用数据集 |
| 操作元数据 | `GET /api/clean/operations`；`group=clean` 渲染“常用清洗操作”，`group=preprocess` 渲染“预处理操作” |
| 启动清洗 | `POST /api/clean/run`；页面固定 `mode=apply`，不传 `format` |
| 任务状态、重试、取消 | `GET /api/jobs/{id}`、`POST /api/jobs/{id}/retry`、`POST /api/jobs/{id}/cancel` |
| 每步统计与前后差异 | `GET /api/clean/outputs/{job_id}/clean_steps_stats_{job_id}.json` |
| 分页预览 | `GET /api/clean/preview/{job_id}?page=&size=` |
| 核心数据集下载 | `GET /api/clean/outputs/{job_id}/{name}?format=csv\|xlsx` |
| 自动入库 | `POST /api/storage/import`（清洗成功后内部自动调用，页面无导入入口） |
| 历史清洗结果 | `/storage?section=library` |

## 7. 响应式与可访问性

- ≥768px：清洗与预处理操作分组纵向排列，卡片多列网格；<768px 单列。
- 运行按钮始终占满整行宽度。
- 分区标题「清洗进度」「清洗结果」18px/650，带左侧主色条；操作分组使用普通文字说明，不嵌套小标题层级。
- 所有说明文字、标签和状态统一 15px；统计数值 24px。
- 操作项为可见复选框，参数标签和选项为中文可见文本，不只依赖 tooltip；差异表有文字摘要。
- 数据预览表横向滚动，不压缩列；分页控件可键盘操作。
- 错误和状态使用文字反馈，不依赖颜色单独传达。
