# 趋势看板（TrendBoard）

## 页面与路由
- 页面名：缺陷引入趋势看板
- 路由：`/trend`
- 入口：导航栏「趋势看板」

## 概述
- 模型选择由单下拉改为**架构 → 模型级联双下拉**。
- 下方原单个趋势图拆分为**两个独立图表**：提交数趋势图、高风险数趋势图，各自按时间独立展示。
- 点「查询」时，两个图表随筛选条件（粒度、架构+模型、时间范围）**同步刷新**。

## 布局（从上到下）

```
┌────────────────────────────────────────────────────────────────────┐
│ 缺陷引入趋势看板                                                    │
├────────────────────────────────────────────────────────────────────┤
│ 粒度 (周)(月)  架构[▾] 模型[▾]  时间范围[____ 至 ____]  [查询]      │
├────────────────────────────────────────────────────────────────────┤
│ [区间提交 1234]  [高风险提交 56]  [加权平均风险 0.23]               │
├────────────────────────────────────────────────────────────────────┤
│ 提交数趋势                                                          │
│ ┌────────────────────────────────────────────────────────────────┐ │
│ │ 柱状/折线：X=时间（period），Y=提交数（commit_count）          │ │
│ └────────────────────────────────────────────────────────────────┘ │
│ 高风险数趋势                                                        │
│ ┌────────────────────────────────────────────────────────────────┐ │
│ │ 柱状/折线：X=时间（period），Y=高风险数（high_risk_count）     │ │
│ └────────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────┘
```

分块说明：

1. **筛选栏**（横向 inline）：粒度（周/月 radio）、架构下拉、模型下拉（联动）、时间范围选择器、「查询」按钮。
2. **汇总卡**（保留 3 张）：区间提交数、高风险数、加权平均风险。
3. **图表一 · 提交数趋势图**：横轴时间、纵轴提交数。
4. **图表二 · 高风险数趋势图**：横轴时间、纵轴高风险数。

## 交互
- **架构 → 模型级联**：选「架构」后「模型」联动展示该架构下的模型；切换架构清空已选模型；两级都不选 = 后端默认模型。
- **查询联动**：点「查询」按 粒度 / 架构+模型 / 时间范围 过滤，**两个图表用同一份响应同步刷新**。
- 点击数据点下钻到该时段的风险列表；数据点 < 2 时不画折线，退回明细表兜底。

## 数据接口
| 用途 | 接口 |
|---|---|
| 架构 → 模型层级 | `GET /api/models` |
| 趋势数据 | `GET /api/trends?granularity=&model_name=&start_time=&end_time=` |

`GET /api/trends` 响应（**同一响应驱动两个图表**）：

```json
{
  "granularity": "week",
  "model_name": "lr_v1",
  "series": [
    { "period": "2026-W30", "commit_count": 120, "high_risk_count": 8, "avg_risk": 0.23 }
  ]
}
```

- 图表一取 `series[].commit_count`，图表二取 `series[].high_risk_count`。
- `series[].period` 即横轴时间（周 `2026-W30`，月 `2026-07`）。

## 说明
- 两个图表共用 `GET /api/trends` 的同一份 `series`，**无需两个独立趋势接口**。
- 模型筛选 = 架构（`line`）+ 模型（`model_name`）两级；`line` 不进趋势查询。
- 高风险数口径 = `risk_score >= 运行时高阈值`；平均风险（`avg_risk`）仅出现在汇总卡，不再单列成折线。
