# 趋势看板（TrendBoard）

实现状态：部分　期次：一期

## 一句话

读取 `GET /api/trends` 对导入库的聚合结果，以一张同 Y 轴双系列图展示提交数柱与高风险数线，并用同一响应生成三张汇总卡；本页不预测、不补算、不重写风险概率。

## 入口与导航

- 功能⑤（模型预测）tab 内趋势看板子视图（子签）；`/trend` 重定向到 `/predict` 并选中本子视图，入口索引见 [README.md](README.md)。
- 点击数据点下钻 [风险列表](risk_list.md)，query 携带已加载数据点的时间范围与 `model_name`。
- 库空时引导至 [数据管理](storage.md) 导入预测结果；本页不提供导入或运行入口。

## 控件与接口映射

| 控件 | 端点 | 说明 |
|---|---|---|
| 粒度 [周▾][月] | `GET /api/trends?granularity=week\|month` | 周为 ISO 周，月为自然月 |
| [架构▾][模型▾] | `GET /api/models` | 架构只驱动级联；趋势查询只传实际 `model_name` |
| [时间范围] | `GET /api/trends?start_time=&end_time=` | commit 时间两端闭区间，与模型级联独立 |
| [查询] | `GET /api/trends?granularity=&model_name=&start_time=&end_time=` | 同一份 `series[]` 同时驱动图和三卡 |
| 柱系列 / 线系列 | 同上（`series[].commit_count` / `high_risk_count`） | 固定柱 + 线、同一 Y 轴，不提供拆图或系列隐藏控件 |
| 三张汇总卡 | 同上（对 `series[]` 展示聚合） | Σcommit_count、Σhigh_risk_count、按 commit_count 加权 avg_risk |
| 阈值标注 | `GET /api/config`（`risk_high_threshold`）；响应 `threshold` 回显 | 高风险计数由后端按配置阈值聚合，前端不逐行重算 |
| 数据点下钻 | 路由 `/`（query：时间范围、`model_name`） | 使用已加载数据点对应粒度换算区间 |
| [去数据管理导入] | 路由 `/storage` | 库空空态的唯一下一步引导 |

## 交互流程

1. 进入页面读取模型清单与配置，按粒度、默认模型和当前时间范围调用 `GET /api/trends`。架构切换只刷新模型选项，清空已选模型。
2. [查询] 后，柱系列绑定 `series[].commit_count`，线系列绑定 `series[].high_risk_count`，两者共用同一 Y 轴；图与三卡在同一响应完成后一起更新。
3. 三卡仅作展示汇总：区间提交 = Σ`commit_count`；高风险提交 = Σ`high_risk_count`；加权平均风险 = Σ(`avg_risk`×`commit_count`) / Σ`commit_count`。分母为 0 时第三卡显示「—」。
4. 设置页修改 `risk_high_threshold` 后重新查询趋势，线系列与高风险卡按新口径变化；柱系列与加权平均风险不变。概率记录不被修改。
5. 点击数据点，按本次已加载响应的粒度换算该周期起止时间，并携带 `model_name` 下钻风险列表；不得使用尚未点击 [查询] 的编辑态。
6. 数据点少于两个时不画折线，显示周期明细表；完全无数据时区分库空与当前筛选无结果。

## 空态与错误

- 加载中显示图表与卡片骨架；库空显示「尚未导入预测数据」和 [去数据管理导入]；筛选无结果显示「当前区间无数据」与 [重置时间范围]。
- 接口失败显示错误与 [重试]，保留上一次成功图的明确时间戳或清空为失败态，不把失败响应当成全零数据。
- `series=[]` 时三卡显示 0、0、「—」；不得因缺少预测行生成风险 0。
- 非法粒度或时间格式返回 40001；40100 给鉴权提示；资源不存在返回 40400；内部错误返回 50000。
- 配置读取失败时显示阈值来源不明并暂停高风险口径标注，不伪造配置值。

## 验收

- 页面只有一张趋势图，柱固定为 commit_count、线固定为 high_risk_count，两系列同 Y 轴；无第二 Y 轴、第三系列或拆图控件。
- `avg_risk` 只进入加权平均风险卡，不进入图形、图例和周期明细表。
- 图与三卡来自同一次 `GET /api/trends` 响应；三卡公式与 Σ 汇总结果一致，空集合第三卡为「—」。
- 粒度、模型和时间范围查询生效，line 不作为 trends 参数；改风险高阈值后仅高风险线和高风险卡变化。
- 数据点下钻周期与模型正确；数据点少于两个时明细表兜底。
- 库空有去数据管理导入引导；页面只读导入后的库，不含任何业务计算触发器。
