# 预测评估页（Evaluate）

功能⑥　顶级 tab「预测评估」　路由 `/evaluate`　模型性能为独立页面 `/evaluate/models`

## 1. 页面定位

- 目标：选择系统已保存的一次模型预测结果，按用户勾选的指标评估该次预测的质量，产出评估图集与指标表。
- 入口：顶级「预测评估」tab；01 步用下拉框选择已保存的预测结果，选中后同时显示该预测结果的详情介绍。
- 出口：下载「评估图集 zip」与「评估指标表（CSV / Excel）」；历史评估产物到「数据存储 / 产物库」查看或删除；需要重新预测时回到⑤。
- 不负责：训练模型、重算预测、重新判定标签；评估只消费已保存的预测结果文件，不生成预测。
- 与④的边界：训练页只产出模型与切分数据，不做任何性能比较；本页是唯一的单模型性能评估入口。
- 与⑤的边界：预测页产出带真标签的预测结果 Excel；本页的下拉框只列这类已保存结果。一次评估固定对应**单一模型、单一测试集**，不提供模型选择器，也不跨模型混合。
- 阈值口径：评估使用预测结果中已透传的 `predicted_label` 与 `decision_threshold`，**本页不提供判定阈值选择步骤**。
- 页面组织：单页六步配置，不设历史子签；步骤、信息卡、结果分区与其他工具页共用一套样式（`ToolWorkspace`）；模型性能为独立页面 `/evaluate/models`。

```text

  预测结果 [ predict_predictions_xxx ▾ ]
  ┌ 预测结果详情介绍 ────────────────────────────────┐
```

模型性能为独立页面：`/evaluate/models`，不叠加到本页 tab。

### 独立页面：模型性能（`/evaluate/models`）

只读查看某个已登记模型的提交级预测记录与离线性能图，不触发任何计算。

```text
预测评估 / 模型性能　查看已登记模型的历史性能记录

模型 [ 架构 ▾ ] [ 模型 ▾ ]  [ 查看 ]
搜索 [ 哈希/作者/提交信息 ]  时间范围 [ 开始 至 结束 ]  [ 查询 ] [ 重置 ]

表格：提交 | 作者 | 时间 | 提交信息 | 特征详情（悬停预览）| 是否为缺陷 | 缺陷引入概率
分页：上一页 / 页码 / 下一页 / 总数

查看抽屉（全屏）：模型指标 + 评估批次下拉 + 按类型分组的性能图
  批次下拉默认最新批次；无批次 → “暂无已登记性能图”并说明原因
  图缺失 → 显示原因，不显示空图框
```

- 模型选择是「架构 → 模型」级联，未选模型时「查看」禁用。
- 抽屉先选择评估批次，再渲染该批次图集；不同批次的同类型图互不覆盖。
- 表格按模型查询提交记录；「特征详情」悬停展示分组字段，不跳转详情页。
- 抽屉内的图为离线登记产物；缺图与指标不可用分别给出原因，不互相冒充。
- 本页只读：不提供重新评估、删除模型或调整指标的入口。

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 预测结果选择 | 已保存预测结果下拉框 | 01 步用下拉框列出系统已保存的预测结果（来自 `predict_batch` 成功任务，底层为预测结果 Excel）；选中后联动显示预测结果详情介绍：预测任务、单一模型与版本、单一测试集、样本规模、判定阈值、输入文件、生成时间、状态；不提供手动上传，不提供模型选择器 |
| 评估指标 | 指标多选 + 含义查看 | 按排序质量（02）/ 分类质量（03）/ 工作量感知（04）三步展示卡片；默认取配置值，主排序取首项；每项指标提供含义查看（悬停“?”展示名称、说明、公式，来自 `GET /api/evaluate/metrics` 的 `description` / `formula`）；无指标的分组不展示对应步骤 |
| 输出命名 | zip 名称 + 指标表名称 | 05 步用户只命名图集 zip 与指标表基名，均有默认值可修改；图集内每张图**不由用户命名**，由后端按标准命名单独保存并登记到 `model_figure`，便于后续按文件夹与数据库查找 |
| 确认配置 | 完整配置卡 | 05 步展示输入预测结果、模型 / 测试集、沿用阈值、已选指标、指标含义可查看、输出文件与图集命名策略；用户核对后进入 06 运行 |
| 运行 | 开始评估 | 06 步为运行；任务中禁用重复提交，可实时查看评估进度 |
| 结果 | 三段面板：进度 / 结果 / 结果文件 | 进度与其他工具页共用 `JobProgress`；结果面板含四项统计块、本次运行信息卡与评估指标表 / 图集预览；结果文件独立成块，只显示「评估图集 zip」下载与「评估指标表」CSV / Excel 导出 |
| 内部产物 | 不进入结果文件区 | manifest、summary、内部指标长表与混淆矩阵、逐张图片均作为内部记录保存，不单独占据结果文件区条目 |
| 历史产物 | 不在本页渲染 | 历史评估结果在 `/storage?section=library` 统一查看、下载与删除；本页不提供记录卡片区 |

## 4. 主流程

1. 在 01 步下拉框选择系统已保存的一次预测结果，页面显示该预测结果的详情介绍；该结果固定对应单一模型、单一测试集。
2. 在 02 排序质量、03 分类质量、04 工作量感知中确认指标勾选，逐项可查看指标含义；评估沿用预测结果中的 `predicted_label` 与 `decision_threshold`，无需选择阈值。
3. 在 05 步修改图集 zip 名称与指标表名称（均可保留默认值），核对完整配置后点击 [开始评估]（06）。
4. 在 06 步实时查看评估进度，成功后查看评估指标表与图集预览。
5. 在结果文件区下载「评估图集 zip」，并将「评估指标表」导出为 CSV 或 Excel；图集内每张图由后端标准命名并登记，可在产物库与数据库按批次查找。
6. 历史评估产物到「数据存储 / 产物库」查看或下载；查看模型性能时进入独立页面 `/evaluate/models`。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| 未选择预测结果 | 主按钮禁用并说明原因 |
| 指标为空 | 主按钮禁用，提示至少选一个指标 |
| 主排序不在已选指标 | 字段下方提示，阻止提交 |
| 预测结果缺真标签 | 下拉框不列出该结果；若导入后校验失败则前置拒绝，提示回预测页生成评估用结果 |
| 预测结果非单模型 / 单测试集 | 前置拒绝并说明评估只接受单一模型单一测试集的结果 |
| 图集 zip / 指标表名称非法 | 字段下方提示（空名、非法字符、超长） |
| 运行中 | 进度与当前阶段可见，可取消 |
| 缺图 | 图集内显示“暂无该图”及原因；不显示 404 |
| 性能页无离线图 | 显示“暂无已登记性能图”，保留动态结果 |
| 鉴权失败 | 禁用运行与下载，提示重新登录 |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 预测结果下拉清单 | `GET /api/jobs?kind=predict_batch&status=success` |
| 预测结果详情 | `GET /api/predict/preview/{job_id}`（复用预测预览信息） |
| 指标元数据与含义 | `GET /api/evaluate/metrics` |
| 启动评估 | `POST /api/evaluate/run` |
| 任务状态 / 重试 / 取消 | `GET /api/jobs/{id}`、`POST /api/jobs/{id}/retry|cancel` |
| 结果下载 | `GET /api/evaluate/outputs/{job_id}/{name}`（`zip` / `csv` / `xlsx`） |
| 图集与图登记查询 | `GET /api/figures?model_name=`、`GET /api/figures?job_id=` |
| 模型性能页 | `GET /api/commits?model_name=&with_features=1`、`GET /api/figures?model_name=`（返回批次清单）、`GET /api/figures?model_name=&job_id=`（按批次取图） |
| 模型与数据集清单 | `GET /api/models`、`GET /api/datasets` |
| 测试集明细 | `GET /api/commits` |

## 7. 响应式与可访问性

- ≥1200px：指标卡每行 4 个，图集预览每行 3 个。
- 768–1199px：指标卡 2–3 个，图集预览 2 个，指标表横向滚动。
- <768px：单列；名称输入与按钮整行；指标表横向滚动。
- 图表有文字摘要；指标含义“?”可键盘聚焦；名称输入可键盘操作；缺图原因用文字表达。

## 8. 验收清单

- [ ] 本页为单页六步配置，没有历史子签；01 步用下拉框选择已保存的预测结果，并同时显示该预测结果详情介绍。
- [ ] 一次评估固定单一模型、单一测试集，页面不展示模型选择器；下拉框只列带真标签的预测结果。
- [ ] 页面不出现判定阈值选择步骤，评估沿用预测结果中的 `predicted_label` 与 `decision_threshold`。
- [ ] 02 / 03 / 04 的每项指标都能查看含义（名称、说明、公式）；无可用指标的分组不展示该步骤。
- [ ] 05 步只需命名图集 zip 与指标表（均有默认值可修改），可查看完整配置；每张图由后端按标准命名单独保存并登记，不由用户逐个命名。
- [ ] 结果区为常驻三段面板（评估进度 / 评估结果 / 结果文件），与清洗、训练页一致。
- [ ] 结果文件区只显示「性能指标图集 zip」下载与「评估指标表」CSV / Excel 导出；manifest、summary、内部指标长表、混淆矩阵与逐图不进入结果文件区。
- [ ] 06 步可实时查看评估进度并可取消，完成后可查看评估结果。
- [ ] 模型性能是 `/evaluate/models` 独立页面，不是评估页子签，也不占顶级 tab；该页只读：模型级联 + 查询 + 表格 + 全屏图抽屉，无重算入口。
- [ ] 模型性能抽屉先选择评估批次，再渲染该批次图集；无批次时显示原因，不显示空图框。

- [ ] 指标只显示勾选项，主排序只能从勾选项中选择。
- [ ] 缺真标签或非单模型单测试集时拒绝评估并给出回到预测页的路径。

- [ ] 375px 下无横向溢出，图表与表格可用。
