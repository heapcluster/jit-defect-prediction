# 模型性能看板（ModelPerformance）

## 页面与路由
- 页面名：模型性能看板
- 路由：`/model-performance`（新增）
- 入口：顶部导航栏「模型性能」（新增菜单项）

## 功能概述
集中展示各机器学习模型的测试集综合性能：选定模型后查看其**性能评估图**（ROC / PR / 混淆矩阵 / 校准 / effort 等），并在下方表格中按提交逐条查看**测试集的 14 维特征、SZZ 自动缺陷判断、所选模型的缺陷引入概率**，支持联动查询与可视化。

## 布局（从上到下）

分块说明：

1. **模型选择区**（顶部）：架构下拉 → 模型下拉（级联），右侧「查看」按钮。
2. **查询栏**：搜索、时间范围、查询、重置（仿风险列表样式）。
3. **数据表格**（多维指标表）：列定义见下。
4. **分页器**：默认 20 / 页，上限 100。

## 交互
- **架构 → 模型两级级联 + 独立时间范围**：选「架构」后「模型」联动展示该架构下的模型；切换架构清空已选模型；模型不选 = 后端默认模型。时间范围可单独选择，作为 `start_time` / `end_time` 传给表格查询。
- **「查看」→ 性能评估图**：点击后**右侧弹出抽屉（Drawer）**，展示该模型的性能评估图集；随所选模型刷新。
- **查询**：按 搜索 / 时间范围 过滤表格；点「查询」或搜索框回车触发。
- **重置**：清空搜索与时间范围，重新查询。
- **动态概率**：「缺陷引入概率」列随顶部所选模型变化。
- **14 维特征**：单元格提供悬浮预览 / 点击抽屉，按五维度分组展示 Kamei 14 维。

## 表格列定义
| 列 | 字段 | 说明 |
|---|---|---|
| 提交 | `commit_hash` | 前 8 位，悬停显示完整哈希 |
| 作者 | `author_name` | — |
| 时间 | `committed_at` | — |
| 提交信息 | `message` | 超长省略，悬停全文 |
| **14 维特征** | `features` | 悬浮 / 抽屉预览，按五维度分组 |
| **SZZ 判断** | `is_defect` | `1` = 是（引入缺陷）/ `0` = 否 / `null` = 未打标；SZZ 自动打标 |
| **缺陷引入概率** | `risk_score` | 百分比显示，随所选模型动态变化 |

## 数据接口
| 用途 | 接口 |
|---|---|
| 架构 → 模型层级 | `GET /api/models` |
| 模型性能评估图 | `GET /api/figures?model_name=` |
| 多维指标表格 | `GET /api/commits?page=&size=&q=&model_name=&start_time=&end_time=&with_features=1&is_test=1` |

### 性能评估图取图方式
- `GET /api/figures?model_name=` 返回该模型的逐模型图集：`figure_type`（`roc` / `pr` / `confusion` / `calibration` / `effort` / `feat_importance`）、`title`、`file_path`。
- `<img>` 带不了 `X-API-Key`，前端用 `fetch`（带鉴权头）取图片二进制再转 `ObjectURL` 渲染。
- 每线对比图（`roc_curves.png` / `metric_bars.png` / `effort_curves_loc.png`）挂在 `data_model/pipelines/{line}/reports/figs/*.png`，如看板需要可按线补充展示。

## 说明
- 14 维特征只展示 Kamei 14 维，且是 **log 变换值（可为负）**，不是原始行数/人数；语义 / 融合 / 端到端特征不落关系表。
- SZZ 真标签来自 `commit_feature`（原 `commit_label` 已并入），对外字段名 **`is_defect`**：`1` / `0` / `null`（未打标）；manual 不纳入。
- 下方表格固定 `is_test=1`，展示**全部测试集**的逐条结果（14 维 + SZZ + 所选模型概率）；「查看」抽屉里的图与指标同样是测试集口径。本页不展示训练集提交。
- 「缺陷引入概率」= 所选模型的 `risk_score`，模型切换后整列刷新。
