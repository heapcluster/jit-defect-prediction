# 风险列表页（RiskList）

## 页面与路由
- 页面名：风险列表
- 路由：`/`
- 入口：导航栏「风险列表」

## 布局（从上到下）

```
┌────────────────────────────────────────────────────────────────────┐
│ 风险列表                                                            │
├────────────────────────────────────────────────────────────────────┤
│ 架构[▾] 模型[▾] 时间[__至__] [刷新]                                 │
│ 搜索[哈希/作者/提交信息] 架构[▾] 模型[▾] 时间[__至__] [查询][重置] │
├────────────────────────────────────────────────────────────────────┤
│ 风险            提交        作者    时间          提交信息           │
│ 高风险 83.0%   a1b2c3d4   dev1    2024-03-01   fix: null ptr      │
│ 中风险 62.1%   e5f6g7h8   dev2    2024-02-28   feat: add x        │
│ …                                                                  │
├────────────────────────────────────────────────────────────────────┤
│                                   ‹ 1 2 3 ›       共 1234 条        │
└────────────────────────────────────────────────────────────────────┘
```

分块说明：

1. **同步范围行**：架构[▾] 模型[▾] 时间[__至__] [刷新]。这一行的三个条件**只用于刷新**，与下方查询栏互不影响；不使用搜索。
2. **查询栏**：搜索[哈希/作者/提交信息] 架构[▾] 模型[▾] 时间[__至__] [查询][重置]。这一行有自己的架构 / 模型 / 时间，**只用于查询**；搜索只匹配 hash / 作者 / message。
   - 架构 / 模型：架构 → 模型两级级联；模型随架构联动，切换架构清空模型
   - 时间：日期范围选择器（`daterange`），独立于架构 / 模型，可单独选择
   - 查询 / 重置：只查已入库数据，不触发计算
3. **主区：风险数据表格**，列为：
   | 风险 | 提交 | 作者 | 时间 | 提交信息 |
   - 风险列：风险等级标签 + 风险百分比（如「高风险 83.0%」），按 `risk_score` 降序
   - 提交列：`commit_hash` 前 8 位（悬停显示完整哈希，点击复制）
4. **底部**：分页器（prev / pager / next / total）。

## 交互
- **同步范围（架构 → 模型 + 独立时间范围）**：只读「同步范围行」的架构 / 模型 / 时间；选「架构」后「模型」联动，切换架构清空模型，模型不选 = 后端默认模型。
- **查询筛选（搜索 + 架构 / 模型 / 时间）**：只读「查询栏」自己的搜索 / 架构 / 模型 / 时间；结果按 `risk_score` 降序；点「查询」或搜索框回车触发。搜索只匹配 hash / 作者 / message。
- **刷新**：只把「同步范围行」的架构 / 模型 / 时间作为 `line` / `model_name` / `start_time` / `end_time` 调 `POST /api/sync`，**不使用搜索、不使用查询栏的条件**；提交后立即返回，按钮进入 loading，轮 `/api/sync/status`，完成后按查询栏当前条件重新查询。
- **重置**：只清空「查询栏」的搜索 / 架构 / 模型 / 时间并重新查询；同步范围行不变。
- **分页**：默认 20 / 页，上限 100。
- **行交互**：点击行跳转提交详情 `/commit/:hash`；点击哈希复制。

## 数据接口
| 用途 | 接口 |
|---|---|
| 架构 → 模型层级 | `GET /api/models` |
| 风险列表 | `GET /api/commits?page=&size=&q=&model_name=&start_time=&end_time=` |
| 刷新：同步提交 | `POST /api/sync?line=&model_name=&start_time=&end_time=` |
| 刷新：同步进度 | `GET /api/sync/status` |

`GET /api/models` 响应（供架构 / 模型两级下拉；时间范围不来自本接口）：

```json
{
  "lines": [
    { "line": "expert", "label": "专家特征", "models": ["lr_v1", "rf_v1", "xgb_v1", "lgbm_v1", "et_v1", "svm_v1", "mlp_deep_v1", "tabnet_v1"] },
    { "line": "semantic", "label": "语义", "models": ["lr_semantic_v1", "…"] },
    { "line": "fused", "label": "融合", "models": ["lr_fused_v1", "…"] },
    { "line": "e2e", "label": "端到端", "models": ["codebert_e2e_v1"] }
  ]
}
```

- `line`：架构标识，取值 `expert` / `semantic` / `fused` / `e2e`。
- `label`：架构的中文显示名；若后端不返回，前端可本地映射兜底。

## 说明
- 页面有**两套独立筛选**：同步范围行（架构 / 模型 / 时间，只给刷新）与查询栏（搜索 / 架构 / 模型 / 时间，只给查询）；同名控件互不共享状态。
- 搜索只影响查询结果（hash / 作者 / message），**不能作为刷新 / 同步的范围**。
- 页面无「补齐 / 补齐缺口」按钮；「刷新」是唯一同步入口。
- 「刷新」按同步范围行的架构 / 模型 / 时间触发同步，不使用搜索或查询栏条件；按查询栏条件重新查列表用「查询」。
- 数据源：`model` 表按 `line` 分组即可（`model.line` 列已存在）。
