# 风险列表页（RiskList）

## 页面与路由
- 页面名：风险列表
- 路由：`/`
- 入口：导航栏「风险列表」

## 布局（从上到下）

```
┌────────────────────────────────────────────────────────────────────┐
│ 风险列表                                               [刷新]       │
├────────────────────────────────────────────────────────────────────┤
│ 搜索[哈希/作者/提交信息] 架构[▾] 模型[▾] 时间[____ 至 ____] [查询][重置] │
├────────────────────────────────────────────────────────────────────┤
│ 风险            提交        作者    时间          提交信息           │
│ 高风险 83.0%   a1b2c3d4   dev1    2024-03-01   fix: null ptr      │
│ 中风险 62.1%   e5f6g7h8   dev2    2024-02-28   feat: add x        │
│ …                                                                  │
├────────────────────────────────────────────────────────────────────┤
│                                   ‹ 1 2 3 ›       共 1234 条        │
└────────────────────────────────────────────────────────────────────┘
```

分块说明：

1. **顶部操作行**：仅右侧一个「刷新」按钮。无描述文案、无统计卡片、无「补齐缺口」。
2. **筛选栏**（横向 inline）：
   - 搜索：文本输入框，占位「哈希/作者/提交信息」，回车触发查询
   - 架构：下拉框（`expert` / `semantic` / `fused` / `e2e`）
   - 模型：下拉框，随「架构」联动展示该架构下的模型
   - 时间：日期范围选择器（`daterange`）
   - 查询 / 重置：两个按钮
3. **主区：风险数据表格**，列为：
   | 风险 | 提交 | 作者 | 时间 | 提交信息 |
   - 风险列：风险等级标签 + 风险百分比（如「高风险 83.0%」），按 `risk_score` 降序
   - 提交列：`commit_hash` 前 8 位（悬停显示完整哈希，点击复制）
4. **底部**：分页器（prev / pager / next / total）。

## 交互
- **架构 → 模型级联**：选「架构」后，「模型」下拉联动展示该架构下的模型；切换架构会清空已选模型。两级都不选 = 使用后端默认模型。
- **查询**：按 搜索 / 架构+模型 / 时间范围 过滤，结果按 `risk_score` 降序；点「查询」或搜索框回车触发。
- **重置**：清空搜索、架构、模型、时间，重新查询。
- **分页**：默认 20 / 页，上限 100。
- **行交互**：点击行跳转提交详情 `/commit/:hash`；点击哈希复制。

## 数据接口
| 用途 | 接口 |
|---|---|
| 架构 → 模型层级 | `GET /api/models` |
| 风险列表 | `GET /api/commits?page=&size=&q=&model_name=&start_time=&end_time=` |

`GET /api/models` 响应（供架构/模型两级下拉，一次拉全量）：

```json
{
  "lines": [
    { "line": "expert", "label": "专家特征", "models": ["lr_v1", "rf_v1", "xgb_v1", "lgbm_v1", "et_v1", "svm_v1", "mlp_deep_v1", "tabnet_v1"] },
    { "line": "semantic", "label": "语义", "models": ["lr_semantic_v1", "…"] },
    { "line": "fused", "label": "融合", "models": ["lr_fused_v1", "…"] },
    { "line": "e2e", "label": "端到端", "models": ["codebert_e2e_v1"] }
  ]
}
```

- `line`：架构标识，取值 `expert` / `semantic` / `fused` / `e2e`。
- `label`：架构的中文显示名；若后端不返回，前端可本地映射兜底。

## 说明
- 列表查询**不再传** `min_risk`（最低风险）与 `has_label`（仅看已确认），这两个筛选已从页面移除。
- 模型筛选 = 架构（`line`）+ 模型（`model_name`）两级；列表接口只认 `model_name`，`line` 不进列表查询。
- 数据源：`model` 表按 `line` 分组即可（`model.line` 列已存在）。
