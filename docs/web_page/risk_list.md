# 风险列表页（RiskList）

实现状态：部分　期次：一期

## 一句话

按数据集、模型与两行独立筛选浏览已导入库中的提交风险，支持只读导出、进入提交详情，以及带 commit/model 跳转⑦解释与⑧定位子页；本页不收集数据、不加载模型、不触发预测或其他业务计算。

## 入口与导航

- 功能⑤（模型预测）tab 内风险列表子视图（子签）；`/` 重定向到 `/predict` 并选中本子视图，入口索引见 [README.md](README.md)。
- 行点击或 [详情] 进入 `/commit/:hash`，携带当前 `model_name` 与列表筛选态；返回时恢复两行控件、页码和滚动位置。
- [解释] 进入 `/explain?commit_hash=&model_name=`，[定位] 进入 `/localization?commit_hash=&model_name=`；两者均为⑤子页，也可独立访问，不要求本页已导入库。
- 趋势数据点经 `start_time` / `end_time` / `model_name` query 下钻到本页；空库引导至 [数据管理](storage.md)。

## 控件与接口映射

| 控件 | 端点 | 说明 |
|---|---|---|
| 数据范围行 [数据集▾] | `GET /api/datasets` | 只列已导入数据集；缺省读 `user_config.default_dataset` |
| 数据范围行 [架构▾][模型▾] | `GET /api/models` | 两级级联，切换架构清空模型；必须显式选择模型，未选时显示空态并禁用查询 |
| [应用范围] | `GET /api/commits?dataset_id=&model_name=` | 只改变数据范围并读取库；保留查询筛选行的独立编辑态 |
| 查询筛选行 [搜索][时间][查询] | `GET /api/commits?page=&size=&q=&model_name=&start_time=&end_time=&dataset_id=` | 仅查询库中数据；q 匹配 hash 前缀、作者、message |
| [重置] | 同上 | 只清空搜索与时间并重查，不改数据范围行 |
| 风险等级标签 | `GET /api/config`（`risk_high_threshold` / `risk_mid_threshold`） | 只对返回的 risk_score 作展示分档；概率本体不变 |
| SZZ 列 | `GET /api/commits`（`items[].is_bug_inducing`） | 1/0/null 三态，null 显示「无 SZZ 标记」 |
| [导出 CSV][导出 XLSX] | `GET /api/storage/export?table=prediction&format=csv\|xlsx&dataset_id=&model_name=&q=&start_time=&end_time=` | 只导出当前库中结果，不补算缺行；CSV 带 UTF-8 BOM |
| 行点击 / [详情] | 路由 `/commit/:hash`；详情数据见 [commit_detail.md](commit_detail.md) | 携带模型与列表筛选态，不在跳转时预测 |
| [解释] | 路由 `/explain?commit_hash=&model_name=` | 进入⑦解释子页并预填对象；本页不触发解释计算 |
| [定位] | 路由 `/localization?commit_hash=&model_name=` | 进入⑧定位子页并预填对象；仍需定位页提供仓库与预测文件 |
| 分页器 | `GET /api/commits`（`page` / `size`） | 默认 20/页，上限 100；固定 risk_score 降序、hash 次序 |
| [去数据管理导入] | 路由 `/storage`；导入 `POST /api/storage/import` | 仅空库引导，不在本页内嵌导入或运行业务模块 |

## 交互流程

1. 进入页面并行读取 `GET /api/config`、模型与数据集清单，再按默认范围调用 `GET /api/commits`。配置或清单失败不得被当成库空。
2. **两行独立**：数据范围行只编辑数据集、架构和模型；查询筛选行只编辑搜索与时间。[应用范围] 使用查询行已生效条件重查，[重置] 不清空数据范围行。
3. 架构 → 模型级联只用于产生 `model_name`，`line` 不传给 commits；未选模型时显示空态并禁用查询，不做默认解析或版本序回退。
4. [查询] 或搜索回车读取第一页；分页保留全部已生效条件。结果只含库中已有预测行，按 `risk_score DESC, commit_hash ASC` 排序。
5. 设置页修改风险高/中阈值后，本页重新读取配置并更新等级标签；不重写 prediction，不改变 risk_score，也不触发趋势或预测任务。
6. 导出使用当前已生效范围与筛选条件；缺预测记录不在导出中补 0，未打标标签保持空值。
7. 点击行进入详情并保存列表状态；从详情返回后恢复两行筛选、页码与滚动位置。
8. 库空时显示导入引导；导入完成后用户回到本页重新查询，页面不会把上传文件直接伪装成已导入结果。

## 空态与错误

- 加载中显示骨架屏；库空显示「尚未导入预测数据」和 [去数据管理导入]；筛选无结果显示「当前筛选条件下没有提交」与清空入口。
- `GET /api/commits` 失败显示错误与 [重试]，保留控件值，不以空表代替失败。
- 未预测提交在列表中表现为缺行，不得显示风险 0；`is_bug_inducing=null` 不得归入非缺陷。
- 非法分页、时间格式或筛选参数返回 40001；40100 禁用导出；数据集、模型或记录不存在返回 40400；内部错误返回 50000。
- 若页面出现后端图 URL 或缩略图，必须用带 `X-API-Key` 的 fetch 转 ObjectURL，并在替换或卸载时释放；不得使用 `<img>` 直连鉴权地址。

## 验收

- 数据范围行与查询筛选行状态独立；[重置] 只清查询行，[应用范围] 不丢查询条件。
- 全部查询、分页和导出只读导入后的库；页面无收集、同步、刷新模型、预测或评估按钮。
- 库空与筛选无结果文案不同，库空可一键到 `/storage`。
- 表格六列齐全，风险排序与分页稳定；未预测缺行不补 0，SZZ 三态正确。
- 风险高/中阈值来自 `GET /api/config`，修改后标签联动且概率不变，重启后配置仍保持。
- CSV/XLSX 导出筛选生效、字段完整、中文不乱码；缺预测与未打标保持空值。
- 行点击携带模型进入详情，返回后筛选、页码与滚动位置恢复；[解释]/[定位] 带 commit/model 进入⑤对应子页且不触发计算；图片若存在均鉴权 fetch。
