# 风险列表页（RiskList）

## 页面与路由
- 页面名：风险列表
- 路由：`/`
- 入口：导航栏「风险列表」

## 概述
- 列表筛选的搜索字段统一改为「提交信息」，**只对提交信息（message）做关键字检索**，不再搜哈希/作者。
- 原右上角「刷新」重构为「同步」，整行下移到标题下方，成为独立的**同步操作栏**。
- 同步操作栏：选定「架构 → 模型」与「时间范围」后点「同步」，后端从 Camel 仓库拉取该时间段的 commit、用所选模型预测入库，完成后刷新下方列表。

## 布局（从上到下）

```
┌──────────────────────────────────────────────────────────────────────┐
│ 风险列表                                                              │
├──────────────────────────────────────────────────────────────────────┤
│ 同步： 架构[▾] 模型[▾]  时间范围[____ 至 ____]  [同步]                │
├──────────────────────────────────────────────────────────────────────┤
│ 筛选： 提交信息[____]  架构[▾] 模型[▾]  时间范围[____ 至 ____] [查询][重置] │
├──────────────────────────────────────────────────────────────────────┤
│ 风险            提交        作者    时间          提交信息             │

│                                    ‹ 1 2 3 ›       共 1234 条        │

```

分块说明：

1. **同步操作栏**（标题下，替换原操作区）：架构下拉 → 模型下拉（级联）+ 时间范围选择器 + 「同步」按钮。**无搜索框**。
2. **筛选栏**：提交信息搜索 + 架构/模型级联 + 时间范围 + 查询 / 重置。与同步栏互相独立。
3. **风险数据表格**：风险等级 / 提交哈希 / 作者 / 时间 / 提交信息，按 `risk_score` 降序。
4. **分页器**：默认 20 / 页，上限 100。

## 交互
- **架构 → 模型级联**：同步栏与筛选栏共用同一套 `GET /api/models` 数据；选架构后模型联动，切换架构清空已选模型。
- **同步**：选定模型 + 时间范围 → 点「同步」→ 后端拉取该区间 commit 并预测入库（后台任务）→ 完成后刷新列表。
- **同步加载态**：
  - 点击后按钮置 loading（`同步中…` 禁用），不阻塞其它操作；
  - 进度轮询 `GET /api/sync/status`（`running` / `total` / `done` / `current_hash`）；
  - 完成 → success 提示 + 刷新列表；失败 → error 提示（含 `last_error`）；
  - 服务端串行锁：已在同步中再点，提示「已在同步中」。
- **筛选**：提交信息 / 架构+模型 / 时间范围过滤，查询 / 重置。
- **行交互**：点击行进入提交详情 `/commit/:hash`；点击哈希复制。

## 数据接口
| 用途 | 接口 |
|---|---|
| 架构 → 模型层级 | `GET /api/models` |
| 同步（拉取 + 指定模型预测入库） | `POST /api/sync`（`model_name` + `start_time` + `end_time`） |
| 同步进度 | `GET /api/sync/status` |
| 风险列表 | `GET /api/commits?page=&size=&q=&model_name=&start_time=&end_time=` |

## 说明
- 同步是后台长耗时任务（单条现算 P50 ≈ 108 秒），前端**不得同步等待**，靠 `GET /api/sync/status` 看进度。
- 同步栏与筛选栏是两个独立区域：同步栏负责「拉取 + 预测入库」，筛选栏只负责「过滤展示」。
- 列表搜索 `q` 只匹配提交信息（message）；接口当前 `q` 若仍匹配哈希/作者，需后端收窄口径。
