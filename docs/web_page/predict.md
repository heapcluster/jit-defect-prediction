# 模型预测页（Predict）

功能⑤　顶级 tab「模型预测」　路由 `/predict`

## 1. 页面定位

- 目标：选择训练阶段已保存的模型和训练产出测试集，按判定阈值执行批量预测，查看进度、二维表结果并下载核心产物。
- 入口：顶级「模型预测」tab；训练完成后的结果页可引导到此。
- 出口：提交详情 `/predict/commit/:hash?model_name=&job_id=`；预测结果可送入⑥预测评估；历史预测结果到「数据存储 / 产物库」查看。
- 不负责：训练模型、计算解释、行级定位、模型运行时管理；本页只编排 `predict_batch` 任务并展示结果。
- 页面组织：单页配置，不设历史子签；提交详情为独立页面，解释与定位是详情页内的普通板块，不设独立页面。
- 预测结果二维表每一行都可以点击进入“预测详情页”（即提交详情页），携带 `commit_hash`、`model_name`、`job_id`。
- 预测详情页主体是当前 commit 的预测详情信息；其后展示针对该 commit 的“预测结果解释”和“缺陷定位及修复”两个普通板块，UI 不刻意展示功能编号 ⑦ / ⑧。

## 3. 区域与组件

| 区域 | 内容 | 交互与约束 |
|---|---|---|
| 输入选择 | 两组下拉框：已训练模型、待预测测试集 | 模型下拉直接列出已登记的 `.pkl` 模型文件（按模型名展示），不列 ZIP、不要求上传；测试集只能来自训练成功任务产出的 `train_testset`；切换模型默认带出同任务测试集；用户可改选其他训练任务测试集，但必须校验特征线和 schema；无手动上传 |
| 模型详情 | 模型名称、算法、特征线、模型版本、训练任务、状态、创建时间 | 选中模型后显示；不显示本地路径、长 hash 或原始 JSON |
| 测试集详情 | 测试集名称、训练任务、样本数、正样本、负样本、未标注、切分方式 / 时间边界、manifest、生成时间 | 选中测试集后显示；训练测试集标签必须非空；样本规模从训练任务摘要读取 |
| 判定阈值 | 单个滑杆 + 数值标签 | 范围 0.05–0.95，步长 0.01，默认 `0.5`；页面不展示阈值说明文字；`risk_score >= threshold` 判为引入缺陷 |
| 确认输出与配置 | 预测结果 / 导出文件名称 + 配置摘要 | 一个字段同时作为预测结果名称、下载文件基础名、产物库显示名；默认 `<模型名>_预测结果`；不填扩展名；摘要展示模型、测试集、样本规模、阈值、输出和数据库保存 |
| 运行 | `开始预测` 按钮 | 独立第 04 步，占满整行；无模型、无测试集、阈值非法或运行中时禁用 |
| 预测进度 | `JobProgress` | 文案为“当前正在预测，已完成 X / Y 条提交”；成功 / 失败 / 取消各有明确文案；重试使用原任务，运行中可取消 |
| 结果统计 | 输入提交、成功预测、失败、判定阈值 | 四项统计卡；未出结果显示 `—` |
| 结果摘要 | 预测模型、待测数据、判定阈值、失败样本、完成时间、已入库行数 | 仅在成功任务显示；失败样本最多展示 100 条摘要，详细原因由产物内部记录承载 |
| 数据库保存 | `prediction` 表入库状态 | 批量预测成功后，所有成功行的预测结果二维表必须写入 `prediction` 表；页面显示已入库行数；入库失败视为任务失败并允许重试 |
| 预测结果预览 | 分页二维表 | 展示预测结果表全部字段，不展示内部特征列；默认每页 20 行，可翻页浏览全量结果；每一行均可点击进入预测详情页（提交详情页），并携带 `commit_hash`、`model_name`、`job_id` |
| 结果文件 | 一个逻辑文件「预测结果」 | 下载菜单只有 CSV / Excel；CSV 读取规范主表，Excel 从同一主表按需生成；manifest / summary / failed_samples 不展示 |
| 历史产物 | 不在本页渲染 | 历史预测结果在 `/storage?section=library` 查看与下载；本页不提供历史记录区 |

## 4. 主流程

1. 在 `01` 选择已训练模型；系统自动带出同训练任务的测试集，用户可改选其他训练任务产出的测试集。
2. 查看模型详情与测试集详情，确认模型特征线和测试集 schema 兼容。
3. 在 `02` 调整判定阈值；默认 `0.5`，范围 0.05–0.95，步长 0.01；页面不展示阈值说明文字。
4. 在 `03` 填写或修改预测结果 / 导出文件名称，并核对配置摘要。
5. 在 `04` 点击 [开始预测]，提交模型、测试集、阈值和输出名称，创建 `predict_batch` 任务。
6. 页面轮询任务进度，显示“已完成 X / Y 条提交”；支持取消与失败后重试。
7. 成功后把全部成功行的预测结果二维表写入 `prediction` 表，并发布核心产物文件。
8. 结果区展示统计、摘要、分页预览与入库行数。
9. 在结果文件区只下载「预测结果」一个逻辑文件，下载时选择 CSV 或 Excel。
10. 点击任意预览行进入该条 commit 的预测详情页；页面先展示预测详情信息，再展示针对当前 commit 的预测结果解释与缺陷定位及修复两个普通板块，解释与定位的进一步入口只在详情页提供。
11. 历史预测结果到「数据存储 / 产物库」查看；评估页读取预测结果作为输入。

## 5. 状态与反馈

| 状态 | 表现 |
|---|---|
| 无模型 / 无测试集 | 主按钮禁用；下拉框空态说明需要训练产物 |
| 模型与测试集不兼容 | 显示特征线或 schema 不匹配原因；主按钮禁用 |
| 阈值非法 | 按钮禁用；滑杆限制在 0.05–0.95 |
| 运行中 | 显示已完成条数，可取消；重复提交禁用 |
| 成功 | 统计、摘要、分页预览、入库行数和结果文件可见 |
| 数据库保存失败 | 任务失败；显示可读原因，文件产物保留，可重试 |
| 失败 | 保留输入、阈值和输出名称，显示原因与重试 |
| 预览为空 | 显示“预测完成后在这里展示结果” |
| 鉴权失效 | 禁用运行、下载与入库操作，提示重新登录 |

## 6. 接口映射

| 能力 | 接口 |
|---|---|
| 已训练模型列表 | `GET /api/models` |
| 训练任务与测试集产物 | `GET /api/jobs?kind=train&status=success` |
| 启动预测 | `POST /api/predict/run` |
| 任务状态 / 重试 / 取消 | `GET /api/jobs/{id}`、`POST /api/jobs/{id}/retry`、`POST /api/jobs/{id}/cancel` |
| 分页预览 | `GET /api/predict/preview/{job_id}?page=&size=` |
| 核心结果下载 | `GET /api/predict/outputs/{job_id}/{name}?format=csv\|xlsx` |
| 数据库保存 | `prediction` 表，批量预测服务写入 |
| 提交详情 | `/predict/commit/:hash?model_name=&job_id=` |
| 历史预测结果 | `/storage?section=library` |

## 7. 响应式与可访问性

- ≥900px：输入与详情两列；<900px 输入单列。
- <768px：配置单列，按钮整行，预测结果表内部横向滚动。
- 预览表行可点击并支持键盘操作；“查看详情”按钮阻止行点击冒泡。
- 阈值、模型、测试集、输出名称均有可见标签或 `aria-label`；状态使用文字说明。
- 页面不展示阈值说明文字，但阈值滑杆必须有可见数值标签。
