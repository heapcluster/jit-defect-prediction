## 2 · 文件模板（§6.2）

每个提示词保存为独立 Markdown 文件，命名 `{测试类型}_{模块/功能}_{序号}.md`，含：

```text
# 提示词：{简要描述}
## 基本信息
- 使用工具：
- 使用日期：YYYY-MM-DD
- 关联测试文件：
## 提示词原文
{完整内容，不得改写}
## 大模型输出摘要
{摘要}
## 人工审核与修改记录
- 审核结果：直接采纳 / 修改后采纳 / 弃用
- 修改内容：
- 弃用原因：
```

本目录的提示词须与测试文件头部的「提示词见：`prompts/unit_xxx_01.md`」互相可查。

## 3 · 约束

- 来源标签逐条落在测试函数旁；核心业务断言（概率区间、鉴权码、14 维列序、数据一致性）须人工复核（AI-R4）。
- AI 生成用例须经人工审核与验证后方可纳入交付（AI-R3）；「人工审核与修改记录」不得由 AI 代填为「已审核」。
- 提示词中不得含密钥、令牌、个人数据或真实数据集内容，上传前须脱敏。
