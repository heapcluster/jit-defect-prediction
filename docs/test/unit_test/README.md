## 2 · 用例设计

按课程要求，每个核心函数至少「正常 / 边界 / 异常」三例，使用等价类划分与边界值分析；外部依赖（数据库、模型文件、第三方 API）用 Mock / Stub 隔离；断言针对业务结果，禁止 `assert True` 或只判断「未抛错」。

**待补**：逐函数「三例」覆盖清单、参数化用例与逐条来源标注，由各线作者按当前提交补齐。当前副本中部分文件已有文件级来源标签（如 `test_timeutil.py` 的 `# [AI生成] …`、`RiskList.spec.js` 的 `// [AI生成-人工修改] …`），但**不是指南 §2.1 要求的用例来源比例注释**（见 §5）。
