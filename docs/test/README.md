## 5 · 运行说明

| 类型 | 命令 | 前置 |
|---|---|---|
| 单元（后端） | `cd backend && python -m pytest -q --cov=app --cov-branch --cov-report=html:htmlcov` | 隔离 MySQL 测试库；`pytest-cov` |
| 单元（模型线） | `cd data_model && python -m pytest -q` | `data_model/environment.yml` |
| 单元（前端） | `cd frontend && npm run test:unit -- --coverage` | Node 版本见 `frontend/package.json` |
| 集成 | `cd backend && python scripts/integration_cases.py --json out.json` | 后端 `uvicorn` 已启动、本机 MySQL 可用 |
| 安全 / 性能 | `python scripts/security_cases.py`；`python scripts/perf_loop.py`；`python scripts/load_test.py` | 同上；`load_test.py` 输出并发 / 吞吐 / 错误率 |
| 系统异常 | `python scripts/system_exceptions.py --scenario all` | 自起 / 自停独立子进程，不移动真实权重 |
| 验收对照清单 | `python scripts/acceptance_scenarios.py` | 抽取 `openspec/specs/` 活规格 Scenario |
| 系统 / 验收走查 | 浏览器四页面现场走查 | 见 [`../common/local-runbook.md`](../common/local-runbook.md) |

交付包内 [`unit_test/tests/`](unit_test/tests/README.md)、[`integration_test/scripts/`](integration_test/scripts/README.md) 是**实体代码副本**，仓库内原位置不移动（CI / pytest / vitest 路径绑定原目录）；副本不参与仓库内 CI，上传前须按最终 SHA 重新同步。
