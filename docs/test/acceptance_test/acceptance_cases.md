## 1 · 覆盖统计

| 验收类别 | 条数 | 编号 | 课程要求 |
|---|---:|---|---|
| 功能验收 | 9 | A-01 ~ A-09 | 核心业务闭环、需求覆盖率、预测准确性 |
| 数据验收 | 3 | A-10 ~ A-12 | 数据完整性、展示一致性、跨模块链路 |
| 界面验收 | 4 | A-13 ~ A-16 | 展示完整性、交互合理性、错误反馈 |
| 文档验收 | 4 | A-17 ~ A-20 | 用户手册 / API 文档 / 测试交付物 / 缺陷遗留 |
| **合计** | **20** | | ≥15 条，且覆盖四类 |

- 每条用例对应一条可追溯的需求条目（列「对应需求条目」），不照抄课程原文的「用户登录 / 数据上传 / 导出报告」通用示例——本项目无这些功能，业务闭环以 `docs/overview.md` 的「同步 → 预测 → 四页面展示」为准。
- 用例按**最终用户视角**编写：描述「用户要做什么、期望看到什么」，而不是代码断言或 HTTP 状态码；接口级断言属于系统测试与集成测试。
- 重点用例（★）涉及预测结果准确性、数据展示一致性与核心异常反馈，其判定标准须人工逐条确认。
- **通过标准**：每条结论只填「通过」或「不通过」，不允许「部分通过」「待定」；未执行的用例保持空白，不得预填结论。
