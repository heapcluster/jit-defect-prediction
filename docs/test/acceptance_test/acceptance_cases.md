## 4 · 整改与复验要求

1. 按同一提交 SHA 组织一次**用户视角现场演示**，逐条执行 A-01~A-20，把截图 / 录屏按编号放入 `execution_records/`（脚本运行时自动创建）。
2. 修复 #222、#217 并回归至 25 模型全部可预测；补标准测试集准确率 / 召回率实测，由验收方确认量化阈值后重判 A-02、A-03。
3. 补 A-09、A-14、A-17 的专项取证；裁定 #220 六处文档偏差后重判 A-18。
4. 补齐覆盖率报告、验收执行记录与 AI 用例人工审核记录后重判 A-19、A-20。
5. 复验时重新填写「实际结果 / 验收结论」，并由验收方给出最终结论。
