## 1 · 约束与未闭合项

- **AI-R5**：验收方案与验收结论必须人工撰写，AI 不得代写、不得代判「是否接受系统交付」；本目录**不得**存放「生成验收方案 / 验收结论」的提示词。
- **验收阈值人工确认**：预测准确性判定的阈值（如准确率 ≥80%）必须人工确认，不得直接采用 AI 建议值；判定须基于标准测试集实测，见 [`../acceptance_cases.md`](../acceptance_cases.md) §3。
- **AI-R3**：20 条验收用例均为 `[AI生成]` 初稿，审核记录待签署；「实际结果」「验收结论」由验收人现场填写，AI 不代填，不允许「部分通过 / 待定」。
- 用例须标注来源；复核后确有修改的改标 `[AI生成-人工修改]` 并写明修改点，人工重写的改标 `[手写]`，使采纳率落在 40%–70% 合理区间（§6.3）。
- 逐条执行截图 / 录屏见 [`../execution_records/README.md`](../execution_records/README.md)；课程红线：未实际执行、仅提交文档该部分计 0 分。
- 提示词不得含密钥、令牌、个人数据或真实数据集内容，上传前脱敏。
