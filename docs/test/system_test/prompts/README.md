## 1 · 口径差异留痕

`system_cases_pages_01.md` 的输出摘要写「24 条用例、反向 14 条（58%）」，而用例证据文件头部与正式文档 [`../test_cases.md`](../test_cases.md) §1 按逐条计数为 **15 / 24 = 62.5%**。以正式用例表为准，差异待原作者核对，**不静默改数**。

## 2 · 约束与未闭合项

- **AI-R5**：测试计划与总结报告必须人工撰写，AI 只能润色格式；核心结论、风险评估、发布建议由 neon 判断。本目录**不得**存放「生成测试计划 / 总结」的提示词。
- **AI-R3**：24 + 6 条用例均为 `[AI生成]` 初稿，审核记录待签署；未经审核不得计入最终交付。
- **AI-R4**：涉及预测结果准确性的 ★ 重点用例（T-ST-01/02/04/05/14/15）核心断言须人工编写或逐条复核。
- Bug 报告可由 AI 生成初稿，但复现步骤须人工验证、截图须人工采集；现有 Bug 清单见 [`../bug_list.md`](../bug_list.md)。
- 用例文档每条须在「来源」列标注 `[AI生成]` / `[AI生成-人工修改]` / `[手写]`；复核后确有修改的须同步改标签，使采纳率落在 40%–70% 合理区间（§6.3）。
- 提示词不得含密钥、令牌、个人数据或真实数据集内容，上传前脱敏。
