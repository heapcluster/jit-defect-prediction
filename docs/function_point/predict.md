# 提交风险预测

纵向功能点：对单条提交现算特征并给出风险分。跨模型线、后端、前端。

## 各层职责
| 层 | 职责 |
|---|---|
| 模型线 | 训练并交付模型（四方案 25 模型），提供现算预测能力 |
| 后端 | `POST /api/predict` 现算特征 + 预测；`prediction` 表存各模型结果 |
| 前端 | 提交详情页/风险列表展示 risk_score 与判定 |

## 关键字段
| 字段 | 作用 |
|---|---|
| `prediction.risk_score` | 风险概率 |
| `runtime_setting` 阈值 | 风险分级（高/中/低） |

## 验收
- 给定 commit + model_name 能返回风险分；判定与阈值一致。
