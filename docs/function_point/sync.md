# 数据同步

纵向功能点：从 Git 源仓库取提交、按选中模型现算预测并入库。跨后端、数据库、模型线。

## 各层职责
| 层 | 职责 |
|---|---|
| 模型线 | 提供单条现算特征 + 推理能力 |
| 后端 | `POST /api/sync`（按条数 / 按 commit 时间区间 / 按选中模型）与 `catchup` 拉取并补算；`GET /api/sync/status` 状态；`GET /api/sync/stream` SSE 进度（当前前端未接） |
| 数据库 | `commit` / `commit_feature` / `prediction` 写入 |

## 分工口径
本功能点是**唯一**会触发计算的能力。列表（`/api/commits`）、趋势（`/api/trends`）全部只读已入库结果；前端「查询」不补算，「补齐这段时间」才补算。

## 验收
- 增量 / 补齐同步幂等：同一批重复提交不产生重复行；
- 状态可查、进度可订阅；后台任务在请求返回后继续跑，前端不靠超时判断成败；
- 按 `start_time` / `end_time` 补算时，边界外提交 MUST NOT 被算进来；
- 单条现算耗时以实测为准（P50 ≈ 108 秒），验收文档与页面文案不得写成秒级。
