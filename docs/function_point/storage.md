# 功能点 1 数据库存储

一句话：统一持久化「缺陷数据集、用户信息、用户配置、已训练模型、算法库」五类数据，集中在 `/storage` 一个页面中查看自己完成的文件与做过的配置；已保存的配置在后端或页面重开后自动恢复。

设计图功能 ①「数据库存储」。表结构见 [`../database/`](../database/)；接口见 [`../api/storage.md`](../api/storage.md)、[`../api/datasets.md`](../api/datasets.md)、[`../api/config.md`](../api/config.md)、[`../api/models.md`](../api/models.md)。

## 0 界面划分（已定）

功能点 1 只由一个页面承载：**数据存储页 `/storage`**。

- 页面同时提供两类内容：① 用户完成的文件——数据集、各阶段产物、已训练模型、算法库；② 用户做过的配置——五项用户配置。
- 本页包含配置区；`/settings` 仅作为兼容地址重定向到本页配置区。
- 页面分为四个区域：我的文件（产物库）、数据链路、算法库、我的配置。

## 1 五类数据与页面区域

| 数据 | 落库 | 页面区域 | 口径 |
|---|---|---|---|
| 缺陷数据集 | `dataset` / `dataset_commit` | 我的文件 | 收集或清洗产出后自动登记；可查看成员、导出 CSV、删除 |
| 用户信息 | `user` | 不展示 | **单用户**：预置 `global` 行承载配置归属；不做登录、注册、多用户切换 |
| 用户配置 | `user_config` | 我的配置 | 展示五项；重开后自动恢复已保存值 |
| 已训练模型 | `model` / `model_artifact` | 我的文件 | 训练产出登记；按 `model_name` 加载 |
| 算法库 | `algorithm` | 算法库 | 由 `data_model` 注册表同步的**只读**目录 |

## 2 职责

- 数据集登记与统计回填：样本数、正负样本、提交时间范围、成员关系。
- 模型与算法登记：模型文件与训练任务关联；算法清单与超参数 schema 入库，供训练页读取。
- 单用户与配置归属：`user` 预置 `global` 行，`user_config` 按用户归属存储。
- 产物库与数据链路查询：按 `job.chain_id` / `parent_job_ids` 还原任务树，支持整链删除。
- 配置读写与恢复：读取、批量写入、单键写入、删除回落；服务重启或页面重开后恢复已保存配置。
- 数据集 CSV 导出：仅用于数据集成员导出，不提供按表导出页面入口。

## 3 不负责

- 不做多用户、登录注册、权限审批流与多租户隔离；固定 `X-API-Key`，所有配置归属 `global`。
- 不执行收集、SZZ、清洗、训练、预测、评估、解释、定位。
- 不接受页面文件上传；不提供「文件导入」子签。
- 不提供算法的新增、编辑、删除、启用/停用入口；算法库只读。
- 不修改模块产物本身，不把登记当作模块运行前置。

## 4 算法库口径

- 唯一来源：`data_model/pipelines/registry.py` 的 `algorithms()`；前端 MUST NOT 硬编码算法清单。
- 同步方式：查询或训练前按 `(line, algo)` 幂等登记到 `algorithm`，已存在不覆盖。
- 规模：`expert` / `semantic` 两线各 12 个注册算法，其中 8 个 `enabled=1` 为默认训练集合；其余可被显式选择。
- 页面只读列：算法、模型线、类别（`family`）、是否默认、说明；支持按模型线筛选与关键字搜索。
- 不展示、不允许修改超参数 schema；训练页的动态超参数表单直接消费该 schema。

## 5 配置与重启恢复

本页「我的配置」区只展示五项：

| 配置键 | 含义 | 约束 |
|---|---|---|
| `risk_high_threshold` | 高风险阈值 | (0,1)，须大于中风险阈值 |
| `risk_mid_threshold` | 中风险阈值 | (0,1)，须小于高风险阈值 |
| `default_dataset` | 默认数据集 | 引用对象必须已登记 |
| `default_xai` | 默认解释技术 | 枚举值合法 |
| `page_prefs` | 页面偏好 | JSON 对象 |

- 其余配置键仍由 `GET/PUT /api/config` 提供，但不在本页展示。
- 保存写 `user_config`（`user_id=global`）；后端重启或页面重开后读取同一行自动回填。
- 只恢复**已保存**配置；未保存的表单草稿不恢复、不缓存。
- 读取失败时显示错误与重试，MUST NOT 用默认值冒充已加载。

## 6 数据存储页能力范围（页面文档细化）

- 四个区域：我的文件（产物库）、数据链路、算法库、我的配置。
- 我的文件：数据集与六类任务结果的统计、筛选、分页、查看与下载；数据集可删除。
- 数据链路：按 `chain_id` / `parent_job_ids` 展示链路与节点，支持整链删除。
- 算法库：只读列出两线算法、默认标记与说明。
- 我的配置：读写五项用户配置，保存后立即生效。
- 整链删除：链内任务、产物、模型与数据集一并删除；被链路外引用时拒绝（40001）并列出引用方。
- 页面交互与验收见 [`../web_page/storage.md`](../web_page/storage.md)，本文不重复。

## 7 约束

- 单用户：`user` 无凭证列；配置归属缺省 `global`，`disabled` 用户的配置读取返回明确错误。
- 算法清单由注册表同步，数据库为空时首次查询自动补齐，不靠前端硬编码。
- 数据集 CSV 导出上限与过滤条件以 [`../api/storage.md`](../api/storage.md) 为准。
- 整链删除必须 `confirm=true`；共享引用检查通过后才提交，失败整体回滚。
- 配置引用对象（数据集、解释技术）必须已登记。

## 8 验收

- 五类数据均有落库表与可查询入口；算法库区可列出两线算法、默认标记与说明，且无编辑入口。
- 一个 `/storage` 页面同时承载「我的文件」与「我的配置」；`/settings` 重定向到本页配置区。
- 本页配置区只出现五项；修改保存后立即生效，后端重启与页面重开后回填已保存值。
- 读取配置失败时显示错误与重试，不显示伪造默认值。
- 数据集可见成员、可导出 CSV、可删除；模块产物文件不受影响。
- 依次跑收集 → 清洗 → 训练 → 预测 → 评估后，链路接口返回同一条链；训练多模型时分叉不拆链。
- 整链删除缺 `confirm=true` 被拒；有外部引用时被拒并列出引用方；无外部引用时任务、产物、模型与数据集一并清除。
- 本页不出现文件导入入口；数据库为空不影响任何模块独立运行。

## 9 边界

storage 是展示与持久化的可选层。模块间交接只依赖文件与 manifest；数据库缺失、登记失败或被清空，都不改变模块产物与独立验收结论。用户体系只服务单用户配置归属，不承担认证与权限。
