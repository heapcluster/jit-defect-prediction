## 为什么低保真

先把「数据从哪来」对齐，再做视觉。信息结构没定就做视觉，改一次等于重做一次。

## 三页面低保真要点

| 页面 | 低保真包含 |
|---|---|
| 风险列表 | 表格（哈希/作者/时间/风险%）+ 筛选条（模型下拉/最低风险/时间）+ 分页 |
| 提交详情 | 顶部元信息 + 风险解释条（横向 bar）+ 14 项特征值分组表 |
| 趋势看板 | 折线图（avg_risk）+ 汇总卡（提交总数/高风险/加权平均）+ 周期 tooltip |

## 边界

- **只有三个页面**，第四个（模型管理/用户设置）不做（课程没要求，且稀释完成度）。
- 趋势看板不做分组、不做同图多模型对比（单模型单维度）。
- 视觉与交互细节以飞书原型为准；字段以 `docs/frontend/pages.md` 为准。
