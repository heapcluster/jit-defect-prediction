## 1. G1-1 缺陷可视化定位（行级）

- **做什么**：按缺陷概率分档高亮可疑代码行，色阶与 `frontend/pages.md` 第 5 节同源。
- **降级**：行级数据缺失时**降到提交级并给出提示，不报错**。
- **依据**：用户调研显示行号漂移是可解释性障碍，故验收标准写死「必须能降级」。

## 2. G1-2 高质量修复建议

- **做什么**：给出**可回溯到风险解释键名**的修复建议；无依据时**不编造**，返回空态。
- **边界**：不新造解释字段，复用 `model/explanation.md` 的 SHAP 键名。

## 3. G1-3 公开缺陷数据集加载与质量治理

- **定位**：数据源扩展，与 ActiveMQ 基线**并列**；不替换现有数据管线与交付模型。
- **加载**：新增加载器把公开 JIT 数据集解析为与 `commit` / `commit_label` / `commit_feature` 对齐的记录（**不另立字段名**）；缺必需字段（如提交时间）则报缺失清单并终止该批，不产半成品。
- **质量治理**（对应课程点名的三类突出问题）：
  1. **标签粒度粗**（仅有/无缺陷、无缺陷类型）→ 保留二分类标签，元数据如实标注「无缺陷类型」，不伪造类型；
  2. **以 Java 为主、其他语种少** → 记录语种分布，非 Java 样本单列统计；
  3. **数据质量**（不完整/不准确/不一致）→ 按高质量数据集评价方法输出缺失率、重复率、时间序一致性报告。
- **边界**：公开数据集仅用于对照实验与质量分析，**不入交付链**；开工前走契约变更流程。
- **规格**：change `feature-addons-sprint3` → `public-dataset-quality`（见 `openspec/changes/public-dataset-quality/`；旧 `specs/public-dataset` 已随 G1-3 移出而删除）。

## 4. G1-4 预训练语义特征建模 —— 已提升为模型线主线（2026-10-13）

> **口径变更**：原定位为「可选附加 · Sprint 3 · 立项不实现」。经任课教师 2026-10-13 指导与课程附加功能 (4)
> （「早期方法基于专家特征（Kamei 14），现在主流方法是预训练模型提取深层语义特征」）判定，**提升为模型线主线**，
> Sprint 2 启动；**Kamei 14 保留但降为基线对照组**。完整设计见 change `semantic-feature-mainline`。

- **定位**：模型线主线的新增特征路线；Kamei 14 不再是唯一主线，转为基线对照组。
- **提取（2026-10-13 订正路线）**：
  - **主路线（全量或近全量）**：**CodeBERT / GraphCodeBERT**（代码专用预训练模型，文献主流方向）。先跑 100 条基准测试定时限，CPU 量级为小时级；算力不足则按时间序分层抽样并如实标注。
  - **弱基线（可选，或直接砍掉）**：`all-MiniLM-L6-v2`（通用句向量，**非代码专用**）——域不匹配，仅作「非代码预训练模型」的对照，报告中必须明确标注，不得与主路线混为一谈。
  - 均以**新特征版本** `feature_version = v2` 落盘；**不改契约二既有 14 项列名与顺序**（走契约变更流程登记）。
- **变更文本构造（质量关键）**：按**文件**生成文本（路径 + 变更类型 + 增删行 + 提交信息首行），超模型上限按行截断并**记录截断统计**；同一提交多文件向量取**均值**聚合。整提交拼成一条超长文本会导致信息被截断、语义特征退化为噪声，故按文件聚合。
- **对比实验**：同一切分、同一测试集、同一套 8 模型下评测「仅专家 / 仅语义 / 融合」三类设置，沿用两类指标（Effort-unaware + effort-aware），产出 `data_model/reports/three_way_comparison.md`。
- **补两项论文方法论工作**（Kamei et al. 2013）：① Kamei 14 留一法消融 + 置换重要性；② 「跨项目 JIT 不可迁移」结论显式登记，作为单仓库设计依据。
- **降级与边界**：无 GPU 或时间受限时用 CPU 推理 / 抽样，报告中**如实标注**模型、设备、样本量、是否全量、截断统计（不声称全量 GPU 结果）；**不静默切换交付模型**（切换另开「模型切换」提案，spec `model-coverage` R6）。
- **环境隔离**：语义特征依赖（`torch` / `sentence-transformers`）装独立环境 `jit-defect-prediction`，**不污染** `jit-defect`（87 + 59 条测试依赖它）。
- **规格**：change `semantic-feature-mainline` → `specs/semantic-features`（**7 Requirement / 10 Scenario**，覆盖原 `semantic-feature` 全部内容并扩充）。
