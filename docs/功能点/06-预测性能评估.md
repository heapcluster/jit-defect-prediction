# 功能点 6 预测性能评估

一句话：对有标签的预测结果计算用户选择的分类指标并生成图表，指标表可导出、可保存为评估历史，每张图可单独导出 PNG。

设计图功能 ⑥。预测结果格式见 [05-模型预测](./05-模型预测.md) 第 4 节；页面见 [`../界面/模型评估页.md`](../界面/模型评估页.md)；接口见 [`../接口/evaluate.md`](../接口/evaluate.md)；表见 [`../数据库/evaluation.md`](../数据库/evaluation.md)、[`../数据库/evaluation_figure.md`](../数据库/evaluation_figure.md)。

## 1 范围

- 入口：评估页 `/evaluate`，需登录。
- 输入两类：本人已保存的预测结果数据集；或导入有标签的预测结果 CSV / Excel。
- 一次只评估一个预测结果，不做多结果同图对比。
- 必须带真实标签与预测概率；无标签的纯预测结果不能进入本页。

## 2 输入

### 2.1 已保存的预测结果数据集

- `source_type=prediction` 的本人数据集。
- 明细来自 `prediction` 表；要求全部行的 `actual_label` 非空。
- 任一行 `actual_label` 为空时禁用该数据集，并提示"该结果来自无标签输入，无法评估"。

### 2.2 导入预测结果文件

- 表头必须与**有标签的预测结果导出格式**完全一致：原始数据集列（含 `bug`）+ `risk_score`、`predicted_label`、`threshold`。
- 专家线为 24 列，语义线为 778 列；缺列、多列、列序或数量不符时拒绝，不能进入下一步，并指出第一处不符列。
- `bug` 必须全部为 0 或 1；存在空值、其他取值或两种类别只有一种时，按第 3.3 节处理。
- `predicted_label` 与 `threshold` 列只用于格式对齐；指标按页面阈值与 `risk_score` 重新计算。
- 导入文件可填一个显示名，默认"外部预测结果"；不关联具体模型。

## 3 指标与阈值

### 3.1 指标集合

| 指标 | 字段 | 依赖阈值 |
|---|---|---|
| 准确率 | `accuracy` | 是 |
| 精确率 | `precision` | 是 |
| 召回率 | `recall` | 是 |
| F1 | `f1` | 是 |
| AUC | `auc` | 否 |
| AP | `ap` | 否 |
| MCC | `mcc` | 是 |

- 用户勾选任意子集，至少 1 项。
- 正类为 `bug=1`；概率取 `risk_score`。

### 3.2 阈值

- 评估时统一设置，默认 `0.5`；`risk_score ≥ 阈值` 判为缺陷。
- 精确率、召回率、F1、准确率、MCC、混淆矩阵随阈值变化；AUC 与 AP 不受阈值影响。
- 阈值写入评估历史，重新打开时按保存值展示。
- 导入文件中的 `threshold` 列只作格式校验，不参与计算；评估以页面设置的阈值为准。

### 3.3 类别缺失

- `bug` 只有一种取值时：AUC 与 AP 不可计算，禁止勾选；其余指标可计算并标注"单类别"。
- `bug` 存在空值或其他取值时拒绝评估。

## 4 图表

| 图 | 触发条件 |
|---|---|
| ROC 曲线 | 勾选 AUC |
| PR 曲线 | 勾选 AP |
| 混淆矩阵 | 勾选精确率、召回率、F1、准确率或 MCC 中任意一项 |
| 指标柱状图 | 始终生成，展示本次勾选的全部指标 |

- 图由后端生成 PNG，页面直接展示图片；每张图可单独下载 PNG。
- 未勾选对应指标时不生成该图，不显示空图。

## 5 流程

1. 选择已保存的预测结果数据集，或导入预测结果文件；系统校验标签与表头。
2. 勾选指标；设置阈值，默认 0.5。
3. 开始评估：异步任务生成指标与图片。
4. 查看指标表与图；指标表可导出 CSV / Excel，每张图可导出 PNG。
5. 需要留档时点击保存，写入评估历史；不保存则只保留到重置或开始新评估。

## 6 保存与历史

- 保存后只进入评估页的「历史评估」，**不进入数据存储页**，数据存储页仍然只有数据集与模型。
- 每次评估独立保存，不覆盖；删除某条历史不影响预测数据集与模型。
- 历史记录包含：名称、来源、模型显示名（未知时为空）、阈值、指标值、样本数、生成时间、图表文件。
- 历史列表支持按名称搜索、按时间排序、打开详情、重新下载指标表与 PNG、删除。

## 7 导出

- 指标表：CSV / Excel，每次评估导出为一行，列名为所选指标的英文名加 `threshold`，用户可命名文件。
- 图片：每张图单独下载 PNG，文件名 `{评估名}-{图类型}.png`。
- 页面指标表使用中文表头，导出使用英文列名。

## 8 边界

- 不做预测、不训练模型、不修改预测结果。
- 不支持多结果同图对比。
- 不支持无标签预测结果；纯预测只能看概率与解释。
- 不计算回归类指标，不生成 SHAP 等解释图。
- 评估历史不属于个人资产，不参与数据存储页统计。
- 评估只有点击「保存到评估历史」才写入数据库；运行、查看、导出都不入库。
- 导入文件落 `temp/uploads/<user_id>/<file_id>/`，页面重置或开始新评估时删除；校验失败立即删除。

## 9 验收

- 有标签的预测结果数据集可进入评估；无标签结果被禁用并说明原因。
- 导入文件缺列、多列或列序不符时指出第一处不符列；含空标签时拒绝。
- 只勾选 AUC 与 AP 时只生成 ROC、PR 与指标柱状图，不生成混淆矩阵。
- 阈值从 0.5 改为 0.3 后，精确率、召回率、F1、混淆矩阵随之变化，AUC / AP 不变。
- 单类别数据时 AUC / AP 不可勾选，其余指标可计算。
- 指标表可导出 CSV / Excel，列名与所选指标一致。
- 每张图可单独下载 PNG。
- 保存后历史评估出现一条记录；删除历史不影响预测数据集与模型。
- 未保存的评估在重置后丢弃；刷新与重新登录可恢复当前进度。
