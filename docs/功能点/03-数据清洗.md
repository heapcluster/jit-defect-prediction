# 功能点 03 数据清洗与预处理

一句话：选一个数据集（已保存的或导入的 CSV / Excel），配置清洗操作，逐步骤查看前后变化，最终得到可导出的清洗结果并保存为个人数据集。

## 1 范围

- 数据源二选一：本人已保存的收集、导入清洗或清洗结果数据集（不含测试集与预测结果）；导入的 CSV / Excel。
- 五项清洗与预处理操作，可开关、可调顺序。
- 执行过程逐步骤展示前后变化。
- 结果预览、导出 CSV / Excel、保存为个人数据集。

不负责：收集、训练、预测、评估；不改变列结构。

## 2 输入与输出

- 输入：数据集标识，或符合字段契约的上传文件；一组清洗操作与参数。
- 输出：清洗后的二维表、每步统计快照、可导出的文件、可选登记的数据集。

## 3 流程

1. **选择数据源**：从本人数据集下拉选择（收集、导入清洗、清洗结果）；或上传 CSV / Excel。
2. **校验字段**：表头必须与选定模型线的字段契约逐列一致（列名、顺序、数量）。缺列、多列、列序不符或两线均不匹配时指出第一处不符的列，不接受该文件，不能进入下一步。Excel 只读第一个工作表、首行当表头。文件大小上限 100MB，超限在选择时即拒绝。
3. **配置操作**：勾选要执行的操作，填写参数，可上移下移调整顺序；默认顺序为 去重 → 缺失值 → 异常值 → 标签规范化 → 样本平衡。
4. **执行清洗**：异步任务，逐步骤产出统计快照。
5. **查看变化**：每一步展示一张前后对比图；结果区展示行数、正负样本比例。
6. **查看结果**：分页展示清洗后的二维表，全量行可翻页，只显示主要字段。
7. **导出**：自定义文件名，选择 CSV 或 Excel；导出只是下载。
8. **保存**：登记为当前用户的数据集，记录来源数据集用于详情展示。

## 4 操作清单

| 操作 | 可选方式 | 参数 |
|---|---|---|
| 去重 | 完全重复行 / 按提交 hash | 去重键 |
| 缺失值 | 删除含缺失的行 / 数值列均值填充 / 类别列众数填充 | 目标列、方式 |
| 异常值 | IQR 截断 / IQR 删除 | 目标列、倍数 |
| 标签规范化 | 只保留 0/1、剔除无效标签行 | — |
| 样本平衡 | 欠采样 | 目标标签比例 |

- 一个操作都不选时禁止执行。
- 语义线只允许清洗元数据列与 `bug` 标签，768 维向量列原样保留。
- 类别编码、特征缩放、特征选择不在本板块，留给训练阶段。

### 4.1 参数与默认值

| 操作 | 参数 | 默认 |
|---|---|---|
| 去重 | `key` | `full` |
| 缺失值 | `mode` / `columns` | `drop` / 空数组（全部允许清洗的列） |
| 异常值 | `method` / `factor` / `columns` | `iqr_clip` / `1.5` / 空数组（全部数值特征列） |
| 标签规范化 | — | — |
| 样本平衡 | `method` / `ratio` | `under` / `1.0`（正负 1:1） |

- `columns` 为空表示该线允许清洗的全部列；语义线不含 768 维向量列。
- 默认值用于覆盖键 `ops_hash` 的规范化：未填写的参数按本表补齐后再计算哈希；JSON 键名升序、无多余空格，结果为 64 位小写十六进制。
- 样本平衡只提供欠采样，不提供过采样与 SMOTE；欠采样只删除多数类行，不复制行。
- 欠采样按 `row_no` 升序保留多数类前 `floor(少数类行数 × ratio)` 行，`ratio ≥ 1`，默认 `1.0`；不随机，同输入同输出。
- `ratio` 表示多数类与少数类的目标行数比。

## 5 变化图表

- 每步一张前后对比：行数变化、正负样本比例、所选特征分布三选一。
- 另给一张数值统计对比表：最小、最大、均值、标准差、缺失率。
- 只保留每步统计快照，不落每步全量文件。

## 6 结果与保存

- 导出列结构与输入一致，不增列、不删列、不改列名。
- 未重置时重新执行覆盖当前结果；保存时按覆盖键判断：基于已保存数据集用 `clean|parent_dataset_id|ops_hash`，基于上传文件用 `upload|file_sha256|ops_hash`。键相同则覆盖原数据集，不同则新建；`ops_hash` 为操作按名称排序并补齐默认参数后的 JSON 哈希。
- 覆盖不改变已训练模型与已保存预测结果；覆盖后数据集内容更新，模型权重不变。
- 清洗结果正样本为 0 时不允许保存为数据集。
- 基于导入文件清洗时 `source_type=upload`、`parent_dataset_id` 为空；基于已保存数据集清洗时 `source_type=clean`、parent 指向来源。
- 基于已保存数据集覆盖或新建时，数据存储页的详情中显示来源数据集；基于导入文件清洗时没有来源数据集。
- 清洗结果继承来源数据集的仓库信息（`repo_url`、`repo_name`、`platform`、`branch`、`head_hash`），用于后续缺陷定位。

## 7 边界

- 不改变列结构与列顺序；需要删列、改列名的场景不在本板块。
- 不做编码、缩放、SMOTE、过采样。
- 导入文件只作为本次输入，不登记为资产；只有清洗结果可以保存。
- 清洗结果若仍含重复 `commit_hash`（未执行去重），保存时拒绝，提示先按提交哈希去重。
- 导入文件落 `temp/uploads/<user_id>/<file_id>/`，页面重置或开始新清洗时删除；校验失败立即删除。
- 清洗只有点击「保存」才登记数据集；执行、预览、导出都不入库。
- 导入文件与未保存结果同样保留到重置或下一轮，刷新不丢。
- 未保存的收集结果不在数据源下拉中；需要先保存为数据集，或导出后作为文件导入。

## 8 验收

- 上传表头不符的文件时被拒绝，并指出第一处不符的列。
- 上传符合契约的文件后，能进入操作配置并执行成功。
- 未选择任何操作时执行按钮不可用。
- 每一步都有前后对比图，数值统计表与图一致。
- 结果表可翻页查看全量行，列结构与输入一致。
- 导出文件列名与顺序与输入一致。
- 保存后在数据存储页看到该数据集，详情显示来源数据集。
- 重复执行同一配置时覆盖原结果；覆盖不改变已训练模型与已保存预测结果。
- 结果含重复 `commit_hash` 且未去重时，保存被拒绝并提示先去重。
