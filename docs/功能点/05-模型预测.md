# 功能点 5 模型预测

一句话：用本人模型或导入的模型文件（`.pkl` / `.pt`）对一批提交批量预测缺陷概率，结果可导出、可保存为预测数据集；单条结果可查看解释与缺陷定位。

设计图功能 ⑤。字段契约见 [02-数据收集](./02-数据收集.md) 第 4 节；页面见 [`../界面/模型预测页.md`](../界面/模型预测页.md)、[`../界面/预测详情页.md`](../界面/预测详情页.md)；接口见 [`../接口/predict.md`](../接口/predict.md)；表见 [`../数据库/prediction.md`](../数据库/prediction.md)。

## 1 范围

- 入口：预测页 `/predict`，需登录。
- 数据源：导入 CSV / Excel，或选择本人已保存的任意数据集（收集、清洗、导入清洗、测试集）。
- 数据集分两类：带 `bug` 列的有标签数据；没有 `bug` 列的无标签数据。两类都允许。
- 输入要求 `commit_hash` 唯一且只含一个 `project`；重复提交哈希或混合仓库时拒绝，不做静默去重。
- 模型来源：本人已保存模型，或导入模型文件（`.pkl` / `.pt`）。
- 一次只用一个模型、一个概率阈值。
- 外部导入的数据集不提供缺陷定位，只提供预测与解释。

## 2 输入与输出

| 类型 | 内容 | 去向 |
|---|---|---|
| 输入 | 待预测数据集、模型、概率阈值 | 预测任务 |
| 输出 | 预测结果二维表、每条提交的概率与标签 | 预览 / 导出 / 保存 |
| 可选保存 | 预测结果登记为 `source_type=prediction` 的数据集，明细写入 `prediction` 表 | 数据存储页 |
| 详情产物 | 解释结果、定位结果 | 按需计算，不落库 |

## 3 流程

1. **选择数据源**：上传文件或选择本人数据集。校验表头：元数据列 + 14 项专家特征或 768 维语义特征；除 `bug` 可缺省外，缺列、多列、列序不符或两线均不匹配时指出第一处不符列并拒绝，不能进入下一步；`commit_hash` 重复时同样拒绝。`bug` 列可有可无，据此识别有标签或无标签。
2. **选择模型**：列出与数据线一致的已保存模型；也可导入 `.pkl` / `.pt` 并声明模型线。`.pt` 必须是本项目导出的自包含格式（格式标记 `jit-pt-v1`）。特征数与模型不一致时拒绝。
3. **设置阈值**：0–1 之间，默认 `0.5`；`risk_score ≥ 阈值` 判为缺陷。
4. **执行预测**：异步任务，按行推进，显示进度与总量；可取消，取消后结果不可保存。
5. **查看结果**：分页表格，页面显示七列中文表头；可按预测结果筛选。
6. **查看详情**：点击任意行进入详情页，查看该提交的预测信息、解释与定位。
7. **导出或保存**：导出 CSV / Excel；保存后成为预测数据集资产。

## 4 结果口径

### 4.1 页面七列

| 中文表头 | 字段 |
|---|---|
| 提交哈希 | `commit_hash` |
| 提交说明 | `commit_message` |
| 作者 | `author_name` |
| 提交时间 | `commit_time` |
| 真实标签 | `bug`（无标签时为空） |
| 预测概率 | `risk_score` |
| 预测结果 | `predicted_label`（1 显示"缺陷"，0 显示"正常"） |

### 4.2 导出列

- 原始列严格保持数据集契约的英文列名与顺序；有 `bug` 则保留，无 `bug` 则不补。
- 末尾追加 `risk_score`、`predicted_label`、`threshold` 三列，顺序固定。
- 导出文件为 UTF-8 BOM CSV 或 Excel，首行为表头。
- 有标签数据只展示真实值与预测值，不计算 Accuracy / F1 / AUC；指标属于评估板块。

## 5 解释

- 专家线支持 SHAP、LIME、置换重要性；语义线支持 LIME 与置换重要性，并展示贡献最大的向量维度。
- 解释按提交按需计算，只在当前页面内缓存，不写数据库；关闭页面后需重新计算。
- 解释结果展示特征贡献排序表，专家线附贡献条形图。

## 6 缺陷定位与修复

- 仅对**有仓库来源**的数据集开放：系统收集的数据集，以及由它派生的清洗结果、测试集、预测数据集。
- 按提交取 diff，候选行为新增与修改行；按文件改动量、空值/边界/异常关键字等规则加权排序，标出可疑行。
- 修复建议使用规则模板，按关键字类别给出，不调用外部模型。
- 外部导入的数据集没有仓库来源，详情页明确提示"无源码，不支持定位"，不伪造结果。

## 7 保存

- 每次预测独立保存为一条资产，同一模型对同一提交的多次预测分别保留。
- 默认名称 `{源数据集名}-{模型名}-predict-{job_id 去掉 job_ 前缀后的前 8 位}`，可修改；长度 1–128，字符规则同数据集名称。
- 预测数据集 `source_type=prediction`，`parent_dataset_id` 指向输入数据集；输入为文件时为空。
- 明细写入 `prediction` 表，主键 `(dataset_id, commit_hash)`；不使用 `dataset_commit`。
- 保存时按每行 `project` + `commit_hash` 幂等补齐 `commit` 行并写 `commit_id`；详情页通过 `commit_id` 取提交说明、作者与提交时间，临时目录清理后仍可读。
- 保存预测结果不依赖模型是否已保存；导入模型可直接保存结果，`model_name` 为空、`model_label` 保留，后续解释不可用。若希望复用模型与解释，可先调用 [`POST /api/predict/save-model`](../接口/predict.md) 保存模型。
- 未保存的结果在重置或开始新流程时丢弃，刷新与重新登录不丢。

## 8 边界

- 不做多模型同时预测，不做在线学习与增量预测。
- 不做模型评估与指标计算。
- 不修改仓库、不提交代码、不自动修复。
- 不对外部导入数据集提供缺陷定位。
- `.pkl` 导入接受任意 sklearn 兼容模型；`.pt` 只接受本项目导出的自包含格式。两者都必须声明模型线并通过特征数校验；加载在独立工作进程中进行，文件限制 200MB。
- 预测只有点击「保存到数据库」才写入 `prediction` 与预测数据集；执行、预览、详情、解释、定位、导出都不入库。

## 9 验收

- 带 `bug` 与不带 `bug` 的数据集都能通过校验并开始预测，错误文件指出第一处不符列。
- 模型线与数据集线不一致时禁止开始。
- 阈值为 0.5 时，概率 0.5 判为缺陷；修改阈值后预测标签随之变化。
- 结果表显示七列中文表头，分页读取真实数据。
- 有标签数据展示真实标签，但不出现指标计算。
- 导出文件保持原始列名与顺序，末尾追加三列预测字段。
- 点击行进入详情页，可切换 SHAP / LIME / 置换重要性；切换不写数据库。
- 有仓库来源的提交能展示 diff、可疑行与修复建议；外部导入数据集显示"不支持定位"。
- 保存后数据存储页出现预测数据集，标签为"预测结果"；每次预测独立成条，历史不被覆盖。
- 未保存结果在重置后丢弃；刷新与重新登录可恢复。
