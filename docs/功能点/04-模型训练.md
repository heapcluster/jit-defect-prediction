# 功能点 4 模型训练

一句话：用本人数据集或导入文件训练一个或多个算法模型，按用户自定义的三段比例切分训练 / 验证 / 测试，产出模型文件（`.pkl` / `.pt`）、测试集与指标对比。

设计图功能 ④。字段契约见 [02-数据收集](./02-数据收集.md) 第 4 节；页面见 [`../界面/模型训练页.md`](../界面/模型训练页.md)；接口见 [`../接口/train.md`](../接口/train.md)；表见 [`../数据库/model.md`](../数据库/model.md)、[`../数据库/model_artifact.md`](../数据库/model_artifact.md)。

## 1 范围

- 入口：训练页 `/train`，需登录。
- 数据源两类：① 导入符合字段契约的 CSV / Excel；② 本人已保存的收集结果、清洗结果或导入清洗结果（`upload`），不含测试集。
- 模型线由表头自动识别：14 项特征为 `expert`，768 维为 `semantic`；识别失败直接拒绝。
- 只用本人的数据与模型，不跨用户。

## 2 输入与输出

| 类型 | 内容 | 去向 |
|---|---|---|
| 输入 | 数据集或导入文件、算法与超参、切分方式与三段比例 | 训练任务 |
| 输出 | 每个算法的模型文件（`.pkl` / `.pt`）、测试集、训练与验证指标 | 下载 / 保存为个人资产 |
| 可选保存 | 选中的模型登记为 `model` + `model_artifact`；测试集登记为 `source_type=split` 的数据集 | 数据存储页 |

- 导入文件与已保存数据集同规则：只作输入，不自动登记；未保存的产物在重置或开始新流程时丢弃。
- 刷新页面与重新登录不丢当前训练页进度与已产出的结果。

## 3 流程

1. **选择数据源**：上传文件，或选择本人已保存的收集 / 清洗 / 导入清洗结果（不含测试集与预测结果）。校验表头、列序、列数与字段契约逐列一致；缺列、多列、列序不符或两线均不匹配时指出第一处不符的列并拒绝，不能进入下一步。识别模型线。
2. **选择算法**：列出当前模型线固定的 13 个算法（见 [`../数据库/algorithm.md`](../数据库/algorithm.md)），**默认全部不勾选**，由用户自行选择，至少选 1 个。每个算法按其超参 schema 展示基础超参，默认值来自文档固定表，可修改。
3. **切分数据**：时间序切分与比例切分二选一。
   - 时间序：按 `commit_time` 升序排序，时间相同按 `commit_hash` 升序；训练取前段、验证取中段、测试取末段。
   - 比例切分：固定随机种子 `42` 打乱后按比例切分。
   - 三段比例由用户填写，均须大于 0 且合计 100%。
   - 行数分配固定为：训练 = `floor(n × train% / 100)`，验证 = `floor(n × valid% / 100)`，测试 = 剩余行。
   - 训练、验证、测试三段都必须同时包含正样本与负样本；任一段缺类时禁止开始训练，并提示调整比例或切分方式。
4. **执行训练**：异步任务，`total` 为算法个数，实时显示当前正在训练的模型与进度；可取消。
   - 单个算法失败不中断其余算法，结果中标为失败并给出原因。
   - 全部算法失败时任务失败；至少一个成功则任务成功。
   - 取消后本轮全部结果丢弃，不可保存。
5. **查看效果**：展示每个算法在训练集与验证集上的指标，柱状图按单个指标对比，雷达图展示多模型综合效果；测试集只导出，不在本页评估。
6. **产出与保存**：下载模型文件（`.pkl` / `.pt`）或测试集 CSV / Excel；勾选后保存为个人资产。

## 4 训练口径

- 预处理统一封装进模型产物：缺失值填充 + 按算法需要的标准化，**只在训练集拟合**，验证与测试只做 transform。
- 产物同时保存特征顺序与模型线，预测页不需要再猜列序。
- 产物格式由算法决定：`lr`…`mlp` 为 sklearn Pipeline，存单个 `.pkl`；`dnn` / `tabnet` 为 PyTorch，存单个 `.pt`，内含 `state_dict`、算法、超参、特征顺序、特征版本、模型线与预处理 Pipeline，格式标记 `jit-pt-v1`。
- 输入要求提交哈希唯一且只含一个 `project`；重复或混合仓库时拒绝，避免同一提交跨训练 / 测试段泄漏。
- 不做重采样；类别不平衡由清洗阶段的欠采样处理。
- 不做超参搜索、不做交叉验证、不做早停；参数取用户填写值与 [`../数据库/algorithm.md`](../数据库/algorithm.md) 中的固定默认值。
- 算法参数只接受 `algorithm.md` 中该算法登记的键；未知键或类型不符返回 `40001`。
- 随机种子固定为 `42`，用于切分与模型初始化，保证同输入同结果。
- 分类阈值固定 `0.5`；风险阈值属于预测板块，不在此处。
- 训练只读数据集快照 `dataset_commit.feature_json`，不读全局 `commit_feature`。

## 5 指标与图表

- 指标固定为：Accuracy、Precision、Recall、F1、AUC、MCC。
- 柱状图：横轴为算法，纵轴为当前选中的单个指标，训练与验证并列。
- 雷达图：每个算法一条折线，轴为 Precision、Recall、F1、AUC、MCC。
- 训练集指标只用于观察过拟合，不作为模型优劣的最终依据。

## 6 保存与命名

- 模型名自动生成 `{line}-{algo}-{job_id 去掉 job_ 前缀后的前 8 位}`，全局唯一；用户不能改名。
- 模型文件写入 `temp/models/<user_id>/<model_name>/`，登记 `sha256`、大小、训练任务、`framework`、`format` 与 `feature_version`：sklearn 为 `sklearn` / `pkl`，`dnn` / `tabnet` 为 `pytorch` / `pt`。
- 测试集保存名默认 `{源数据集名}-test-{job_id 去掉 job_ 前缀后的前 8 位}`，可修改；名称长度 1–128，字符规则同数据集名称；`source_type=split`，`parent_dataset_id` 指向源数据集。
- 测试集继承源数据集的仓库信息（`repo_url`、`repo_name`、`platform`、`branch`、`head_hash`），保证之后可做缺陷定位。
- 测试集成员按 `dataset_commit` 写入，特征存 `feature_json`，与源数据集同一契约。
- 保存为资产后按资产规则独立登记；未保存的模型与测试集不进入数据存储页。

## 7 边界

- 不做超参搜索、自动调参、模型集成与蒸馏。
- 不做跨数据集合并训练，不做跨用户共享模型。
- 不做在线学习与增量训练。
- 导入文件落 `temp/uploads/<user_id>/<file_id>/`，页面重置或开始新训练时删除。
- 不在本页做预测或解释；模型推理属于预测板块。
- 不改进模型文件内容，不提供模型重命名、编辑与删除入口（删除在数据存储页）。
- 训练只有点击「保存选中资产」才写入 `model`、`model_artifact` 与测试集；执行与下载都不入库。

## 8 验收

- 导入列名、列序或列数与契约不符的文件被拒绝，并指出第一处不符列。
- 系统能按表头自动识别专家线 / 语义线，并在页面显示识别结果。
- 勾选多个算法后，训练任务进度按算法个数推进，并显示当前模型名。
- 时间序切分按提交时间升序，比例切分同输入同结果；三段比例之和不为 100 时禁止开始。
- 任一段缺少正样本或负样本时禁止开始训练，并指出缺失的段。
- 训练完成后显示训练与验证两套指标，柱状图与雷达图可切换指标。
- 每个成功算法产出一个可下载的模型文件（`.pkl` / `.pt`），加载后可直接预测，无需外部预处理。
- 测试集可导出 CSV / Excel，导出时可自定义文件名与格式，列名与顺序与数据集契约一致。
- 勾选保存后，模型出现在数据存储页的「我的文件」，测试集作为 `split` 数据集出现并带父数据集关系。
- 取消训练后本轮结果不可保存；单个算法失败不影响其余算法完成。
