# 功能点

描述每个功能「做什么、输入输出、流程、边界、验收」。不写页面布局、字段结构与接口细节，这些分别由 `界面/`、`数据库/`、`接口/` 负责。

## 单篇模板

- 范围：功能边界与触发入口。
- 输入与输出：上游产物、下游产物、落库对象。
- 流程：主步骤与分支，含失败与中断。
- 边界：明确不做什么。
- 验收：可观察的完成条件。

## 编写规则

1. 一篇只覆盖一个功能点，编号与 [设计图](assets/设计图.png) 的 ①–⑧ 对齐；功能点 ⑨（IDE / 插件 / CI-CD）不在 Web 范围，不写文档。
2. 登录与多用户不属于设计图 9 项，编号为 00，排在设计图功能之前。
3. 流程只依赖文件与接口契约，不描述实现内部分层。
4. 功能点之间的交接只写产物与接口，不写“调用某个函数”。
5. 与页面的对应关系登记在 [../index.md](../index.md) 第 4 节，本篇不重复整张矩阵。
