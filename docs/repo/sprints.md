## 2. 每周固定节点

| 时间 | 事 | 谁 |
|---|---|---|
| 每周五晚 | 交周报 `工作周报-日期` | 蒋励 |
| 每周五课上 | 进展汇报 | 蒋励 |
| 每周三前 | 可约老师 30min | 有议题者提，蒋励约 |
| 每工作日 | 站会（10min 内，可异步） | 蒋励组织 |
| 每 Sprint 末 | 迭代评审 + 回顾会 | 苏哲勋 / 蒋励 |

## 3. 逾期升级

- 当天没动 → 站会说明卡点，当场定解决。
- 到期未完成 → 看板标「已延期」+ 说明 + 定继续/缩范围/换人。
- **卡超 1 工作日必须升级**：SM 推到有结论，推不动报 PO，必要时周三约老师。
- 默认：宁可缩范围不可拖交付物（课程按 Sprint 交付物打分）。

## 4. Scrum 仪式

每日站会（三问：昨天/今天/卡哪，允许异步文字）/ 迭代评审（PO，演示可运行增量）/ 回顾会（SM，一条继续+一条改进）/ 每周五汇报（组长）。站会只同步不技术讨论。
