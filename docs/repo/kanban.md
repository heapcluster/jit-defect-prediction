# 看板字段与状态口径

> 来源：原 `docs/collaboration.md` §5（已并入本文件） ｜ 负责人：苏哲勋
> 看板名：`JIT 缺陷预测 · 项目看板` ｜ 表：`任务`

## 字段定义

| 字段 | 类型 | 取值 | 说明 |
|---|---|---|---|
| 任务 | 文本 | — | 一句话说清做什么，对应周报「重要工作事项」 |
| 迭代 | 单选 | Sprint 0~3 | 课程 4 个 Sprint |
| 规格变更或任务 | 文本 | change id；无则 `—` | 课程要求看板对应 Sprint 与 change/task；纯飞书产物填 `—` |
| 类型 | 单选 | type:feat/bug/docs/test/chore | 与 Issue 标签一致 |
| 负责人 | 单选 | 蒋励/苏哲勋/吕建江/刘帅华 | 一人一线 |
| 状态 | 单选 | 未开始/进行中/待审阅/已完成/已延期 | 五值封闭，不得自造 |
| 优先级 | 单选 | 高/中/低 | 高=卡别人/有关键时间点 |
| 关联链接 | 超链接 | — | 指向 Issue/PR/change，**能点开=可追溯落地** |

不设：归属线（一人一线）、截止时间（写在周报）。

## 状态判定（以交付物在哪为准）

| 状态 | 用 when |
|---|---|
| 未开始 | 无产物/分支/PR |
| 进行中 | 有产物或分支，但关键交付物缺项 |
| 待审阅 | 交付物在 PR 上等合（≠有人在审） |
| 已完成 | 已在 `main`，别人 clone 能拿到 |
| 已延期 | 过约定截止仍未「已完成」 |

两处易错：`待审阅`≠有人在审；`已完成`以 main 为准不以「我干完」为准。

## 对应

- 周报「本周计划」一行 → 看板一行。
- 看板 `规格变更或任务` 能点回 openspec change / GitHub Issue/PR。
- 合完 PR 回看板改状态（课程评分点）。
