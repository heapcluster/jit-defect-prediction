# 工作周报规范（repo 包权威）

> 合并自原 `docs/writing-norms.md` §4（已并入 common/writing-norms.md） ｜ 负责人：蒋励（统稿）｜ 审核：苏哲勋
> 课程硬要求：每周五晚上交 `工作周报-日期`，模板结构不得改动。

## 1. 命名与提交

- 命名 `工作周报-日期`（如 `工作周报-20260911`）；组长以组名建飞书文件夹。
- **每周五晚上**提交（放假除外）；**无故缺勤 3 次取消成绩**。
- 个人供稿**周五 17:00 前**给组长，当晚统稿。

## 2. 模板结构不得改动（硬规矩）

只能往既有表格填内容，**不得增删表格/改表头/改列/加章节/改上方说明文字/换块类型**。
比对基线：`docs/common/templates.md`（原 `docs/templates/weekly-report-template.md` 已并入）。合并前六项打勾全过才算「没改模板」：

1. 三节都在、顺序不变 2. 上方说明文字未动 3. 表头逐字一致 4. 无新增章节 5. 块类型未变 6. 填的是内容不是格式。
**留痕**：把「比对基线版本+结论」写进当周「证明材料」格。

## 3. 三张表怎么填

| 表 | 谁填 | 注意 |
|---|---|---|
| 本周计划 | 组长汇总 | 细到「谁做哪件事」；状态用五固定取值 |
| 本周总结 | 组长统稿 | 数字实测值；没做完如实写进「待改进」 |
| 下周计划 | 组长汇总 | 粗到方向，与看板未完成项对齐 |

## 4. 禁止

- 当聊天记录（写「进展顺利」=没写）；只写自己部分；改模板；漏交；仓库文档全文粘进周报（指路径）。

## 5. 与看板/仓库

周报「本周计划」一行 ↔ 看板一行；看板 `关联链接` 点回证据。每周更新周报前先对账（口径见 `kanban.md`）。
