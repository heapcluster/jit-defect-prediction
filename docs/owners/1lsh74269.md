## 4. 原则（做取舍时按这个顺序）

1. **空不是错。** 空数据是正常态，不弹错误；错误码才弹错误。三态必须分开实现，不许糊成一个 `catch`。
2. **不自己造错误信封。** 后端错误包装统一用 `src/api/request.js` 的 `apiError()`（#94 已合入），不允许再写第二套 `toBizError`。
3. **字段顺序即契约。** `FEATURE_GROUPS` 的展平顺序必须与 `feature_order.txt` 的 `[feature_order]` 段逐项一致，用测试守住而不是靠记忆。
4. **不硬编码环境。** 接口地址走 vite proxy，密钥走 `.env.local`，个人路径不进任何入库文件。
5. **截图找得到出处。** 交付的每张图都要能说明：哪个页面、哪个态、怎么造出来的（真实后端 / 断网 / mock），不许混在一起。
